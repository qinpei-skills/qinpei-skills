# 表达基因 · 采集、判定与基因卡（v4 核心）

> **什么时候读这个文件**：四要素全部过关、一句话定位已出口之后；或学员把写好的文案贴回来说「帮我看看像不像我」「这段发朋友圈行吗」（文案自检）。
> **为什么要有这一层**：定位定出来，同赛道的人都差不多（大健康/帮人健康/体型管理）。但定位相同不等于 IP 相同——**差异化不在头衔层（头衔百分百重，是行业结构），在表达层**。表达基因决定他吸引谁。
> 底层逻辑：纳瓦尔「没人能跟你竞争做你自己」；特劳特：定位是占位不是独占——同赛道不同基因，各自吸各自的粉。

---

## 一、采集（全部选择题，回数字，一句一签照常挂）

在 IP 类型四问之前或之后做本采集都行，**一次问一题，绝不连问**。

### 第 1 题 · 叙事人格（四选一）

> 🧭 说句实在话：同样讲养生，过来人讲和研究者讲，吸引的是两拨人。下面四种说话的人，哪个最像你平时跟客户聊天的样子？

| 选项 | 人格 | 内心台词 | 语气基准 | 天然联动要素2的背书 |
|:--:|:--|:--|:--|:--|
| 1 | **过来人** | 我踩过的坑，带你绕 | 讲亲身经历，细节多，常带「我当年/我后来才知道」 | 经历背书 |
| 2 | **同行者** | 我和你一样，一起走 | 陪伴口吻，多提问多回应，常带「我也曾经/咱们」 | 共情背书 |
| 3 | **研究者** | 我拆解给你看 | 讲依据讲原理，爱分类对比，常带「其实/原理是」 | 专业背书 |
| 4 | **实干家** | 我做了有效，直接抄 | 直给步骤和清单，少形容多动作，常带「第一步/照这个做」 | 结果背书 |

**判定规则（看得见就判，禁止凭感觉）**：
- 学员直接选 → 用该人格
- 学员说「都有点像」→ 让他答一道校验题：「客户第一次咨询你，你先说什么？」——答经历→过来人；答「你什么情况」→同行者；答「这个要看原理」→研究者；答「你先做这个」→实干家
- 与要素2背书对不上的（选了实干家但背书是共情）→ **以背书为准**，告诉学员「你的底子是XX型，人格用XX型更撑得住」
- **🔴 人格 × IP 类型联动校验（v4.0.1）**：人格四型与 IP 四类型有天然映射——过来人≈故事型 / 同行者≈陪伴型 / 研究者≈专家型 / 实干家≈工具型。最终结论输出前，对照三.4 四问判出的**主类型**查一遍：映射冲突（如「人格=实干家 + 主类型=陪伴型」）→ **以四问里答得最不犹豫的那一问为准**，但必须在结论里点破矛盾（挂 🧭 说句实在话），让学员二选一——**不许默默输出自相矛盾的结论**。

### 第 2 题 · 价值观取向（三个二选一，可合成一题问）

> ❓ 该你答了：三个小选择，回我三个数字就行——① 发圈你更想显得「高效专业」还是「温暖贴心」？② 说话你更习惯「直接点破」还是「温和提醒」？③ 内容你更愿意给「步骤清单」还是「真实故事」？

- 答案组合成取向标签，如「专业+直接+清单」——写进基因卡
- 三个答案互相矛盾（高效+温和提醒+故事）→ 合法，如实记，不强行归一

### 第 3 题 · 永不说清单

> ❓ 该你答了：有没有哪些话，你打死都不说的？比如夸大效果的话、晒收入、贬低别家……想到什么说什么，说不出来就回「没有」。

- **默认三条，人人都有，学员没说也生效**（合规底线，写进基因卡）：
  1. 不承诺疗效（「吃了就好」「包治」类）
  2. 不晒收入、不展示收益截图
  3. 不贬低同行、不拉踩品牌
- 学员自己加的（如「不提离婚经历」「不用感叹号」）照单全收

## 二、交付物 · 表达基因卡（五件套，一张卡拿走能用）

```
【表达基因卡】
1. 人设宣言（一句）：我是【人格+领域】的【角色】，
   我说话的特点是【语气基准】。
2. 常说 3 句（示范口吻）：
   · …
   · …
   · …
3. 永不说 3 句：
   · 不承诺疗效（默认）
   · 不晒收入（默认）
   · 不贬同行（默认）
   · （学员自加的写这里）
4. 语气基准：【专业/温暖…】+【直接/温和…】——朋友圈、小红书、口播共用这一个地基
5. 衔接一句：下次写任何内容，先问自己「这句话像我说的吗？」
```

**填卡规则**：
- 常说 3 句**必须从学员自己说过的话里长出来**（四要素采集里他讲过的原话优先），AI 只帮忙修顺，不代写金句——他平时不会说的话，发出来就是假
- 一句示范怎么给：「你说'我当年 180 斤，试过三种减肥法都反弹'——这就是过来人式的开场，记住这个味儿。」
- 卡是**定稿产出**，写进画像（见 profile-write.md），并在最终结论里交付

**合成示范（讲给学员听时说明是示范口径，禁当真实成绩）**：
> 「同样是做小儿推拿：过来人说'我孩子积食发烧那次，医院排队三小时，我连夜翻笔记给自己推拿降下来的——现在我把这套手法教给你'；研究者说'积食分三种，你孩子是哪种，对号入座'。两个人群都对，但吸引来的人不一样。」

## 三、文案自检（学员贴文案回来时触发）

**触发词**：「帮我看看这段像不像我」「这段文案发朋友圈行吗」「AI 帮我写的，你看行不行」等任何贴文案求评价的行为。

**流程（按卡四查，看得见就判）**：

| 查 | 什么 | 怎么判 |
|:--:|:--|:--|
| ① 口吻 | 像不像他的人格（过来人/同行者/研究者/实干家） | 文案里有没有该人格的标志词；全家通用话（"希望大家越来越健康"）= 不像 |
| ② 价值 | 有没有「他持续能得到什么」（要素3的影子） | 只有产品名和心情 → 不像 |
| ③ 钩子 | 有没有下一步动作（扣1/私信/到店） | 没有 → 半像 |
| ④ 禁忌 | 撞永不说清单没有 | 撞了 → 一票否决，直接点破 |

**判定三档 + 回复（每档一句改法，不写代改全文）**：
- **像** → 「这条像你说的，发吧。」
- **半像** → 「内容是你的味儿，但少了个'下一步'——结尾加一句'想要的评论区扣1'就完整了。」
- **不像** → 「这条像 AI 写的，不像你——通篇没有一个你的具体细节。挑一件你真做过的事替换中间那段。」
- 撞禁忌 → 「这条不能发，【具体指出撞了哪条】。换个说法：【给一句合规替代表达】。」

**边界**：只判「像不像、行不行」+ 一句改法，**不整段代写**（那是内容包的事）。

## 四、快速采集（学员没建卡就先贴文案时的最小路径）

> **什么时候用**：学员第一条消息就是贴文案求评价、还没走过表达基因采集——先判再补卡，不把三题全套压给他。

**最小采集只有两步**：
1. **第 1 题人格必采**——四选一回数字；学员不肯选 → 用校验题判（见第一节判定规则）。
2. **第 3 题永不说用默认三条**（不承诺疗效 / 不晒收入 / 不贬同行）——学员没说也生效，自加项等他想起再补。

**价值观取向（第 2 题）可后补**：先用中性基准（直接点破 + 清单）判，判完在回复末尾补问一句把第 2 题采了，顺势把卡补全。

**顺手建卡**：判完这条文案，借它做素材——「你这句'……'就是你的味儿，记下来当常说 3 句的第一句」——第一次自检就长出第一句常见话，卡的完成度直接起步。
