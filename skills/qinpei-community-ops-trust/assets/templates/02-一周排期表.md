# 模板 · #2 一周排期表（五类群固定栏目 + 钩子 + 占比校验）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。
>
> ⚠️ **赛道不限中医**：学员可来自**整个大健康赛道**（口腔/视力防控/康复理疗/营养补充/睡眠/心理/慢病管理/运动/健康食品等）。赛道不在案例库内 → 调用模型自身该领域知识按同一逻辑生成，不降质。**红线：不许给非中医学员套"湿气/阳气/脾胃/体质"话术**——学员自己怎么说，内容就怎么说。
> ⚠️ **示例不许跨赛道照抄**：示例只是"长什么样"的示范，不是标准答案。下面带"养生/食谱/拔罐"字样的示例是**中医赛道说法**，视康、减脂、口腔、营养等赛道必须换成自己行业的说法（栏目名也要换）。

## 一、先确认群类型（五选一）

| 群类型 | 产品占比上限 | 核心目标 |
|:---|:---:|:---|
| 兴趣群 | ≤30% | 养客户/验货 |
| 会员服务群 | ≤50% | 已购客户长期服务+复购/转介绍 |
| 垂类打卡群 | ≤50% | 已购客户售后+转化复购/跨品/事业 |
| 养伙伴围观群 | 低 | 养潜在伙伴（不硬邀不逼单） |
| 事业群 | 可高但穿插生活 | 带教训练场 |

学员赛道：【填：如艾灸/减脂/视康/口腔/营养】→ 读 `references/track-case-library.md` 匹配内容侧重与钩子（**案例库是示例不是封闭清单，赛道不在库内 → 用模型自身该领域知识按同一逻辑生成**）。

## 二、排期表（周一~周日 · 固定栏目）

> 每条含：固定栏目 + 内容维度 + 信任层 + 钩子+行动指令

### 周一
- 栏目：【填：如认知升维】｜ 维度：认知升维 ｜ 信任层：二·认可你
- 内容：【填：本期主题一句话】｜ 钩子：【填：如"投票你中了几条→私聊领自测表"】
- 结构：打破一个"人人都信、其实是错的"认知 → 投票 → 私聊领自测表
- 同一栏目·不同赛道的话术：中医「你以为湿气重才拔罐？错」｜**视康「孩子眯眼不是坏习惯，是他在自己调焦」**｜减脂「你以为出汗多就等于燃脂？错」｜口腔「刷牙出血是上火？其实是牙龈在报警」

## 三、建议时段（按客户类型，学员定具体几点）

| 客户类型 | 建议固定栏目时段 | 理由 |
|:---|:---|:---|
| 上班族 | 午休12:30 / 晚20:00-21:00 | 中午和晚上才有空看群 |
| 宝妈 | 上午9:30-10:30 / 晚21:30后 | 娃不在身边的空档 |
| 老人 | 上午9:00 / 晚19:30 | 早起、饭后有规律 |

> 提醒学员：定好后写进群公告，别自己随便改时间。

## 四、占比校验（AI 必须核对）
- [ ] 产品/事业内容占比：兴趣≤30% / 会员服务·垂类打卡≤50% / 事业群可高但穿插生活
- [ ] 三层信任覆盖：一周内认识你/认可你/信任你都有，不只有一层
- [ ] 每条带"钩子+行动指令"（内容离业务近，不只养不收）
- [ ] 六大维度轮着用，不连续3天同一维度
- [ ] 密度匹配学员可投入精力（不排"做不到"）

## 检查清单（AI 交付前对照）
- [ ] 周一~周日完整 7 天，每天主线 1-2 条（不刷屏）
- [ ] 每条有：栏目名 + 内容摘要（一句话，不是空泛主题）+ 钩子+行动指令
- [ ] 内容摘要用的是学员真实画像（赛道/人群），不是通用模板
- [ ] 占比/三层信任/维度轮动校验全过
- [ ] 建议时段按客户类型给了（具体几点由学员定）
- [ ] 无编造数字结果、无硬广
- [ ] **栏目名和内容用的是学员自己赛道的说法**（非中医赛道没出现"养生/食谱/拔罐/体质"等中医词）
- [ ] **案例是学员真实案例**，没有编造数字和细节（学员没给 → 留位置让他填，不代编）
