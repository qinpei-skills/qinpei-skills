# 心结四型与异议拆解 · 完整识别信号与破法

> 状态：v1.0.0-dev｜来源：1对1咨询交付板块「心结分型·三基础型+三新分型」（六场实战验证）→ 转译成**客户版四型**（不信/拖延/比价/无所谓）
> ⚠️ 转译说明：咨询端六型针对**付费学员**（有自我设限、有创伤）；客户版四型针对**零售客户与准伙伴**（信息不对等、怕被坑、怕麻烦）。
> 🔴 第一原则：**先破心结，再谈方案**。心结没破就甩方案＝对着情绪讲道理，白费。

---

## 一、异议预防检查（🔴 顺序不能反，必须先跑）

> 借鉴结构化销售范式：异议多半是销售自己造成的。需求没问清就报价 → 客户必然说贵。

**第一步 · 查上游（必做，30秒）**：

| 客户说 | 先自查 |
|---|---|
| "太贵了" | 🔴 我是不是在她还没说需求时就报了价？ → 是 = 错报在先，别急着降价 |
| "我再想想" | 🔴 我是不是一次推了太多东西 / 讲了太多机制？ → 是 = 信息过载，不怪她犹豫 |
| "我先问问孩子/老公" | 🔴 我是不是跳过了决策链？ → 是 = 该找的是决策人，不是催她 |
| "能先看看效果吗" | 🔴 我是不是没给过任何低门槛的验证方式？ → 是 = 我没铺路 |
| "别家更便宜" | 🔴 我是不是从没讲过我们和别人差在哪？ → 是 = 比较维度是我的漏洞 |
| "我不需要" | 🔴 我是不是在跟一个"不需要"的人硬聊？ → 是 = 该出局，不是该追 |

**第二步 · 才拆异议**（下面四型）

**🔴 预防检查的输出纪律**：查出来是自己的问题 → 先说"这单卡住大概率是我前面没问清"，而不是直接甩话术。学员自己承认这一步，比学十句话术有用。

## 二、心结四型 · 完整识别信号表

### 型1 · 不信型（她不信你这个人或这东西）

**识别信号（学员转述的原话）**：
- "你们是不是传销""听着跟传销似的"
- "我怎么知道你说的真的""你们有资质吗"
- "有效果吗""真的能有用吗"
- "别人也这么说，是不是都是套路"
- 她问的都是"你**是不是**"而不是"这个东西**怎么**"

**根因**：信息不对等 + 怕被坑 + 熟人推荐带来的"关系压力"（她不好意思直接拒绝熟人）

**破法（三步，🔴 顺序）**：
1. **换框**——把神秘的东西换成可理解的机制："你不用信我，你先看这个逻辑……"
2. **归因拉回**——证据放在具体的人和具体的事上，不放品牌名："我服务过的客户里，有一个跟你情况差不多的，她当时也是……"
3. **降级验证**——给一个低成本、可反悔的验证方式：先看看/先试一次/你先问别人。🔴 **不信型最忌讳强攻**，越证明越退

**🔴 失效边界**：如果她的不信来自"曾经被这个品牌坑过"→ 换框无效，要做的是**明确说"那次是XX问题，我们不一样在哪"**，承认历史而不是回避。

**给退路的作用**：不信型客户拿到退路（不合适就算）反而更愿意试——她怕的是被锁住。

---

### 型2 · 拖延型（不是不信，是不想现在做决定）

**识别信号**：
- "我再想想""回头再说""等我忙完这阵"
- "等我孩子放暑假""等我这边忙完"
- "等我跟我先生商量一下"（真商量 or 借口，看后续有没有动作）
- 她聊得挺开心但一直不接下一步

**根因**：三类可能 —— ①真的不急 ②某个具体顾虑没被解决 ③她不知道怎么跟别人开口（要说服家人/团队）

**破法**：
1. **拆穿合理化**（🟡要温和）："如果我猜得没错，你不是没时间，是还没想好跟家里怎么开口，对吧？"
2. **找到那件具体的事**——用事实层问法逼出来："具体哪一块让你还得再想想？"
3. **给最小动作**（不是"你定"）："这周你先试一次怎么样？不用定，就试一次，不合适就算了。"
4. 🔴 **拆穿她的借口 ≠ 催单**——拆穿的目的是**定位真问题**，不是逼她现在下单

**🔴 失效边界**：她真的是"这阵忙"（有明显的时间节点，如"我这个月出差"）→ 🔴 **别拆穿，别催**，给个具体时间点："那我们等你回来，我到时候再找你。" 强行拆穿真诚的忙碌=把客户推远。

**🔴 拖延型最忌讳**：天天催（每次催都在提醒她"你还没定"）。

---

### 型3 · 比价型（她在算账，或者她只是需要一个理由）

**识别信号**：
- "太贵了""别家便宜多少""能不能优惠"
- "XX牌是不是更划算""网上买更便宜"
- "我再比两家"

**根因**：真实的经济考量 ＋ **或者** 她需要一个"不买"的台阶（尤其熟人推荐，她想保留面子）

**破法（三步）**：
1. **算账，把单价拆成单位成本**："这个是XX元，你算一下，你打算用多久？一天不到X元，比你上次买的那个XX还便宜。"
2. **换比较维度**（🔴 关键）：不比单价，比**用起来的结果和风险**——服务的人是不是还在、出了问题找不找得到、有没有退路。⚠️ **不贬低同行**（内容立场铁律：同行做的是同一件事就承认，不否定）——说"我们多了什么"，不说"他们不行"
3. **给退路**：不合适怎么办、多久能退、能不能先试。给了退路的比价型客户，决策速度反而更快

**🔴 失效边界**：她真的在比另一家的**同类产品**，且对方价格确实更低 → 🔴 不要硬扛性价比。给"**买哪一个**"的判断标准（看她要什么），把选择权还给她；不要为了成交去贬低同行或编造对方的黑点（X10 + 立场铁律）。

**🔴 真实成本话术库**（🟡演绎，学员按自己语气改）：
- "你别只看这一次的价钱。你算一下你要用多久、一次多少钱——跟它比的是你现在用的那个东西，不是它的标价。"
- "价格是明面上的。你可以再看看别处——我更想让你看的是：买完之后出问题，你找谁。"
- "你先别急着定。你把两边的差列出来，差在哪一块，你按那块重要来定。"

---

### 型4 · 无所谓型（她没被点燃，或者她不是对的人）

**识别信号**：
- "我先随便看看""没什么兴趣"
- "以后再说吧""有需要联系你"
- 回复极短、只回"嗯""哦""好的"
- 她在群里但不参与话题

**根因**：她现在没有需求 ＋ 或者**你找错人了**（她根本不是目标客户）

**破法**：
1. **价值前置 + 弱连接**——不推，先给一个有用的东西："你现在用的是什么？我给你发个对比，你有空看看。"
2. **允许出局**（🔴 这一型的关键）："如果你现在不需要，那就先不用聊，我不打扰你。有需要随时找我。"
3. **放到长线**——她不是拒绝，是时机没到。记下来，定一个复访时间点

**🔴 失效边界**：如果她已经**明确拒绝并且已经拉黑/明确拒绝后续联系** → 🔴 **立即停止跟进**，只留一次礼貌收尾，之后不再主动联系（这是红线，不是话术问题）。

**🔴 无所谓型最忌讳**：硬推、用"稀缺"逼单、追着问"那你要不要"。

## 三、四型速查（一页版）

| 型 | 一句话识别 | 破法核心 | 🔴 大忌 |
|---|---|---|---|
| 不信 | 她问"你**是不是**" | 换框＋归因拉回＋降级验证 | 强攻证明 |
| 拖延 | "再想想""回头说" | 拆合理化＋找具体事＋最小动作 | 天天催 |
| 比价 | "太贵""别家更便宜" | 算账＋换维度＋给退路 | 贬低同行/硬扛 |
| 无所谓 | 敷衍短回复 | 价值前置＋允许出局 | 硬推/逼单 |

## 四、允许出局：怎么说（这一段话要背）

> 🟡演绎，学员按自己语气改。这段话的作用是**给客户台阶=给她下一次回头的路**。

- 「你要是现在不需要，那就先不用聊，我真不打扰你。」
- 「这个事不着急。你什么时候觉得需要了，随时找我。」
- 「我估计这个对你现在不一定合适，你要真觉得不合适，咱们就都别勉强。」
- 退出后**不再主动追**（🔴 只留一句收尾，之后安静）。想复访就等她有信号，或者按她给的节奏。

**🔴 纪律**：允许出局 ≠ 摆烂。允许出局是**专业判断**（"这单别追了"也是Advance的一种），不是放弃。但不许用"允许出局"当偷懒的借口——真该追的单要追。
