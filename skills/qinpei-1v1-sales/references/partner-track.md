# 轨道B · 事业伙伴招募（招合伙人/招合作伙伴）

> 状态：v1.0.0-dev｜证据等级：🟡**演绎为主**（结构可用、话术必须学员换成自己的话；v1.1 收实测）
> 来源：1对1咨询交付板块咨询端 JTBD 用法 + 团队长案例库伙伴场景 + 行业现实数据（首年流失>50%、5年95%、90天关键窗口、99%参与者零收入）
> 🔴 **本篇是全包风险最高的一篇**。伙伴招募踩错线的代价不是少成一单，是拉进来一个会在三个月内流失的人、透支你自己的口碑。

---

## 一、伙伴轨道的第一原则

**伙伴不是靠话术招来的，是靠 90 天陪跑带出来的。**

> 🟢 行业现实数据（引用时说明来源为行业公开研究口径，不编造具体出处）：直销行业首年流失率超 50%、五年流失率约 95%、90 天是决定去留的关键窗口、绝大多数参与者长期零收入。
> 🔴 **推论**：**凡是用"讲收益、讲前景、讲机会"招来的人，恰好是三个月内会走的人**（因为她要的是钱，而钱还没到）。用"讲支持、讲路径、讲退路"带来的人，才可能活过 90 天。

**🔴 因此本轨道的第一动作不是讲机会，是讲退路。**

---

## 二、JTBD 任务陈述三段式（她真正雇你来干什么）

> 结构化销售范式：JTBD＝Job to Be Done，客户"雇"你是为了完成什么任务。

**三段式**：
1. **当【情境】的时候**
2. **我想【完成的任务】**
3. **这样我就能【获得的结果】**

**伙伴轨道的示范（🟡演绎，学员换赛道改）**：
> 「当我在自己店里做着，收入卡在一个数上不动的时候，我想找到一件能长期做下去的事，让我不用再靠一单一单地熬，这样我就能有自己的一条线。」

**🔴 检验标准**：这句话里**不能出现钱**。出现钱就变成了"她雇你赚钱"——那她的真实任务就不是这个，她的假异议（怕做不好）会永远解不开。

**追问**：她的任务陈述里出现"赚""分红""收入" → 把话题拉回："就算不谈钱，你最想解决的是什么？"

## 三、四力诊断（她的假异议藏在这里）

| 力 | 问什么 | 读什么 |
|---|---|---|
| **推力**（拉力她有什么） | 「现在是什么让你觉得这事值得试试？」 | 她已经有的资源/技能/热情 |
| **拉力**（她想过什么） | 「你自己想过这事多久了？想过怎么干吗？」 | 她主动想过=真需求；没想过=被你说动了 |
| **焦虑**（她怕什么） | 「你最担心的是什么？怕做不下去还是怕做不好？」 | 🔴 **假异议藏在这里**——她嘴上说"我想做"，真障碍是"我怕我不行" |
| **习惯**（她现在怎么做） | 「你现在靠什么撑到现在？没做这件事之前你是怎么过来的？」 | 她已经有一套活法，习惯=最大的阻力 |

**🔴 四力优先级**：**焦虑 > 拉力 > 习惯 > 推力**。焦虑不解决，后面三样都白做——因为她带着"我不行"的预设进来，你给的所有路径她都会翻译成"我也做不到"。

**🔴 牵引力不足时怎么办**：**别劝，先诊断**。学员说"她没兴趣"→ 她的推力不足。**硬劝来的伙伴90天内流失率最高**，这正是行业数据在警告的事。

---

## 四、伙伴轨道的六步谈法（🔴 顺序不可换）

| 步 | 做什么 | 关键 |
|---|---|---|
| 1 | **先问动机** | 「你自己怎么想到这个事的？」——她说得出自己的理由才谈；说不出来=还没到 |
| 2 | **找焦虑** | 「你最怕的是什么？」——焦虑=真入口 |
| 3 | **讲清支持（不讲收益）** | 你能给什么：带教、样板客户、陪跑、工具、答疑、复盘 |
| 4 | **给90天里程碑** | 不是"以后会更好"，是第7/30/60/90天各看到什么 |
| 5 | **给退出标准** | 🔴 关键：**什么情况可以退出、怎么退、退出不丢人** |
| 6 | **落最小动作** | 这周一起做一件小事（跟一个客户、体验一次服务、做一份样板） |

**🔴 第3步的"讲支持"清单**（🔴 一律不谈金额、不谈回报率、不谈"月入"）：
- 我会怎么带你（具体到"每周一次复盘"）
- 起步期我给你什么现成的（样板话术、样板客户、现成素材）
- 遇到搞不定的事找谁、多久回你
- 我不做的事（🔴 诚实说清楚=专业）

## 五、90天里程碑模板（🟡演绎，学员按自己情况改）

| 时间点 | 她会看到什么 | 你要做的 |
|---|---|---|
| 第7天 | 完成第一次真实接触（哪怕只是陪她聊一个客户） | 复盘这次接触她卡在哪 |
| 第14天 | 完成第一次自主成交 | 复盘：哪句起了作用 |
| 第30天 | 有了第一批可复制的客户来源 | 判断：是她能力问题还是环境问题 |
| 第60天 | 收入结构开始出现第二条腿 | 判断：是否该调整节奏 |
| 第90天 | 双方共同评估 | **明确复盘：这个继续还是调整** |

**🔴 里程碑里不能出现的目标金额**——用"完成了什么动作"而不是"赚到了多少钱"。动作可对账，金额一变化就变成收益承诺。

## 六、退出标准（🔴 本轨道的信任开关）

**为什么必须给**：不谈退路的招募=套路。给退路反而让她敢进——而且**能熬过90天的人，本来就不是被套路来的那批**。

**话术（🟡演绎，学员换自己语气）**：
- 「我先说一句不好听的：三个月里如果你发现这事不适合你，或者家里不同意，你随时可以停，我不怪你，也不会让你难堪。三个月后咱们一起看还继不继续。」
- 「如果三个月你还没跑通第一个闭环，那大概率这行不适合你，早说比晚说好。」

**🔴 纪律**：
- 退出条件要**具体、可判断**（不是"不合适的时候"）
- 退出**不扣任何东西**、不道德绑架
- 说出口之后**不许再以任何形式把她拉回来施压**

## 七、伙伴轨道的合规禁区（🔴 违反即违规，永久禁止）

| 🔴 禁止 | 为什么 | 替代说法 |
|---|---|---|
| "月入过万""轻松月入几千" | 收益承诺 | "起步阶段主要靠你自己的服务收入，成熟之后有团队部分" |
| "稳赚""躺赚""被动收入" | 收益承诺 | "前面几个月主要是打底，收入结构跟你的动作量直接相关" |
| "零风险""不成功也没损失" | 虚假承诺 | "做这件事的成本主要是你的时间和精力" |
| "一定能做起来""跟着我就能…" | 效果承诺 | "我能给你的是支持和路径，能不能跑起来取决于你的动作量" |
| "回本周期X个月" | 收益承诺 | 🔴 不谈回本周期 |
| 拿别人的收入截图当承诺 | 数据不实 | 🔴 案例可讲过程，不讲收入结果 |
| 暗示"做不好也没事"（同时又不给退出标准） | 虚假承诺 | 退出标准要给，但不能用来暗示"反正不损失" |

**🔴 另一条硬线**：**不说"这是零风险的""大不了亏点时间"这类给承诺的话**——人生方向的选择有真实成本，否认成本=另一种虚假。

---

## 八、轨道B 的 Advance 判据（不是"她答应加入"）

伙伴轨道的 Advance 判据（🔴 因为"她答应加入"不等于推进）：
- ✅ 她说出了一个她自己想做的事（原话）
- ✅ 她说出了自己的焦虑（真话，不是"没什么好担心的"）
- ✅ 她答应做第7天那件小事（具体动作）
- ✅ 她开始问你某个具体问题（开始依赖你）
- 🔴 "我再考虑一下""你先发点资料给我" = 停在原地，不算

**🔴 允许出局**：她看完90天里程碑说"我不适合"→ 这就是最好的结果，**明确说"这个不适合你反而好"**，并祝她好。这条路走出来的口碑，比多签一个人值钱得多。

## 九、伙伴轨道 vs 零售轨道的语言差异表（🔴 混轨自检）

| | 零售客户 | 事业伙伴 |
|---|---|---|
| 她要的是 | 一件东西 | 一件事 |
| 谈的是 | 效果、体验、价格 | 路径、支持、节奏、退出 |
| 时间尺度 | 这一单 | 90天/一年 |
| 🔴 禁出现 | 事业/分红/招募/团队规模 | 收益/回本/零风险/躺赚 |
| 收口形态 | 下单/加量/复购 | 加入+里程碑+首周动作 |

## 十、伙伴轨道的失效边界（🔴 轨道B最容易出事）

⛔ **本轨道的每一步都有"不能这么用"的地方**——搞错一步就是合规事故，不是话术问题。

| 步骤/工具 | 🔴 什么时候不适用 | 该怎么调 |
|---|---|---|
| JTBD 三段式 | 她只是想买东西（轨道判错了） | 🔴 立刻回轨道A，别硬套"任务陈述" |
| 四力诊断 | 她只是随口问问，完全没打算做 | 别做诊断——她没进入这个对话，直接礼貌收尾 |
| 90天里程碑 | 她是零售客户买了很多产品（忠诚客户≠准伙伴） | 转轨道A做复购，🔴 禁讲事业/收益 |
| 退出标准 | 她明确要走（已退出） | 🔴 立即停止跟进，不许再劝 |
| 六步谈法 | 她是完全被家人塞来"看看"的 | 先问"你是自己想了解，还是家里让你来的" |
| 每周动作 | 她还没做第一个动作（连第一周都没启动） | 回到第一步，先给一个**今晚就能做**的最小动作 |
| "我能赚多少"类提问 | 🔴 **永远不接**——就算她主动问 | 转到"我能帮你做到什么"＋判断标准，不给数字 |
| 收益测算/回本周期 | 🔴 永久禁止，无例外 | 给退出标准与90天里程碑替代（合规红线，不是话术） |
| 身份想象引导（"三年后你想成为谁"） | 她明确说"我只想赚点零花钱" | 降低期待、做零售级建议，别灌长期叙事 |

🔴 **通用边界**：轨道B 的最大风险不是谈不成，是**谈成了但违规**。任何涉及"收入、回报、躺赚、零风险、回本"的表述，一律不出现在学员端——学员自己发出去的，本包不提供。

🟢 **理论锚点**：伙伴轨道的90天设计锚定"90天是新人存活的关键窗口"（行业普遍规律：大量参与者在最初几个月退出）——所以本包把 90 天拆成里程碑，而不是承诺一年。🔴 **失效边界**：这是**行业观察**不是铁律，具体窗口因赛道、品牌、陪跑强度而异；学员必须按自己的真实情况调整（🔴 学员把90天当承诺说出去=违规）。
