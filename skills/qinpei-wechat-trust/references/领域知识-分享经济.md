### 💼 领域五：分享经济 · 直销/微商/社交电商创业

**核心定位**：不讲"拉人头"，讲"经营人"——让朋友圈看起来像事业伙伴，不像推销员。

**创业者的5个核心认知（朋友圈底层逻辑）：**

| 核心认知 | 朋友圈标题角度 |
|:---|:---|
| 经营人 > 经营流量 | ①"朋友圈不是柜台，是客厅——没人想在柜台交朋友"（认知升维）②"你以为是卖货，其实是帮人——帮到了，成交是顺便的事" |
| 线上养客，线下成交 | ①"别让客户在朋友圈就决定'不买了'——线上做朋友，线下做成交"（认知升维）②"朋友圈只有一个角色：让客户还没见你，就已经信任你" |
| 利他心态是最大的商业模式 | ①"不卖货，卖'我也想像你这样'"（事业轻感）②"帮了100多个人之后我明白：最好的销售是不销售" |
| 创业不是割韭菜，是种树 | ①"三个月就想躺着赚钱的，最后都回去上班了——慢就是快"（认知升维）②"你帮过的每一个人，都是你未来某一天的'刚好'（过程纪实） |
| 朋友圈即人设 | ①"你的朋友圈就是你的简历——但不是写给别人看的，是活给别人看的"（认知升维） |

**常见客户抗拒及化解（事业轻感/过程纪实的素材库）：**

| 客户说什么 | 你怎么回（朋友圈可用的角度） |
|:---|:---|
| "太贵了" | 不是贵，是你还没看到它能帮你省多少  → 发一篇"算账式"朋友圈：感冒一次花多少 vs 一年调理花多少 |
| "我没时间" | 你不需要每天一小时，需要一个"不可能做不到"的最小动作  → 发一篇"1分钟养生法"合集 |
| "我不信这些" | 你不需要信我，你需要信你自己的感受  → 发一篇"过程纪实"："我自己试了三个月才敢推荐" |
| "我老公/老婆不同意" | 带TA一起来了解，不买也没关系  → 发一篇夫妻一起调理的温情故事 |
| "我试过了没用" | 不是你不行，是方法没对上你的体质  → 发一篇"为什么同样方法有人管用有人不行"的认知文 |

**创业心态金句库（可直接用在朋友圈结尾）：**
- "你不是在卖产品，你是在帮人少走弯路。"
- "慢就是快——种一棵树最好的时间是三年前，其次是现在。"
- "线上做朋友，线下做成交——顺序不能乱。"
- "信仼像存钱，每一条朋友圈都是一次存款。"
- "不要追着客户跑——把自己活成别人想成为的样子，客户会来找你。"

**🔬 领域五 · 深度知识触发（当学员说"写深一点"/"更专业些"时调用）：**

| 话题 | 可调用的深层知识 | 朋友圈安全化表达 |
|:---|:---|:---|
| 为什么"朋友介绍"比广告管用 | 信任转嫁——人对熟人的信任会自动延伸到他推荐的人/产品 | "你花10万打广告不如你闺蜜说一句'这个真的好用'。朋友圈做的就是这件事——让每个客户变成你的'闺蜜推荐'" |
| 为什么优惠券不如"只给朋友" | 损失厌恶——人对"错过"的痛苦远大于"得到"的快乐；稀缺效应——限量的东西更有价值 | "别在朋友圈发'限时优惠'——那是超市促销。发'我帮你们留了三份，手慢就等下一批'——这才是朋友" |
| 为什么有人发得多反而被屏蔽 | 社交过载——单方面信息轰炸触发防御机制→降低信任 | "一天五条广告不是勤奋，是在透支信任。每条朋友圈都是一次'敲门'——敲太多次别人就装不在家了" |
| 为什么AI能帮到分享经济从业者 | AI不是替代人，是帮人把"重复劳动"自动化，腾出时间做"只有人能做的事"（深度链接、情绪价值） | "AI帮我写文案不是偷懒——是让我把省下来的时间，去陪客户聊一小时天。文案AI能写，但'被人真心关心'的感觉，AI写不出来" |
