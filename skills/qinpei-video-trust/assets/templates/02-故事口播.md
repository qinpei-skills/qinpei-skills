# 模板02 · 故事口播（AI 生成前必加载本模板）

> **这一格干什么用**：故事是最快的信任构建器——观众听完一个真故事，对你的信任顶得上看十条干货。适合讲：自己踩过的坑、走过来的路、辟过的谣。
> **双版本规格（默认双稿齐出，学员指定单版才单出）**：
> - 📱 **60秒内版**：约240字（上限260）——故事只留骨架：代价/低谷画面 → 转折 → 现在的看法
> - 🖥️ **3分钟中视频版**：约700字（上限750）——故事讲肉：加"当时怎么想的""试错的弯路"两层细节，转折那一刻展开讲
> - 故事格比价值观格长，但**一个故事只服务一个道理**。
> **三小格**：踩坑（过来人避坑）/ 逆袭（走过低谷）/ 破谣（打破流行说法）。
>
> **v0.2 结构变更**：① 人设句紧跟开头（"那时我做这行第X年"式，紧跟代价/画面句）；② 结尾必留钩子，钩子必问学员、永不代编（见 SKILL.md 钩子档位表）。

---

## 先选小格（学员的一句话判断法）

| 学员说 | 选哪格 |
|:---|:---|
| "我当年信过一个错误的做法/买错过东西/走过弯路" | → 踩坑 |
| "我从很低谷的状态走到今天" | → 逆袭 |
| "现在流行一个说法，其实是错的" | → 破谣 |

> 拿不准 → 都让学员用一句话讲讲大概，AI 帮选。

## 小格A · 踩坑故事（过来人避坑）

**结构**：我当年信了什么 → 付出了什么代价 → 现在怎么看（+别人还在踩）

1. **【开头】代价先行**（不要从"想当年"开始——从疼的地方开始）：
   - `我为一句"趁年轻多扛扛"，扛出了【填：真实代价，用场景词不用病名，比如"整整一年早上醒不来"】`
2. **【人设句·紧跟开头】**（紧跟代价句，一句立住你是谁）： 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】，禁只报年头。
   - `那时我做养生才第【填：X】年` / `那会儿我刚入行，【填：当时的身份处境】`
3. **信了什么**：当时那个错误认知原话是什么：
   - `那时候我真心觉得【填：当年的认知，比如"身体的事忍忍就过去了"】`
4. **转折**：什么事让你醒了：
   - 【填：转折事件，一个具体瞬间最好】
5. **现在怎么看**（认知反转，一句收）：
   - `现在我明白了：【填：一句话道理，比如"身体不是扛出来的，是养出来的"】`
6. **【收尾】照见观众 + 钩子 + CTA**：
   - `如果你现在还在扛，这条视频就算没白发。关注我——【填：钩子，你真有的才算数，比如"我踩过的坑还有一箩筐，下一条讲XX"】`

**示例骨架**：

我为了"省钱"两个字，白扔了三年的功夫。【开头·代价】

那时我做养生才第【填：X】年，自己就是最不信养生的那个。【人设句·紧跟】妈妈让我早点睡，我觉得矫情；让我泡泡脚，我嫌麻烦。那时候我真心觉得：身体的事，忍忍就过去了。【信了什么】

直到【填：转折事件——比如"有天蹲下来给孩子系鞋带，站起来眼前黑了好几秒，孩子问我妈妈你怎么了"】。【转折】

现在我干了这行【填：X】年才明白：身体不是扛出来的，是养出来的。你现在怎么对它，它二十年后就怎么对你。【现在怎么看】

还在硬扛的姐妹，这条视频没白发。关注我——【填：钩子，你真有的才算数，比如"下一条讲我入行第一年交过的最贵的学费"】。【钩子+CTA】

**（60秒内版约240字；3分钟版在【信了什么】后加一层"当时怎么想的"内心戏、转折那一刻放慢展开。约700字。【填】处必须学员真实经历，AI 不得代编——编的故事观众闻得出假味；钩子同理，AI 不得代编承诺。）**

## 小格B · 逆袭故事（走过低谷）

**结构**：低谷状态 → 转折点 → 现在的状态（+拉观众一把）

⚠️ **本格高合规风险**：涉及"身体变好"的逆袭，必须过案例铁律——**只讲过程与感受，不讲功效结论与数字**。

1. **【开头】低谷画面**（场景词，禁病名）：
   - `三年前的我，是连楼都不敢爬的人——不是懒，是真的上三层楼就得歇一次`
2. **试错的弯路**（增加真实感，别跳过）：
   - 【填：试过什么没用的，一笔带过】
3. **转折与动作**（重点段：做了什么，一样一样讲）：
   - 【填：具体的动作清单——调了作息/换了吃法/坚持了什么外治法。⚠️ 只列动作，不说"所以就好了"】
4. **现在的状态**（感受式，禁因果）：
   - 【填：现在的主观状态——"现在周末能陪孩子爬一整座山"。🔴 禁："调好了/根治了/X个月见效"】
5. **【收尾】给观众递手 + 钩子 + CTA + 软声明**：
   - `如果说低谷里的姐妹我能递一句话：别追求一步到位，先把一件小事做一百天。每个人情况不一样，我讲的只是我自己的路。关注我——【填：钩子，你真有的才算数】`

**合规红线回抄**（本格生成后 AI 逐条对）：
- 🔴 病名+指标数字（"血压160降到120"）→ 不出现
- 🔴 绝对因果（"因为泡脚所以好了"）→ 拆成"做了什么+现在感受"
- 🔴 "调理好了/根治/痊愈" → 改状态描述
- ✅ 每条自带软声明："这是我自己走过的路，每个人情况不一样"

## 小格C · 破谣故事（打破流行说法）

**结构**：流行说法 → 为什么不对（拆给观众看）→ 靠谱的做法是什么

1. **【开头】把流行说法钉出来**（判断句钉，不用疑问句）：
   - `"多喝热水"这四个字，是最贵的一句养生建议`
   - `都说【填：流行说法，比如"红枣补血"】，我查了这么多年资料、也见了这么多客户——这话得拆开说`
2. **【人设句·紧跟开头】**（紧跟钉说法句，一句立住你是谁）： 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】，禁只报年头。
   - `我做这行【填：X】年，这话我听过不下【填：真实次数/频次】遍`
3. **它为什么不对**（拆解，给认知增量）：
   - 【填：拆解逻辑——说法里对的部分先承认（先立再破），错的部分指出来】
   - `这话不是全错，错在【填：错在哪，比如"把它当万能答案，反而耽误了找真正的原因"】`
4. **靠谱的做法**（给替代动作，不是只拆台）：
   - 【填：一个更靠谱的方向/动作，落到生活语言】
5. **【收尾】金句 + 钩子 + CTA**：
   - `养生这事，最贵的学费是"听一半"。关注我——【填：钩子，比如"这种流行话我手里还有一沓，下一条拆XX"（你真打算拆的才算数）】`

**示例骨架**：

"多喝热水"这四个字，可能是最便宜也最贵的养生建议。【开头】

我做这行【填：X】年，这话听过不下【填：真实频次】遍。【人设句·紧跟】便宜在哪？不要钱。贵在哪？它让太多人把"该去看的原因"拖成了"忍一忍就算了"。【填：一个真实见闻——比如"我见过太多姐妹，难受了大半年，对策就是喝热水"】这话不是全错——水当然要喝。错在它成了万能答案：睡不着，喝热水；没力气，喝热水。真正的原因，一次都没被找过。【拆解】

下次身体给你递话，先别急着端杯子，先问它一句：你到底想说什么？【填：一个具体方向，比如"把这三个月的作息和吃法写下来看一看"】【靠谱做法】

养生这事，最贵的学费是"听一半"。关注我——【填：钩子，你真打算拆的才算数】。【钩子+CTA】

**（60秒内版约240字；3分钟版加一层"这话为什么能流行开"的拆解+第二个真实见闻。约700字。破谣格是科普格里最稳的形态——只拆说法不讲疗效，零功效风险。）**

## 故事格通用规则

1. **一个故事一个道理**——道理超过一个，砍掉次要的（下次再讲）。
2. **人设句紧跟开头**——代价/低谷画面句后第二句就立住"那时我是谁"，不拖到故事中段。
3. **结尾必留钩子，钩子必问学员**——"我踩过的坑一条条讲给你"这种可持续承诺，先确认学员真打算做系列才写；🔴 AI 永不代编钩子（编了学员兑现不了，观众落空就取关）。
4. **细节即信任**：【填】位填得越具体越好（时间、地点、一个动作、一句原话）——AI 给的填写引导要教学员"回到那个画面里，把看到的写下来"。
5. **禁演苦情**：低谷讲事实不卖惨（"上三楼歇一次"是事实，"我这命太苦了"是卖惨）——卖惨掉粉，事实圈粉。
6. **细节不对称（R4 防对号入座）**：故事里离开的人/被批评的人零细节；留下的人/帮过你的人写最小真实细节（一句原话、一件小事）——细节是可信度的燃料，控制流向。
7. **情绪段必须跟决定（R5）**：每段情绪之后跟一个"我/她做对了什么决定"——观众带走的不是"好惨/好励志"，而是"在XX时刻做了XX决定"。自我感动与观众代入的分界线。
6. **故事循环改编**：每个学员备 5 个核心故事（踩坑2+逆袭2+破谣1），同一故事可换开头句式改编重拍（换钩子不换内核）。

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 开头是代价/画面/钉住说法，不是"想当年/今天讲讲"？
- [ ] **人设句紧跟开头了吗（第二三句内）？**
- [ ] 小格选对了吗（坑/谷/谣）？
- [ ] 所有【填】位都有引导？AI 零代编？
- [ ] **结尾钩子是学员真有的东西吗？**（AI 没有代编任何承诺？）
- [ ] 逆袭格过了案例铁律四条回抄？（无病名数字/无绝对因果/无功效结论/带软声明）
- [ ] 全稿口语？长句已砍短？
- [ ] 收尾 CTA 在最稳档？
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 版本对版吗？（60秒内版240字±10% / 3分钟版700字±10%，按学员选的出）
- [ ] 时长标注 + 拍摄提示（故事格提示：讲转折那一刻放慢语速）？
