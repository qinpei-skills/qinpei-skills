# 《展业诊断简报》产出模板（一页纸 · 学员可转发给助教）

> 用法：AI 把诊断结果填入【】占位；**示例列的内容可直接改词即用**；填完对照底部检查清单自查。
> 交付：默认生成 **.docx**（电脑端存桌面并告知路径；手机端降级为"可直接复制的文字版"）。
> 长度铁律：**一页纸**。四根支柱每根只给一句判语，全篇 600 字以内——简报是提醒，不是报告。
> ⚠️ 简报会被学员转发出去，**不出现分数、不出现内部术语**（详见底部检查清单）。

## 二、你的四根支柱（每根一句，说人话）

| 支柱 | 立住程度 | 判语（一句，具体到他的业务） |
|:---|:---|:---|
| ① 链路 | 【立住了 / 半立 / 还没立】 | 【填】 |
| ② 定位 | 【立住了 / 半立 / 还没立】 | 【填】 |
| ③ 一体化 | 【立住了 / 半立 / 还没立】 | 【填】 |
| ④ 新旧融合 | 【立住了 / 半立 / 还没立】 | 【填】 |

**示例（一位断点在链路的学员）**：

| 支柱 | 立住程度 | 判语 |
|:---|:---|:---|
| ① 链路 | 还没立 | 客户加进来之后没有固定动作，基本靠想起来才聊两句 |
| ② 定位 | 立住了 | 一句话能说清帮谁解决什么，朋友一问你答得挺利索 |
| ③ 一体化 | 半立 | 线上聊得不错，但一个月也约不出一个人见面 |
| ④ 新旧融合 | 半立 | 工具学了不少，能长在自己业务里的还不多 |

> 判语写作三条：① 不许写"数字化能力待提升"这类空话 ② 立住的那根也要写，让他知道自己有什么 ③ 不许出现分数和黑名单词。

## 七、给助教的跟进参考（这一栏请转给如意老师）

> 这一栏是给**助教**看的，学员会一起转发过去。措辞要让学员看了也觉得专业、被认真对待——不冒犯、不评判、不像档案标签。

```
【给助教的跟进参考】　　称呼：【填】　｜　诊断日期：【填】

· 学员现状　　【一句话：什么水平、什么阶段、手上大概有多少客户/伙伴】
· 明显强项　　【一句：可以先肯定他的地方，助教开场用】
· 沟通切入点　【一句：从什么话题聊进去最自然——从他的断点现象切入，不要从产品切入】
· 建议给什么　【技能包名 + 一句为什么他需要这个】
· 跟进节奏　　【3 天 / 7 天 / 14 天各做什么，见下方节奏库】
· 注意点　　　【情绪状态、行业信心、合规提醒等；没有就写"无"】
```

### 跟进节奏库（按断点选，写进简报时压成一行）

| 时间 | 动作 | 目的 |
|:---|:---|:---|
| **第 3 天** | 只问一句"那件事做了吗？"——**不谈产品、不谈价格** | 看她动不动手。动手率是后面能不能谈深度的唯一依据 |
| **第 7 天** | 让她发一下做出来的东西（发的朋友圈/约的人），**给一次具体反馈** | 用专业感建立信任，让她觉得"有人真在带我" |
| **第 14 天** | 动手了 → 顺着她的新卡点聊下一步（此时才自然过渡到深度需求）；没动手 → 不推，换更小的动作再试一次 | 升单只在"她已经动了"之后发生 |

### 注意点的三种典型情况

| 情况 | 写进简报的话 |
|:---|:---|
| 行业信心低（新旧融合没立 + 情绪低落） | 先别给方法，先给信心——她需要的是"这行还能做"的确认。 |
| 客户资源多但不动（存量沉睡） | 不缺人，缺动作。给她最小动作，别给新工具。 |
| 新人（加入不久、还没客户） | 先从"让人看懂你是谁"下手，别让她去做成交动作。 |

## 八、底部检查清单（生成前逐条自查）

- [ ] 全篇 600 字以内，一页纸放得下
- [ ] 四根支柱都写了，每根只有一句判语
- [ ] 主断点**只给了一根**
- [ ] **没有出现任何分数**（"我多少分"这类一律不写）
- [ ] **没有出现内部术语**：数字化三问 / 看得清 / 复制得了 / 放得大 / 5 维度 / 年份（2015、2018、2022、2026）/ 数字化体检 / 业务体检
- [ ] 最小动作是一句话、当天能做的，不是"提升 XX 能力"
- [ ] 第七栏（助教参考）六项都填了，跟进节奏写到了具体天数
- [ ] 助教参考里没有评判性、标签化的措辞
- [ ] 无品牌名、无产品名、无疗效/业绩承诺、无编造数字
- [ ] 没有出现学员真实姓名之外的个人敏感信息（不要身份证、住址、银行卡等）
