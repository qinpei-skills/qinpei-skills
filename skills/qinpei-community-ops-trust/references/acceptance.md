# 验收标准 · 产出物合格线（AI 交付前必对照）

> 读取条件：AI 出完每份产出物、交付前，必须对照本表自查；达标才交付。交付时告诉学员"我按×条标准查过，你重点看这几条"。

## 一、产出物合格线

### ① 群公告 / 欢迎语（5 条标准）
- [ ] **价值清楚**：一眼看懂"这个群是干嘛的、我能得到什么"，不模糊
- [ ] **人群对**：口吻、例子、痛点对得上群成员画像（宝妈/老人/上班族）
- [ ] **有动作**：新人进群知道第一步做什么（看什么/回什么/找谁）
- [ ] **不硬广**：无功效承诺、无绝对词、无焦虑话术（过合规底线）
- [ ] **长度合适**：手机一屏能看完，不堆条款

### ② 一周群排期（4 条标准）
- [ ] **覆盖三层信任**：一周内认识你/认可你/信任你三层都有，不只有一层
- [ ] **每条带钩子+行动指令**：内容离业务近，不只养不收
- [ ] **占比合规**：兴趣群产品≤30%、会员服务/垂类打卡≤50%、事业群可高
- [ ] **节奏可落地**：按客户作息给建议时段，密度匹配学员可投入精力（不排"做不到"）

### ③ 群间流转钩子（3 条标准）
- [ ] **轻**：一句话、给价值、不推销，客户不反感
- [ ] **对信号**：钩子对应明确的观察信号（如"问怎么买""连续邀请≥3人"）
- [ ] **有目的**：每条钩子指向明确的下一站（哪类群/哪个动作）

### ④ 群消息 / 互动话术（4 条标准）
- [ ] **像人聊**：口语、有温度，无命令式/通知腔
- [ ] **留钩子**：结尾有自然的下一步动作（私聊/报名/晒）
- [ ] **合规脱敏**：无夸大功效、无绝对词、建议咨询（过底线）
- [ ] **保原意**：改写不跑题、不丢学员要传达的核心信息

### ⑤ 群诊断结论（3 条标准）
- [ ] **量化可解释**：活跃率按公式估算、产出判定走30天窗口，结论写清依据
- [ ] **矩阵正确**：洗/不洗/先救内容判断符合决策矩阵，不因"热闹/冷清"误判
- [ ] **动作落地**：若洗给了5步SOP+洗后分流；若不洗给了激活建议

### ⑥ 事业群带教方案（3 条标准）
- [ ] **分层清楚**：新人/骨干/带头人各有带教重点
- [ ] **链路完整**：招募→培训→带教→出单→表彰五步齐全
- [ ] **本周可执行**：带教时间/话题/流程/预告话术具体到能直接发

## 二、内容饱满度三件套（每份产出物必达）
1. **场景/痛点例子**：先给一个具体场景（让学员一眼知道"这说的是谁"）
2. **可直接用的话术**：逐句、口语化、复制即用（引号括起来，能直接发）
3. **落地动作**：有数字、有顺序、有物料的具体动作

> 自检：从头到尾读一遍——如果某环节只有一句概括（如"加强互动"），**不合格**，必须展开到"能直接照着发"。宁可写得啰嗦，不可写得空。

## 三、返工机制（学员说"不对"就按标准改）
- 学员不满意 → 对照合格线**逐项检查，只改不合格的那一项，不重新生成一版**
- 返工话术：「你指的是哪条？我按标准查了，这条排期产品占比超了（标准是兴趣群≤30%），我调一下，你看行不行」
- 学员说"太像广告/太硬了" → 对照四步改造法/合规清单逐项改

## 四、内容力自检分支（交付后顺口一问）
- 「想再稳一点的话，说『帮我过一遍内容』，我按共鸣/价值/人感三关帮你查一遍。」
- 三关：**共鸣**（群友会不会觉得"说的就是我"）／**价值**（干货够不够）／**人感**（像不像人话、有没有 AI 腔）
- 纪律：只点最该改的 1 条，不列一堆
