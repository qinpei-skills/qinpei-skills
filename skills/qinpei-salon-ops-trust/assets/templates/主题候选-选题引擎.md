# 模板 · 主题候选（选题引擎 · 3 个候选）

> 用法：学员只说赛道，AI 自动补全其余三项，出 3 个候选让学员选。

## 公式：主题 = 赛道 × 人群痛点 × 季节/热点 × 低成本载体

## 起名公式（内置，直接给）：痛点词 + 圈层词（局/夜/会/手作/茶话会）+ 季节/热点

## 3 个候选（每个含：主题名 + 一句话卖点 + 玩法与成本两档）

| 候选 | 主题名 | 卖点 | 玩法/成本 |
|---|---|---|---|
| A | 【填：痛点+圈层词+季节】 | 【填：为什么有人愿意来】 | 低配：0 元 |
| B | 【填】 | 【填】 | 标配：≤15 元/人 |
| C | 【填】 | 【填】 | 低配：0 元 |

- 示例（赛道=脾胃·人群=上班族·季节=秋季）：
  - A「脆皮打工人的养胃局」｜说的就是被外卖掏空的你｜低配：围聊+热茶，0元
  - B「手作陈皮香囊夜」｜带走自己的养胃香囊｜标配：材料≤15元/人
  - C「入秋养胃茶话会」｜换季胃不舒服的姐妹局｜低配：茶话会，0元

## 成本硬约束（每个候选必带）
- **低配**：零成本（围坐聊天 + 一杯茶，家里就有）
- **标配**：≤15 元/人（香囊/茶包/扇子等 DIY 材料，拼多多可买）

## 低成本载体清单（AI 内置选用，防学员卡在"不知道玩什么"）
香囊手作 / 养生茶包DIY / 团扇画 / 节气食疗试吃 / 体质小测（MBTI式自测卡）/ 艾灸体验 / 泡脚方分享 / 拍立得打卡 / 书签抄方——**载体只选 1 个，与主题强相关，物料≤15 元**。

## 合办场景
学员说"我们几个一起/团队合办" → 每个候选附一句「分工 + 成本 AA 建议」（轻量一句，不展开）。

## 检查清单
- [ ] 3 个候选（主题名 + 卖点 + 玩法 + 成本档）
- [ ] 至少 1 个低配（0 元）
- [ ] 主题名符合起名公式（痛点+圈层词+季节/热点）
- [ ] 成本 ≤15 元/人（标配）
