# 分诊与双轨判定 · 五问分诊全表 + 轨道信号表

> 状态：v1.0.0-dev（首版）｜证据等级：🟢实证（有真实档案支撑）／🟡演绎（结构可用、话术需换学员自己的话）／🔴空白（v1 不装）
> 🔴 使用顺序铁律：**先定轨道 → 再分诊 → 才谈方法**。轨道判错，后面全错。

## 一、为什么必须先定轨道（本包第一硬化）

> 依据：直销行业现实数据 —— 首年流失>50%、5年流失>95%、90天是关键窗口、99%参与者零收入或亏损。
> 这意味着：**伙伴不是靠话术招来的，是靠90天陪跑带出来的**；而零售客户根本不关心这些。
> 🔴 同一个团队长的微信里，两类人天天混在一起。轨道不分的代价不是"效率低"，是**该签的人没签、不该签的人被签进来**。

| 维度 | 轨道A · 零售客户 | 轨道B · 事业伙伴 |
|---|---|---|
| 她要什么 | 一件东西（产品/服务） | 一件事（一起做这事） |
| 决策人 | 她本人 | 她＋家人＋团队＋资金 |
| 核心驱动 | 怕痛、怕麻烦、熟人信任、怕被坑 | 算账、身份想象、90天承诺感、怕丢脸 |
| 时间尺度 | 这一单 | 这一年 |
| 典型异议 | "太贵了""我再想想""我先问问孩子" | "我能赚多少""万一做不下去""我怕我不行" |
| 关键证据 | 体验、感受、熟人证言 | 时间表、里程碑、退出机制 |
| 🔴 绝对禁语 | 讲事业/分红/团队规模 | "稳赚""月入过万""零风险""躺赚""回本" |
| 收口形态 | 下单/加量/复购 | 加入+90天里程碑+首周动作 |

## 二、轨道判定信号表（看哪三个信号）

> 🟢 实证依据：案例深挖笔记库中的零售/伙伴场景对话特征差异。

| 信号 | 轨道A（零售客户） | 轨道B（事业伙伴） |
|---|---|---|
| 她问的问题 | "这个多少钱""怎么用""有没有副作用""能退吗" | "我能赚多少""什么时候能上手""需要什么条件""万一做不下去呢" |
| 她带来的 | 自己/家人要买 | 想问团队/朋友要不要一起做 |
| 她关心的单位 | 一件产品/一次服务 | 一年/一个季度的路径 |
| 她的身份 | 顾客、粉丝、熟人 | 想做经销商/合伙人/代理的人 |
| 她说的话里有 | "我先自己用" | "我想让身边的人一起" |

**判定规则（三条，取多数）**：
1. 三个信号里有≥2个落在同一轨道 → 按该轨道走
2. 信号不足 → **问一句**（不是猜）：「她是想买这个东西，还是想跟你一起干这事？」
3. **学员明确说是零售但话里带事业词**（如"客户说想代理我的产品"）→ 🔴 问清楚她的身份：自己是买还是想带人买？**买自己用 = 轨道A；想带人 = 轨道B**（这条最容易混，混了就全盘错）

## 三、混轨检测清单（M12，出稿前逐句扫）

| # | 检查项 | 触发动作 |
|---|---|---|
| 1 | 轨道A的稿里出现 合伙人/分红/事业/招募/代理/团队规模 | 全部换成产品语言（"用起来怎么样""家里人在用吗"） |
| 2 | 轨道B的稿里出现 收益承诺/回本周期/零风险/稳赚/躺赚/被动收入 | 🔴 全部删掉，改成"能拿到什么支持""三个月里会有什么动作" |
| 3 | 轨道A里出现"你也来带人"式暗示 | 删——零售客户面前提事业=污染关系 |
| 4 | 轨道B里出现"这个产品效果很好"式产品话术压过事业对话 | 保留产品信息但**不作为说服主线**——她要的是路径不是产品 |
| 5 | 全篇没有一句说明"我们是什么关系" | 补一句身份锚（"我是做XX的"），不说明关系=信任无从建立 |

**混轨检测的判定口径**：一句话同时可读成两轨 → 判为混轨，**改成只能读成一轨的表达**。

## 四、五问分诊全表（L1，每轮开头静默自答）

> 🟢 实证依据：1对1咨询交付板块的两批六场实战（8/26、9/29 两批验证）。

### 问1 · 她现在到哪一步？
| 阶段 | 识别标志 | 该做的事 |
|---|---|---|
| 0 未聊过 | 只加好友没说过话 / 你主动问过没回应 | 破冰：给一个跟"她能得到什么"有关的开口 |
| 1 聊过没深聊 | 打过招呼、问过价格就跑了 | 挖事实：她真正在意什么 |
| 2 在比价 | 同时在问别家 / 说"太贵" | 算账 + 换比较维度 |
| 3 已问怎么买 | 问"在哪买""怎么付款""有没有优惠" | 🔴 这时候不是继续讲产品，是**给最小动作**（先来一次/先试一档） |
| 4 买过一次 | 有过成交 | 复购/唤醒：价值前置+弱连接 |
| 5 买过但闲置 | 买了没用起来/没用完 | 激活：先问为什么没用起来 |

### 问2 · 这单多大？
- **小额零售**（单次消费）→ 🔴 别硬套大单方法，直给+复购钩子
- **大额套餐**（疗程/周期/年度）→ 用三层提问法+落锤
- **长期合作**（伙伴/代理/团队）→ 走轨道B，90天里程碑
- 判不出 → 问一句：「她这次大概打算花多少？」

### 问3 · 她是谁？
新客 / 老客 / 客户的熟人 / 潜在伙伴 / 老客介绍的伙伴 —— 这决定**证据怎么给**（老客证言 > 机制说明 > 品牌介绍）。

### 问4 · 她什么情绪？
警惕 / 犹豫 / 着急（好信号，但别被带节奏）/ 不屑 / 有点信了 / 有点生气（被之前的人伤过）。
🔴 **着急的客户容易被逼单**：她急 ≠ 你该催，可能她在赶时间但还没想清楚。

### 问5 · 这轮的具体下一步是什么？
要约时间 / 要资料 / 要试一次 / 要她拍板 / 要她转介绍 —— **说不出具体下一步 = 这轮没设计，白聊**。

### 三道状态门（🔴 违反即停）
| 门 | 状态 | 🔴 禁止 |
|---|---|---|
| 事实未清 | 她要什么、预算多少、之前用过什么都不知道 | 不许谈方案报价 |
| 选择未定 | 她要不要做、做哪个还没定 | 不许催成交 |
| 假设未立 | 她为什么信你、想成为什么样的人还没立 | 不许谈长期合作 |

## 五、轨道B 判定后的分流（详见 partner-track.md）

判定为轨道B后，🔴 三条硬规矩：
1. **先谈她怕什么，不谈收入**（收益承诺是永久禁区，X1）
2. **必须给退出标准**（90天内什么情况可以退出）——不谈退路＝招来的是被套路的人
3. **必须给90天里程碑**，不是"以后会更好"

## 六、场景 × 输入 路由表（L0）

| 学员给的 | 判定 | 第一动作 |
|---|---|---|
| 一整段聊天记录 | 诊断模式 | 读出她走到哪步、卡在哪、心结型 → 给下一句该说什么 |
| 一份产品方案/价格表 | 方案诊断 | 判断她看到这页会卡在哪 → 给谈法（不给新方案，除非她要） |
| 一句场景描述（"我同事说她犹豫"） | 补事实 | 一次补2个分诊项（她到哪步+什么情绪）→ 再给谈法 |
| 一句"客户说贵" | 异议 | 轨道判定 → 预防检查 → 心结判定 → 给话 |
| 什么也没给 | 采集 | 问一句"她现在到哪一步了" |

## 七、轨道判定与分诊的失效边界（🔴 判错了，后面全错）

⛔ **轨道判错＝整套打法用错**。这是本包最贵的错误，比说错话严重得多。以下情况判定会失灵：

| 情况 | 🔴 判定会错在哪 | 该怎么处理 |
|---|---|---|
| 她是零售客户，但想顺便拉几个姐妹一起买 | 像轨道B（谈事业） | 🔴 判轨道A，只是在方案里加一句"你要转给谁"，🔴 禁讲事业/收益 |
| 她是老客，但这次来问"能不能代理" | 像轨道A（买产品） | 问一句就清楚："你是想自己用，还是想跟着我做"——**她答什么就按什么走** |
| 她是被团队长拉来"了解下"的（可能是合伙人候选） | 像零售 | 问她的**身份和目的**而不是猜：听她关心的是"这东西好不好"还是"这事能不能做" |
| 她自己也不知道要不要做 | 判不出 | 判定为**轨道A + 未定型**，走零售流程，别急着上轨道B |
| 学员自己也没说清 | 判不出 | 🔴 问学员一句（就一句）："她是想买东西，还是想跟着你一起干？" |
| 她只是替朋友问价格 | 像零售但不是决策人 | 事实层要问"最后是谁定"——决策人换了，方案和落锤对象都要换 |
| 她同时有"我想赚点"的想法但主要为自己用 | 混轨 | 🔴 混轨检测：只要她主要为自己用→轨道A；把"顺便赚点"当**想法**存起来，不在第一轮谈 |

🔴 **判定优先级**：🔴 **先问身份，再判轨道；轨道不明，先走轨道A**（零售流程更保守，不会踩合规线）。问一句的成本远低于判错一次。

🔴 **分诊三道状态门的失效边界**：状态门是**停止条件**不是**推进条件**——过了门不代表该往下推，还要看她这一步的**情绪水位**（刚发火、刚冷淡、刚问价三种状态下，问事实层都可能踩雷）。
