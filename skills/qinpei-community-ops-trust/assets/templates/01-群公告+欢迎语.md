# 模板 · #1 群公告 + 欢迎语（五要素 + 破冰钩子 A-E + 建群节奏）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。

## 一、群标配要素三大模块（先想清楚，再出文案）

**① 价值定位**（这个群为谁、解决什么问题）
- 一句话群价值：【填：如"帮产后妈妈用对减脂方案，不饿肚子瘦下来"】
- 自问：如果群友只记住一句"这个群对我有啥用"，应该是哪句？

**② 人群定位**（什么人、从哪来）
- 适合标签的人：【填：2-3个共性标签，如"已购减脂包/产后1年内/试过节食失败"】
- 从哪来：【填：朋友圈/转介绍/线下活动扫码…】

**③ 功能描述**（输出什么内容、什么节奏、什么角色）
- 输出内容：【填：每周固定栏目，结合六大维度/三层信任，不硬广】
- 运营节奏：【填：周几发、每天几条】
- 角色分工：【填：默认不分工（1-2人运营）；核心团队>5人且群>5个才设主运营+气氛组】

## 二、群类型确认（五类群选一）

【填：兴趣群/会员服务群/垂类打卡群/养伙伴围观群/事业群】+ 一句话理由
- 示例：「兴趣群——你的老客里有已购也有未购，先建兴趣群作统一入口，不踢人，靠价值递进流转」

## 三、群公告（服务谁/提供什么价值/如何提供价值）

```
【本群是什么】【填：如"XX养生交流群，每周分享中医调理干货，帮大家少走弯路"】
【你来得到什么】【填：如"每周三养生小课堂、每周六真实案例分享、不定期福利"】
【群规】【填：如"不发广告、不私加群友、友好交流"】
【进群动作】【填：如"发一条自我介绍（你是谁+最想改善的养生问题），群主送你一份见面礼🎁"】
```

## 四、欢迎语五要素

1. **群是什么**：【填：一句话价值】
2. **群核心内容**：【填：每周固定栏目】
3. **群规和群文化**：【填：如"不发广告、不私加人、友好交流"】
4. **群价值确认**：【填：再强调一次加入能得到什么】
5. **引导动作**：【填：欢迎新人+引导自我介绍/领福利】

## 五、破冰钩子（A-E 五版选一个，按产品/客群选）

| 版本 | 钩子内容 | 适合场景 | 话术示例（可直接套） |
|:---|:---|:---|:---|
| A 一对一咨询 | 自我介绍后免费私聊答疑/出方案 | 咨询服务型（中医体质/营养/护肤） | "进群发一条自我介绍，我抽 3 位免费做 1 对 1 体质分析 👇" |
| B 免费体测/体验 | 自我介绍+到店领免费检测/体验装 | 有线下或实物产品 | "自我介绍+你最想改善的问题，到店免费体测一次（限前10名）" |
| C 小礼物/样品 | 自我介绍领实物小样/养生茶包 | 有低成本实物赠品 | "发自我介绍就能领一份养生小礼包，群主私你地址📦" |
| D 活动名额 | 自我介绍优先锁定线下沙龙/体验席位 | 有活动承接 | "本周六申时茶会，自我介绍报名优先留座，仅8席" |
| E 资料/工具包 | 自我介绍领电子干货（自查表/食谱） | 纯线上、零成本（新人首选） | "发自我介绍，私你一份《体质自查表》电子版，自己就能测" |

**选钩子3原则**：①成本可控（新人优先 E 或 A）②和群目的挂钩 ③限时限量（"前10名/本周有效"制造稀缺）

## 六、建群节奏表

| 时间 | 动作 | 说明 |
|:---:|:---|:---|
| 第1天 | 发欢迎语+公告 + 引导3-5人自我介绍破冰 | 用"发一条自我介绍+领钩子福利"降低门槛 |
| 第1周 | 密集破冰：每天3-5个低门槛话题+小额福利 | 前14天活跃率>40%=破冰成功 |
| 第2周起 | 进入固定栏目节奏（用模板02排期表） | 从"破冰"过渡到"价值输出" |

**破冰话题示例**：
- "大家平时最困扰的亚健康问题是什么？投票👆"
- "一句话介绍自己+你的养生小习惯"
- "猜猜今天分享的主题？提示：和'寒'有关"

## 检查清单（AI 交付前对照）
- [ ] 三模块（价值/人群/功能）齐全，先想清楚再出文案
- [ ] 群公告含：本群是什么/你得到什么/群规/进群动作
- [ ] 欢迎语五要素齐全
- [ ] 破冰钩子从 A-E 选了一个（按学员产品/客群匹配）
- [ ] 建群节奏表给到（第1天/第1周/第2周起）
- [ ] 无功效承诺、无绝对词、无焦虑话术
- [ ] 手机一屏能看完，不堆条款
