# 画像写入细则（诊断完成后执行，两处同时写）

> **什么时候读这个文件**：诊断完成（**含劝退结论**）后。正常诊断写定位画像；学员被劝退 → 写下面的「劝退档案」。**先征得学员同意再写**（见下）。写完一句话带过，不把文件内容念给学员听。

---

**写之前先确认**："我把你的定位存下来，以后你再来、或者用其他功能，我就不用重新问你了，好吗？"（学员同意才写；这是必做动作，但要说一声。）

## ① 用户级记忆（`~/.workbuddy/MEMORY.md` · 让画像在任何会话里自动被读到）

- **先 Read 整个文件**，找到 `<!-- qinpei-profile:start -->` 与 `<!-- qinpei-profile:end -->`。
- **已有标记块** → 只替换块内内容，块外**一个字都不动**。
- **没有标记块** → 追加到文件末尾（不插入、不改动任何既有内容）。
- 写入内容（精简版，控制在 15 行内）：

```markdown
<!-- qinpei-profile:start -->
## 我的IP画像（沁珮技能包通用）
- 你是谁：做大健康5年，主营中草药保健品
- 帮谁：产后妈妈
- 你凭什么：结果背书——服务过100多个产后妈妈
- 你给什么：产后气血+身材调理的方法
- 行动引导：想要自测表评论区扣1
- 一句话定位：用中草药+外治法，解决产后妈妈的气血和身材问题
- IP类型：陪伴型60% + 工具型40%
- 表达基因：过来人型｜专业+直接+清单｜永不说：承诺疗效/晒收入/贬同行
- 获客目标：顾客为主｜链路断点：承接（私信24小时内回）
- 变现方式：卖产品+办卡套餐
- 避讳：不出现XX品牌名/敏感词
<!-- qinpei-profile:end -->
```

（上面是模板示例——写学员的真实内容，不照抄示例数字。）

## ② 共享画像（`~/.workbuddy/skills/qinpei-profile/我的画像.md` · 详细版，供沁珮其他技能包共享）

- 文件**已存在** → 只更新对应字段（补四要素、类型），**不删除学员原有内容**。
- 文件**不存在** → 新建，按 qinpei-profile 的标准格式写入（基础信息 / 引流钩子 / 风格偏好 / 文案类型偏好 / 免打扰设置）。
- ⚠️ 学员说"重新填"才覆盖画像；否则一律**增量更新**。

## ②.5 劝退档案（v4.1.0 · 学员被劝退时写这个，不写定位画像）

学员走了 SKILL.md 三.4（4）劝退路径 → 画像**不写定位四件套**，改写**劝退档案**。四处字段一个不许少：

```markdown
<!-- qinpei-profile:start -->
## 我的IP画像（沁珮技能包通用）
- IP状态：**暂缓IP**（2026-XX-XX 诊断结论）
- 劝退原因：【一句话，来自诊断时的具体判定，如"业务未跑通：无稳定客户、无内容积累"】
- 三个月要攒的三样东西：①【与学员共同定下并确认过的】②【】③【】
- 复查日期：【绝对日期，如 2027-01-20——当天 + 3 个月】
<!-- qinpei-profile:end -->
```

- **复查日期必须写绝对日期**（当天 + 3 个月），🔴 禁止只写"三个月后"——没有日期，三个月后谁也无法触发复核。
- 三样东西必须是**可验收的具体项**（"3 个稳定客户"可以，"把业务做好"不行）——这与 SKILL.md 三.4（4）的劝退前必做联动。
- **共享画像（②处）同步**：在对应文件加一行"IP状态：暂缓IP（复查日期 X）"，不建详细定位档案。
- **复访识别（与 SKILL.md 〇节联动）**：学员之后再来做诊断，读到「暂缓IP」标记 → 先复述劝退原因和三样东西、逐项验收，全过才进正常诊断；缺哪项先补哪项。

## ③ 写完的反馈话术（一句话，不念内容）
> "你的定位我已经记下来了，下次直接来找我就行，不用重新讲一遍～"
> （劝退档案版）："今天先不急着做 IP——**咱们约定好了：三个月后 X 月 X 日，你带着【三样东西】回来找我，咱们再验一遍。** 到时候见。"
