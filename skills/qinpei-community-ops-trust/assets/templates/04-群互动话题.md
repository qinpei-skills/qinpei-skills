# 模板 · #4 群互动话题（互动五步骤 + 话题库 + KOC识别）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。

## 一、互动五步骤（用于固定栏目和日常激活）

```
1. 前一天预告 → 2. 提前2-6小时预热 → 3. 主题互动（抛出话题）
   → 4. 结束后总结答案 → 5. 第二天促进行动
```

## 二、好话题 3 特征 + 话题库

**好话题3特征**：①具体场景（人人都能对号入座）②人人可答（不需要专业知识）③自然带出专业（你做"总结者"轻轻植入知识点）

**可套用的话题模板**（按群类型/赛道选）：
- 投票型：【填："秋天你最怕哪种不适？A 干咳 B 皮肤干 C 睡不好（投票👆）"】
- 晒图型：【填："今天泡了什么养生茶？晒出来我帮你看看体质对不对🍵"】
- 接龙型：【填："一句话说说你今年最想改善的身体问题，接龙走起"】
- 故事型：【填："我有个客户坚持灸了一个月，变化挺明显的，你们想听吗？"】

## 三、互动执行方案（本栏目怎么跑）

- 预告话术：【填："明天周三养生小课堂，主题是【主题】，有问题提前扣1～"】
- 预热话术：【填："还有2小时开聊，先问一个：你最近最困扰的【主题】问题是啥？"】
- 主题抛出：【填：按上面话题模板选一个】
- 总结话术：【填："谢谢大家分享！我把高频答案整理一下：①…②…③… 有想深聊的私信我～"】
- 次日动作：【填："昨天聊的【主题】，今天可以试试【具体动作】，三天后回来说感受"】

## 四、群成员角色识别（找 KOC 带节奏）

| 角色 | 特征 | 你怎么用 |
|:---|:---|:---|
| 强IP/群主（你） | 定调者、内容源、信任锚 | 定调+输出价值+总结，不抢话但镇场 |
| 核心用户/KOC | 活跃、爱分享、有影响力、信你 | **重点维护**：让TA先答、先晒，带动氛围 |
| 普通成员 | 大多数，偶尔互动或潜水 | 互动五步骤激活，别指望人人都聊 |
| 潜水者 | 不说话，但可能默默看、甚至私聊下单 | 别急着踢——"假死群"里藏着产出 |

**KOC 培育小动作**：
1. 【填：私聊问建议："最近群里你带得最好，想请你当个栏目主持人？"】
2. 【填：给特殊感："这周六互动日，你先打个样？"】
3. 【填：公开认可："看，群里第一个交作业的就是XX"】

> ⚠️ **禁用"群托/水军"控评**：零售素材里"群托刷屏、转移负面"属灰色手法，与我们"真实信任经营"定位冲突，全部不用。用核心用户/KOC 真实带动。
