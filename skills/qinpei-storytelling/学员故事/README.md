# 学员故事沉淀目录

本目录存放学员已写过的故事与叙事偏好，供 AI 跨会话复用（「越用越像你」）。

## 文件命名
`<学员标识>.md`（微信昵称/品牌+角色，如「艾灸-王姐」；不存手机号等强隐私）

## 每份档案内容
- 已写过的故事清单（类型+场景+一句话主线）
- 常用叙事风格（如"喜欢转折前置""案例数字要真实标注"）
- 学员偏好（改稿反馈提取）

## 读写规则（两端自适应）
- **电脑端**：AI 用 Read/Write 直接读写本目录
- **手机端**（无法写本地文件）：对话内持续携带故事要点与偏好，开场主动复述确认；或引导学员存腾讯文档（同账号可访问）
- **复用**：下次写故事先查沉淀，不重复问偏好；学员说"我讲过那个故事"→ 直接续写/改写，不重写

## 边界
- 只存必要业务信息与叙事偏好，不存身份证/手机号/住址等强隐私
- 学员要求删除随时可删
