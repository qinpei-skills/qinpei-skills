怎么装（三步）

1点上面任意一个「复制安装指令」，提示「已复制」就行
2打开 WorkBuddy，在对话框里长按粘贴，发送
3手机保持亮屏别切走，等它说「装好啦」，然后说一句话就能开始（每张卡片上有那句）
小提示：装之前建议先把模型切成 DeepSeek，会更快。
装完想再装第二个？回到这页点下一个就行，它们各装各的、互不影响。
已经装过了？一条指令就能升级
1点下面按钮复制指令，粘给 WorkBuddy 发一次（就这一次）
2它自己会把新版取回来换上。以后想升级，直接说一句 「升级到最新版本」 就行，永久有效，不用再回来复制任何东西
放心：升级只换技能本身，你的画像、资料卡和档案原样都在，不会丢，也不用重装。
装不上怎么办
1先说一句「再试一次」——多数是网络抖了一下，重来就好
2还不行，就点那张卡片的备用指令，它绕开一堆中间环节直接下包
3都不行 → 把这句话发给助教：「XX 技能包装不上，试过两条指令了」
