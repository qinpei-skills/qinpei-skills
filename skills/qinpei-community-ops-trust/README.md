# 社群运营提效技能包 · 使用说明（v2.0）

> 帮大健康 / 分享经济从业者，用 AI 把微信群从"广告死群"升级为"信任运营场"。
> 不会写提示词？跟我聊天就行。

---

## 一、这是什么

一个 WorkBuddy AI 技能包。激活后，你用大白话跟 AI 说"我想建个群养客户""帮我排这周群内容""我的群要不要洗"，AI 就自动给你出完整方案——群公告、欢迎语、一周排期、互动话题、事业带教全都有。

**适合谁**：做艾灸 / 减脂 / 视康 / 茶修 / 护肤 / 体质食疗 / 抗衰 / 钙片 / 女性健康……任何需要运营私域微信群的大健康从业者、团队长。

---

## 二、怎么安装

1. 把 `社群运营技能包.zip` 下载到电脑（**仅桌面版 WorkBuddy 支持，Win / Mac，无手机版**）。
2. 打开 WorkBuddy，把 zip 文件**直接拖进对话框**。
3. 发一句："请帮我安装这个技能"。
4. 安装完成后，在对话里说"帮我做社群运营"或"激活社群运营技能包"即可使用。

> 技能包内已**内嵌**朋友圈技能包的核心方法论（六大维度 / 三层信任 / 黄金四段式），**独立可用，不用再装朋友圈技能包**。若你已装朋友圈技能包，两者方法论一致，可配合使用。

## 三、四类群速查（v2.0 核心升级）

建群前先定类型，内容基调完全不同：

| 群类型 | 目标 | 服务对象 | 占比上限 | 生命周期 | 典型 |
|:---|:---|:---|:---:|:---:|:---|
| **① 养客群**（垂类/兴趣） | 养客户 | 未成交/潜在客户 | 产品≤30% | 3-6月封顶 | 养生科普群、瑜伽群 |
| **② 垂类服务群**（打卡/售后） | 已转化客户售后，转化复购/跨品/事业 | 已购买客户 | 产品≤50% | 7/21/90天+可延长 | 7天打卡、21天减脂、90天筑基 |
| **③ 闪群/快闪群** | 短期集中爆破 | 活动/新品/团购流量 | 价值:转化≈6:4 | 3-21天 | 新品快闪、3天体验营 |
| **④ 事业群** | 养伙伴/运营伙伴 | 事业意向者/团队长 | 可高但穿插生活 | 3-6月(可延一年) | 团队长训练群 |

**一句话区分**：养客群让陌生人想认识你；垂类服务群让买过的人更信你、买更多；闪群短时间打透一个点；事业群把用的人变成做的人。

## 四、怎么用（三种姿势）

**姿势一：第一次用 / 不会表达 → 诊断优先**
直接说："帮我诊断一下我的群"。AI 会问 6 个问题（有无群 / 类型 / 画像 / 卡点 / 时间 / 赛道），再出内容。

**姿势二：老手 / 赶时间 → 直接说**
"排下周养客群内容，客户是宝妈" → AI 直接出，跳过诊断。

**姿势三：手动指令 → 文末 B 层**
复制技能包里的「指令 0~6」模板，填空发给 AI，精准产出。

---

## 五、内容产出四标签（双模式，不强制）

每条群内容可带 4 个标签，方便复盘和带教：
- **目标层**：养客 / 复购 / 事业 / 激活
- **信任层**：认识你 / 认可你 / 信任你
- **钩子设计**：投票 / 晒图 / 咨询 / 打卡 / 资料
- **行动指令**：发言 / 私聊 / 到店 / 打卡 / 转发 / 邀约

AI 产出时问你："要带四标签说明吗？还是直接出内容？"——**不强制**，你选。

## 六、赛道案例库（让内容"像你自己写的"）

内置 10 个真实赛道（内测学员赛道去标识化 + 知识库补充）：视康、减脂塑形、茶修、艾灸、护肤、中医体质食疗、气血湿寒、女性抗衰、钙片/骨骼、乳腺健康。诊断时套用，AI 自动按你的行业口吻出内容。
