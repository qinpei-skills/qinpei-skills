## 八类红线速查（每条 = 禁什么 + 怎么改）

### 第 1 类 · 不当承诺（视频号最高频，实拍扣 12 分）
- **禁**：高价回收 / 任务返现 / 课程包学会 / 包你赚到 X 万 / 保证收益 / 无效退款 / 学不会退费
- **改**：删承诺 → 方法论展示 + 结果不确定性说明（"我们学员里有……，但结果因人而异"）

### 第 2 类 · 极限词 / 绝对化用语（《广告法》第九条）
- **禁**：最 / 第一 / 唯一 / 绝 / 绝对 / 100% / 之王 / 专车专用 / 精准 / 顶级 / 独家 / 永久 / 极致 / 完美 / 冠军 / 首选
- **改**：较 / 相对 / 特定条件下 / 某类人群中 / 表现之一

### 第 3 类 · 医疗保健边界（大健康赛道高危）
- **禁**：宣称治疗 / 治愈 / 根治 / 抗癌 / 降三高 / 医生推荐 / 经临床验证 / 替代药物 / 无副作用
- **改**：营养支持 / 辅助改善 / 日常保养 / 草本成分（"体质调理"仅限私域口语，不上视频稿——见 compliance-gate 关1）

### 第 4 类 · 虚假数据 / 炫富
- **禁**：编造月入 / 晒收入截图 / 虚构转化率 / "宣传 30 万单实际 1 万单"式夸大
- **改**：只引学员真实有的数字（对接 M8 数字工作流：【填】机制），无数字用方法论 + 定性

### 第 5 类 · 诱导交易 / 饥饿营销
- **禁**：必须 / 错过就没 / 最后机会 / 再不下单 / 限时秒杀 / "今天不下，明天涨价"
- **改**：客观陈述（"本周报名 200 人"）+ 自然紧迫（"名额有限"），不人为制造焦虑

### 第 6 类 · 引流导流违规（短视频 vs 直播间双轨）
- **短视频**：结尾"关注我 / 主页有资料"为最稳档（见 compliance-gate 关2 CTA 三档）
- **直播间**：🔴 禁口头导流（"加我微信 / 扫码 / 看我主页"）——视频号直播最常踩，限流/中断/封开播
- **改**：直播间留资走平台官方组件（购物车/小风车/企微组件）
- ⚠️ 本 skill 口径从严：**短视频口播也不说"评论区扣1"**（与外部平台 SOP"短视频可用"的差异见下"口径冲突裁决"）

### 第 7 类 · 虚假宣传 / 承诺效果
- **禁**：保证效果 / 无副作用 / 安全无毒 / 任何体质适用 / 包瘦 X 斤 / 三天见效 / 一次根治
- **改**：客观描述（"配合饮食运动可能有助于……"）+ 个体差异说明

### 第 8 类 · 行业红线（按赛道）
- **大健康**：不说治病、不打"祖传/秘方"、不贬低医疗
- **金融/投资**：不承诺收益、不预测涨跌、不"稳赚"
- **教培**：不"包过/包就业/包学会"
- **美容/减肥**：不承诺具体瘦身斤数、不"7 天瘦 X 斤"

## 口径冲突裁决（本 skill 从严项）

| 冲突点 | 外部平台 SOP 原文 | 本 skill 裁决 | 理由 |
|---|---|---|---|
| 短视频"评论区扣1" | 短视频可用（合规路径） | **不用**，统一"关注我/主页有资料" | 视频号短内容生态审核趋严；学员客资走主页/私信更稳；且与关2 CTA 三档保持一致 |

| 极限词双轨制 | 极限词一律禁 | **纯内容口播**：观点修辞中的"最"（如"最灵的报警器"）可保留——不涉商品宣传，《广告法》管辖的是商业广告；**挂车/带货稿**：一律降级（"较灵"或删） | 学员内容分"立人设"与"带转化"两类，一刀切会把正常表达杀光 |

## 交付前 8 问自检（叠加在 compliance-gate 四关之后）

> v0.4.9 起：8 问与四关过闸已去重合并为「交付统一清单」，见 compliance-gate.md 末节——**执行走统一清单，本表保留作八类红线的速查与裁决细节依据**。

| # | 自检问句 | 命中则改 |
|:--:|:---|:--|
| 1 | 有无"包学会/保证收益/无效退款"等不当承诺？ | 删承诺，改方法论+不确定性 |
| 2 | 有无极限词？（纯内容修辞"最"按双轨制判断） | 商品语境一律降级 |
| 3 | 有无医疗表述？ | 改"辅助改善/日常保养" |
| 4 | 有无编造数据/虚构案例？ | 换真实数字或【填】 |
| 5 | 有无"错过就没/最后机会"诱导？ | 改客观陈述 |
| 6 | 有无口播导流（尤其直播间）？ | 短视频走 CTA 最稳档；直播间删口头导流 |
| 7 | 有无效果承诺？ | 改"可能有助于"+个体差异 |
| 8 | 行业底线有无越界？ | 按第 8 类改 |

**重点**：1/2/3/6 是视频号最高频处罚项（有实拍证据），每条必查。
