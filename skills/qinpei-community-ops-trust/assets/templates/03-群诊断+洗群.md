# 模板 · #3 群诊断 + 洗群（活跃度 + 产出判定 + 结论）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。

## 一、采集（先问，一次 1-2 个，已知的不问）

| 维度 | 学员回答 |
|:---|:---|
| 群类型 | 【填：兴趣/会员服务/垂类打卡/养伙伴围观/事业】 |
| 建了多久 | 【填：如5个月】 |
| 群里互动情况 | 【填：热闹/安静/只有我发】 |
| 有没有人私下下单/介绍朋友/加入事业 | 【填：有/无，大概多少】 |
| 手头几个群、精力顾得过来几个 | 【填：如3个群，只能顾2个】 |

## 二、诊断计算（AI 按规则算，不凭感觉）

**① 活跃率估算** = 日均发言人数 ÷ 群总人数
- 学员说"大概X人说话" → 估算：【填：如 5/120 ≈ 4%】
- 等级：【填：≥20%高度活跃 / 10-20%正常 / 5-10%轻度 / <5%低活跃】

**② 生命周期判断**（按群类型）：
- 兴趣/会员服务群：3-6个月（最多不超6个月）
- 垂类打卡群：按7/21/90天周期
- 事业群：3-6个月（可延长至一年）
- 当前群龄：【填】→ 是否到红线：【填：是/否】

**③ 产出判定（30天窗口，量化 · 关键）**：
- 有产出（✅）：成交≥1笔 / 事业加入≥1次 / 有效转介绍≥1次 / 复购≥3人（任一）
- 无产出（❌）：以上全无，且近30天无任何"业务信号"（无人问产品/无报价/无约见）
- 模糊（拿不准）→ 选项式逼问（"最近一个月，群里有人下单或私聊你问产品吗？哪怕一单？"）；仍说不清 → 按保守判定（不算有产出）
- 判定结果写进结论："我按30天窗口判，你有X笔成交/无成交，所以判定为有/无产出"——可解释、可复查、可被学员推翻重判

## 三、诊断结论（按矩阵出结论）

| 互动率 | 有产出？ | 生命周期 | 结论 | 动作 |
|:---:|:---:|:---:|:---|:---|
| <5% | ✅ | < 生命周期 | **不洗** | 闷声出单群，低频维护+私聊跟进 |
| <5% | ❌ | 已到/接近 | **洗** | 按洗群SOP执行 |
| <5% | ❌ | 远未到 | **先救内容** | 群定位/内容错了，重启互动五步骤 |
| 5-10% | — | — | **激活** | 轻度激活，不用洗 |
| ≥10% | — | — | **健康** | 维持节奏 |

**结论输出**：【填：洗/不洗/先救内容 + 一句话理由】

## 四、动作建议

### 若"不洗"（闷声出单群）：
1. 低频维护 + 私聊跟进（别急着解散，它在帮你出单）
2. 用"核心用户带节奏"激活群氛围（模板04）
3. 到了生命周期上限如果产出也停了，再按洗群SOP操作

### 若"洗"（按洗群SOP，5步）：
1. **提前3天公告**：【填："这个群完成阶段使命啦，感谢陪伴～重要干货我整理好发你"】
2. **末次价值输出**：【填：发一份干货/打卡表/一次答疑，让人带走价值】
3. **引导迁移**：【填："想继续跟着我的，进【兴趣群/会员群】（附邀请）"】
4. **私聊重点客户**：【填：高潜力/已购未转化客户 1on1 单独邀请到正确群】
5. **解散/归档**：【填：到时间解散，或设只读归档】

**洗后分流（人不能丢）**：
| 客户类型 | 洗群后去哪/做什么 |
|:---|:---|
| 高潜力客户（问过事业/爱邀请人） | 1on1私聊跟进 → 养伙伴围观群或直接启动事业 |
| 已购未复购客户 | 邀请进会员服务群或下一期垂类打卡群 |
| 普通围观客户 | 引导进兴趣群留存；朋友圈/公众号持续触达 |
| 全部留存客户 | 资料沉淀：干货转成钩子资料/打卡表发给每人 |

### 若"先救内容"：
不是洗群问题 → 回模板02重启排期 + 模板04互动激活，群定位/内容对了再谈。

## 检查清单（AI 交付前对照）
- [ ] 活跃率按公式估算（不是凭感觉说"还行"）
- [ ] 产出判定走 30 天窗口量化规则，结论可解释可复查
- [ ] 决策矩阵判断正确（洗/不洗/先救内容），不因"热闹/冷清"误判
- [ ] 若洗：给了完整5步SOP + 洗后分流（人不能丢）
- [ ] 无"多少天没人说话就当死群"式拍脑袋
- [ ] 不编造学员数据（学员没说清→按保守判定并说明）
