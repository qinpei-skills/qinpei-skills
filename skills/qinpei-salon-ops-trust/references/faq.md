# FAQ 常见问题（学员问到时读）

**Q1：我想办招商会，能直接出方案吗？**
→ 先走信任诊断：老客多、复购好、关系深 → 支持，按"招商收口"微调；否则拦偏到体验沙龙。**不硬生成招商模板。**

**Q2：时间不够/人手不够怎么办？**
→ 用极简 2 人版（总控兼主讲＋氛围官兼邀约）；微课压到 20 分钟；互动只留 1 类（分享或游戏）；邀约只走朋友圈＋1V1 两条。AI 会按"最省事配置"重出一版。

**Q3：我完全没办过活动，从哪开始？**
→ 从「进阶工具包·最小SOP卡」起步：一场 30 分钟微课＋一个互动＋3 人小组。AI 会把每一步拆到能直接照着做——先看第一份「一页纸办沙龙」总纲，再按对话框里的「使用导航」走第一步。

**Q4：客户说"别推销，就聊天"怎么办？**
→ 微课强化干货价值、产品种草全部移除、暗线改为纯理念认同；收口只留"下次活动/线上交流群"自然引导，不碰产品。

**Q5：来了 20 多人，超出小型规模怎么办？**
→ 用 5 人扩展分工（+邀约伙伴+AI内容官）；若长期 20+，建议把单场拆成两场小型体验沙龙（体验感更好）。

**Q6：活动办完，客户没反应怎么办？**
→ 按信号卡：没到 OK 线就**成交放缓**——隔 1~2 天发照片＋一条干货，重新拉链接。别追单，把"一次机会"变"慢慢养"。

**Q7：我办过活动了，怎么让它下次更好？**
→ 直接说"我办过××，效果一般，帮我看看怎么改进"。AI 先查你的活动档案，诊断上次卡在哪，文字确认改进方向后，出「改进版方案」（保留什么/改什么/加什么）——不是重做一份，是把上次升级成下次更好的。

**Q8：不知道办什么主题，邀约都没人理？**
→ 说「帮我想想主题」，AI 用选题引擎给你 3 个候选（每个带卖点+玩法+成本档，至少 1 个零成本版）。主题没意思，人就不愿来线下——先让主题有吸引力，邀约才接得上；但不用怕成本，低配版 0 元就能办。

**Q9：方案太多看不懂 / 时间不够用怎么办？**
→ 拿到方案后看第一份「一页纸办沙龙」就够了，其余按需打开。还觉得多：回复「大白话」我翻译成最简单的话；时间紧回复「1小时/半小时」我出极简版；不知道先干啥回复「先干啥」我告诉你第一步。**别硬啃 10 份，我帮你挑。**
