# 故事力 · 快速上手话术卡

> 不会用？照抄下面一句发出去就行。

---

## 一、直接抄这 3 句

| 你想干嘛 | 就发这句 |
|---|---|
| 第一次用，不知道说啥 | 「帮我写个朋友圈故事」 |
| 讲客户案例 | 「我要发圈讲个客户案例，帮我写」 |
| 讲创业经历 | 「我该怎么讲我的创业经历，吸引同频的人？」 |

## 二、它先问你 2 件事（答一下就行）

1. **讲给谁听、在什么场合**？（比如：沙龙上都是新客 / 社群里都是陌生人 / 1对1聊意向客户 / 招商沟通）
2. **发在哪**？私域分享（社群/朋友圈/1对1/沙龙）还是公域平台（小红书/视频号/抖音/公众号）

> 不确定就回"没想法，你看着办"，它按你的素材直接选，不追问。
> 私域分享→出原声版直接用；发公域→出待过审版+自检卡，发布前再过一遍平台红线。
> 🔴 "治好了病"这类话任何场合都不能讲（线下分享会也算公开场合，有真实罚单案例）——让它帮你改成个人感受的说法。

## 三、六类故事速查（它帮你选，你了解即可）

| 类 | 一句话 |
|---|---|
| 个人故事 | 你走过的路，让人认识你 |
| IP故事 | 你信什么、不做什么，让人认可你 |
| 创业故事 | 你怎么开始怎么决定，吸引同频 |
| 案例故事 | 客户原状→你的方法→转变，临门一脚 |
| 产品故事 | 一个真实使用场景，让人想了解 |
| 失败/转折故事 | 摔过跤才真实，信任的加固钉 |

## 四、常用小指令

- 「太像广告了」→ 它对照自检只改那处，不重写全文
- 「帮我改改我发的这条」→ 发原文给它，续写/改写
- 「我讲过那个故事」→ 它记得，直接续写

## 五、记住一句话

**先讲摔跤，再讲现在；一条主线，一个目标。**
