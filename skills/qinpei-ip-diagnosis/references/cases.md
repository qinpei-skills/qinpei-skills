# 诊断案例库（IP 定位 · 5 个案例）

> **什么时候读这个文件**：诊断过程中需要"讲个案例帮学员对号入座"时。案例是教学素材——具体数字为方法论示范口径，讲给学员听时点明"这是示范，你自己的情况按实际来"，严禁当成该学员的成绩承诺。

---

**案例一：育儿团队长——"活成了一个广告位"**
一个做育儿的团队长，朋友圈早上"早安，元气满满的一天"、中午甩团购链接、晚上"晚安"。把自己当陌生人刷一遍——"好像……就是一个普通妈妈。"
→ **点破**："你不是不够努力，你是活成了一个广告位，不是一个活生生的人。"

**案例二：旅游学员——从"晒美照"到"避坑指南"**
一开始觉得"做 IP 就是拍好看的照片"，拍了半年该没人看还是没人看。后来换思路——不晒美照，开始分享"带娃出游的避坑指南"：哪个景点婴儿推车能进、哪些酒店有儿童餐、怎么在机场安抚哭闹的孩子。
→ 评论区全疯了："求攻略""太需要了""你什么时候开团"。
→ **结论**：她从"展示自己好看"变成了"帮别人做决策"。后者，才叫 IP。

**案例三：全职妈妈——同样一个人，三个月被追着问**
做健康养生副业，发产品海报+养生语录，两个月一条咨询都没有。后来做了**三个换**：
- **换身份**：从"我是XX品牌代理" → "我是懂食疗的二胎妈妈"
- **换视角**：从"XX产品调理效果很好" → "用我踩过的坑，帮你少花冤枉钱"
- **换内容**：不发产品图，发"孩子积食了，我是这么处理的""婆婆说这个偏方有用，我试了之后发现……"
→ 一个月后评论区开始有人问"你怎么判断孩子积食的"；**三个月内 20 多个妈妈主动问她：你在用什么？**
→ **结论**：她的专业度没有任何变化。变的只是她从"卖货的人"变成了"一个懂食疗的妈妈"。

**案例四：小C——四问定类型**
30岁，女儿3岁，想做育儿副业，最开始晒娃+分享绘本，没起色。走四问：讲干货还是讲故事→"讲故事时特别开心"；希望因为什么被信任→"有用又真实"；最容易产出的形式→"语音和短视频，特别喜欢跟人聊"；每天能花多久→"1-2小时"。
→ **结论**：主类型 = 陪伴型（60%）、辅助类型 = 工具型（40%）。
→ 调整后方向："凌晨妈妈树洞"陪焦虑的新手妈妈聊天 + 每周给一个育儿小模板（如"宝宝辅食一周安排"）——从"泛育儿"收窄到"焦虑的新手妈妈"这一类人。
→ **三个月后自然涨粉 2000 多**，开始有出版社寄绘本找她合作。
→ **结论金句**：不要用"我想成为谁"来选类型——要用"**我本来是谁**"来选。不要用"哪里人多"来选方向——要用"**哪里我能做到不可替代**"来选。

**案例五：健康管理学员——从泛养生收窄到一类人，粉丝掉一半、收入翻两倍**
一个做健康管理的学员，一开始发"每天吃什么"的泛养生内容，发了半年粉丝不少，但变现很差——泛粉不买单。后来收窄人群，聚焦"30–45 岁职场女性的亚健康调理"，发"久坐腰痛的 3 个办公室拉伸动作""熬夜后的气血茶怎么配"。
→ **粉丝从 3 万掉到 1 万，月收入翻了两倍。**
→ **结论**：粉丝数不是资产，"不可替代"才是。宁可让 1000 个人离不开你，也不要 10 万人刷到你就划走。
