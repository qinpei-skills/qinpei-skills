# 模板05 · 科普口播（AI 生成前必加载本模板）

> **这一格干什么用**：引流主力——观众因为一条有用的科普记住你、关注你。适合讲：行业误区、正确认知、具体做法。**知识和带团队类的科普优先于产品类**（离成交越远的科普，涨粉越快）。
> **双版本规格（默认双稿齐出，学员指定单版才单出）**：
> - 📱 **60秒内版**：约240字（上限260）——一个误区+一个正确做法
> - 🖥️ **3分钟中视频版**：约700字（上限750）——加"为什么会这样"的原理层+第二个例子
> **三小类**：误区拆解（最稳，优先）/ 正确认知 / 操作方法。
>
> **⚠️ 科普格合规要领**：只讲知识和做法，不讲功效和结果——"这样做有什么好处"是功效雷区，改说"为什么值得做"。

---

## 先选小类（学员的一句话判断法）

| 学员说 | 选哪类 |
|:---|:---|
| "很多人把XX做错了/理解错了" | → 误区拆解 |
| "我想讲讲XX到底是什么/怎么回事" | → 正确认知 |
| "我想教大家一个具体做法" | → 操作方法 |

> 拿不准 → 都让学员用一句话说说想讲什么，AI 帮选。跟故事格的"破谣"（拆流行说法）区别：破谣讲"一句话流言"，科普讲"一个知识/一套做法"。

---

## 小类A · 误区拆解（最稳，优先推荐）

**结构**：误区钉出来 → 为什么是错的（拆给人看）→ 正确的做法是什么

1. **【开头】误区钉出来**（数字+反差最好用）：
   - `【填：一个高频误区，比如"睡前泡脚"，配上频率词，比如"十个做的人九个在瞎泡"】`
   - `越【填：高频行为，比如"勤快地涂身体乳"】的人，【填：越容易出的问题，比如"皮肤反而越干"】`
2. **【人设句·紧跟开头】**：`做这行【填：X】年，这个错我见得最多` 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】，禁只报年头。
3. **为什么是错的**（先立再破）：
   - 先承认对的部分：`这个做法本身没错，错在【填：错在哪——时机/顺序/程度】`
   - 拆解：【填：用大白话讲原理。专业词后必须跟一句白话解释，"角质层就是我们皮肤的外墙"】
4. **正确的做法**（给替代动作，落到生活语言）：
   - 【填：怎么做才对，一二三列清楚。🔴 只讲做法，不讲"做了就会怎样"的功效承诺】
5. **【收尾】金句 + 钩子 + CTA**：
   - `养生这事，最贵的学费是听一半。关注我——【填：钩子，比如"这种误区我手里还有一箩筐，下一条拆XX"（你真打算拆的才算数）】`

**示例骨架**：

十个泡脚的人，九个在瞎泡。【开头】

做养生这行【填：X】年，光这个错我就亲眼见过【填：真实数量】次。【人设句·紧跟】泡脚本身没错，错在时机——很多人一泡就是半小时，泡到【填：错误状态，比如"浑身出汗才罢休"】，这反而是在耗。咱们的气血就像口袋里的钱，该花在刀刃上，不是撒出去越多越好。【先立再破+白话解释】

正确的泡法记三件事：一，【填：要点1】；二，【填：要点2】；三，泡完【填：要点3，比如"别晾着，赶紧擦干穿袜子"】。至于适不适合你、什么情况不能泡——每个人情况不一样。【正确做法+软声明】

养生这事，最贵的学费是听一半。关注我——【填：钩子】。【收尾】

**（60秒内版约240字；3分钟版在【为什么是错的】加一层原理（还是白话）+第二个日常例子。约700字。）**

## 小类B · 正确认知（讲清一个概念）

**结构**：这个事大家都理解歪了 → 它到底是什么（白话+比喻）→ 讲懂了有什么用

1. **【开头】认知差钉出来**：
   - `大部分人以为【填：流行理解】，其实它管的完全是另一回事`
2. **【人设句·紧跟开头】**：`这个东西，我给客户讲了【填：X】年，每次讲完对方都恍然大悟` 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】，禁只报年头。
3. **它到底是什么**（比喻是最好的老师）：
   - 【填：一个生活化比喻，比如"脾就像家里的后勤部长，看着不出门，缺了它全家转不动"】
   - 🔴 讲功能不讲病症：说"它管什么"，不说"它出问题你会得什么病"
4. **讲懂了有什么用**（认知红利，不承诺结果）：
   - 【填：明白这个概念后，人的选择会怎么变。禁"懂了就能治好/改善XX"】
5. **【收尾】金句 + 钩子 + CTA**：同小类A

## 小类C · 操作方法（教一个具体做法）

**结构**：这个方法解决什么麻烦 → 怎么做（步骤化）→ 什么情况别硬来

1. **【开头】麻烦钉出来**：
   - `【填：一个具体麻烦，比如"晚上躺下脑子停不下来"】的，这个方法你可以今晚就试`
2. **【人设句·紧跟开头】**：`我做这行【填：X】年，这个方法是我客户里反馈最踊跃的一个——经我手服务的客户【填：真实数量】个` 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】留白，禁只报年头。
3. **怎么做**（步骤化，一二三，每步一句话）：
   - 【填：2-4步，每步具体到动作。🔴 全程不提"做了会怎样"的因果承诺，只说"做什么"】
4. **什么情况别硬来**（软声明前置，反而显专业）：
   - `如果有【填：特殊状况，比如"正在孕期/有基础情况在调理"】，先问你身边专业的人再做`
5. **【收尾】金句 + 钩子 + CTA**：同小类A

## 科普格通用规则

1. **一条一个知识点**——想讲第二个 → 拆成下一条（正好攒系列）
2. **专业词后必跟白话**——"角质层，就是我们皮肤的外墙"。每个专业词都这么处理，一个不落
3. **只讲做法不讲功效**——"为什么值得做"可以说（原理），"做了会怎样"不能说（因果承诺）
4. **人设句紧跟开头**——科普格尤其容易通篇知识没人味，人设句是那条"人味锚"
5. **钩子天然顺手**——科普格最适合做系列（误区清单/概念合集），钩子问学员"这个主题你还能讲几条"，能讲就做成系列钩
6. **数据引用规则**——要说"十个九个"这类频率词，只能用行业常识级表述；具体研究数据学员拿不出处 → 一律删掉不引

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 开头把误区/麻烦/认知差钉出来了？没有"今天给大家科普一下"？
- [ ] **人设句紧跟开头了吗（第二三句内）？**
- [ ] 小类选对了吗（误区/认知/方法）？
- [ ] **每个专业词后面都跟了白话解释？**
- [ ] **全程无功效承诺、无因果断言？**（"做了会怎样"一句都没有？）
- [ ] 体质词过了转化表？（讲身体状况全用场景词）
- [ ] **结尾钩子是学员真有的东西吗？**（系列钩问过学员能讲几条吗？）
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 版本对版吗？（60秒内版240字±10% / 3分钟版700字±10%）
- [ ] 时长标注 + 拍摄提示（科普格提示：可加简单的手势比划原理，讲到步骤时放慢、掰手指数）？
