# 社群运营技能包 · 快速上手话术卡（v3.0）

> 激活技能包后，直接把下面任意一句发给 AI，就能出内容。**不用记编号，说人话就行。**

---

## 🟢 新手必说（先诊断）

| 你想干啥 | 直接发这句 |
|:---|:---|
| 不知道群咋样 | 「帮我诊断一下我的群」 |
| 从零建群 | 「我想建个兴趣群养客户，我是做____的，客户是____」 |
| 排一周内容 | 「帮我排这周____群的内容，客户是____」 |
| 群没人说话 | 「我的群好久没人说话了，要不要洗群？」 |
| 大家不聊 | 「群里总是我一个人在说，怎么让大家聊起来？」 |
| 带伙伴 | 「我想把群里积极的伙伴带起来做事业」 |
| 改硬广告 | 「我写了段群发消息太硬了，帮我改改：[粘贴原文]」 |

- 「排内容带四标签说明，我要带教伙伴用」

## 🟣 五类群一句话区分

- **兴趣群**：让陌生人想认识你（未转化，养认知）——漏斗入口
- **会员服务群**：让买过的人享受专属服务、愿意复购（已购客户）
- **垂类打卡群**：用打卡带动行为改变、转化复购/跨品（有垂类产品时建）
- **养伙伴围观群**：让潜在伙伴"围观"你如何带人、种下事业种子（团队长必建）
- **事业群**：把用的人变成做的人（核心伙伴带教培训）

> 流转：兴趣 → 会员/打卡 → 养伙伴围观 → 事业（不是并列，是漏斗）

---

## 🟡 你该做哪几个群？

| 你的身份 | 最少需要 | 说明 |
|:---|:---|:---|
| 个人经营者 | **2 类**：兴趣群 + 垂类打卡群 | 先养客再转化复购 |
| 团队长 | **3 类**：兴趣群 + 垂类打卡群 + 事业群 | 加上育人闭环 |
| 系统强大 | **5 类全做** | 跑满完整漏斗 |

> 群是为展业目标服务的，先定目标再决定做哪几个。

---

## 🟡 内容四标签（复盘用，不强制）

每条内容问自己：① 目标层（养客/复购/事业/激活）② 信任层（认识/认可/信任）③ 钩子（投票/晒图/咨询/打卡）④ 行动（发言/私聊/到店/转发）

---

## 🔴 三条红线（群里别碰）

1. 不治病（"治好了XX病"❌）
2. 不绝对（"最有效/第一"❌）
3. 不控评（"群托/水军"❌，用核心用户/KOC 真实带动；可用"气氛组"适度引导）

> 记住：群是信任银行，不是广告牌。线上养熟，线下/私聊成交。
