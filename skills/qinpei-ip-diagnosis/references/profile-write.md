# 画像写入细则（诊断完成后执行，两处同时写）

> **什么时候读这个文件**：诊断跑完、学员确认定位方向后。**先征得学员同意再写**（见下）。写完一句话带过，不把文件内容念给学员听。

---

**写之前先确认**："我把你的定位存下来，以后你再来、或者用其他功能，我就不用重新问你了，好吗？"（学员同意才写；这是必做动作，但要说一声。）

## ① 用户级记忆（`~/.workbuddy/MEMORY.md` · 让画像在任何会话里自动被读到）

- **先 Read 整个文件**，找到 `<!-- qinpei-profile:start -->` 与 `<!-- qinpei-profile:end -->`。
- **已有标记块** → 只替换块内内容，块外**一个字都不动**。
- **没有标记块** → 追加到文件末尾（不插入、不改动任何既有内容）。
- 写入内容（精简版，控制在 15 行内）：

```markdown
<!-- qinpei-profile:start -->
## 我的IP画像（沁珮技能包通用）
- 你是谁：做大健康5年，主营中草药保健品
- 帮谁：产后妈妈
- 你凭什么：结果背书——服务过100多个产后妈妈
- 你给什么：产后气血+身材调理的方法
- 行动引导：想要自测表评论区扣1
- 一句话定位：用中草药+外治法，解决产后妈妈的气血和身材问题
- IP类型：陪伴型60% + 工具型40%
- 变现方式：卖产品+办卡套餐
- 避讳：不出现XX品牌名/敏感词
<!-- qinpei-profile:end -->
```

（上面是模板示例——写学员的真实内容，不照抄示例数字。）

## ② 共享画像（`~/.workbuddy/skills/qinpei-profile/我的画像.md` · 详细版，供沁珮其他技能包共享）

- 文件**已存在** → 只更新对应字段（补四要素、类型），**不删除学员原有内容**。
- 文件**不存在** → 新建，按 qinpei-profile 的标准格式写入（基础信息 / 引流钩子 / 风格偏好 / 文案类型偏好 / 免打扰设置）。
- ⚠️ 学员说"重新填"才覆盖画像；否则一律**增量更新**。

## ③ 写完的反馈话术（一句话，不念内容）
> "你的定位我已经记下来了，下次直接来找我就行，不用重新讲一遍～"
