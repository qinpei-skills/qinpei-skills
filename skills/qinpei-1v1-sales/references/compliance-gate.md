# 合规双门禁 · 私聊场景（直销红线 + 平台/私域红线）

> 状态：v1.0.0-dev｜来源：团队长案例库「合规红线与数字可信度清单」（2026-10-27 汇总）＋1对1咨询交付板块合规要求
> 🔴 **每次交付前必过**。私聊场景同样受《广告法》《反不正当竞争法》及平台规则约束——**一对一推销也是广告行为**，不是"熟人聊天就没事"。

---

## 一、门禁结构（两关都过才交付）

- **关一 · 直销行业红线**——收益承诺、疗效承诺、医疗边界、行业红线（这个赛道最常踩的）
- **关二 · 私域/平台红线**——导流、骚扰、诱导、绝对化用语、虚假数据

---

## 二、关一 · 直销行业红线

### 1. 收益承诺（🔴 永久禁止，最高危）

| 🔴 禁 | 说明 |
|---|---|
| "月入过万""轻松月入几千""年入几十万" | 收益承诺 |
| "稳赚""躺赚""被动收入""睡后收入" | 收益承诺 |
| "零风险""不成功也没损失""亏了算我的" | 虚假承诺 |
| "回本周期X个月""多久能回本" | 收益承诺 |
| "跟着我就能赚""我带的伙伴都赚到了" | 收益承诺＋案例数据不实 |
| 拿别人的收入截图/流水当承诺 | 数据不实＋暗示普遍性 |

**为什么这条排第一**：它是本行最常被举报、也是最容易一夜翻车的一条。**任何形式的"确定性收益"表述都不许出现在给客户的话里**——包括"轻轻松松""大部分人都能""一般三个月就……"这种软化版。

### 2. 疗效与健康承诺

| 🔴 禁 | 为什么 |
|---|---|
| "用一个月就能改善""三个月见效""保证有效" | 效果承诺＋医疗边界 |
| 出现病名＋指标（"降血糖""治失眠""结节消了"） | 医疗边界 |
| "调理好了""根治""不用吃药" | 医疗边界 |
| 体质词上客户（"你这是气血虚/脾胃虚"） | 医疗边界（越界诊断） |

**替代说法**：
- 疗效 → **体验与感受**："用起来是什么感觉""很多人反馈……"（🔴 反馈也必须学员给，AI 不代编）
- 病名 → **生活场景**："手脚常年凉""睡不踏实"（🔴 描述现象不诊断）
- 体质判断 → **需求确认**："你是有这种情况，还是别的原因？"（🔴 让客户自己说，AI/学员不下判断）

### 3. 恐吓式与诱导式

| 🔴 禁 |
|---|
| "再不用就晚了""身体迟早报复你""等到躺病床上才后悔" |
| "这个病拖下去会……"（推演后果吓人） |
| "现在不买就吃亏了""过期了就没了"（制造恐慌） |
| "专家/主任/教授"类医疗身份暗示（无资质说明） |
| 一人叠多个健康头衔 |

### 4. 信息遮蔽式销售（🔴 反面教材之首）

**🔴 绝对不做**：只给方案不提产品、收货后才发现是某品牌。**客户必须在决策前知道你是谁、你卖什么**。这是行业里最被诟病的做法，也直接违反告知义务。

### 5. 案例红线

| 🔴 禁 |
|---|
| 案例里的真人姓名、公司名、具体门店 |
| 案例中出现收入数字 |
| "他们家孩子考试提高了""她妈妈指标正常了"（效果暗示） |
| 群控/水军痕迹（"大家都在问""都说好"式的整齐互动被截图当证据） |

**✅ 替代**：案例讲**过程**（她原来怎么做 → 遇到什么 → 做了什么 → 现在的状态），真人一律代号化。

### 6. 数字可信度

- 🔴 引用任何数字前先核对**口径**（分子分母是什么、统计周期多长）
- 🔴 教学示例的数字 ≠ 实测数字，🔴 不许把上限当常态
- 🔴 客户案例里的数字必须学员给，AI 不代编

## 三、关二 · 私域/平台红线

| # | 红线 | 🔴 禁 | 说明 |
|---|---|---|---|
| 1 | 导流导流 | "加我微信""扫这个码""私聊我领" | 一对一私聊里导流到站外=平台重点打击 |
| 2 | 诱导交易 | "赶紧拍""最后3单""手慢无" | 虚假稀缺 |
| 3 | 诱导互动 | "扣1""点赞抽奖""转发领资料" | 诱导互动 |
| 4 | 绝对化用语 | "最好""第一""最有效""唯一""国家级" | 广告法禁 |
| 5 | 虚假数据 | 编造销量/评价/资质/获奖 | 数据不实 |
| 6 | 骚扰 | 连续多条发送、深夜发消息、无回复仍高频追 | 平台骚扰规则 |
| 7 | 引流群发 | 把客户拉进群/转发群发话术 | 平台与法律双重风险 |
| 8 | 篡改资质 | 用"国家认证""官方推荐"等未证实表述 | 虚假宣传 |

**🔴 第6条（骚扰）在私聊场景最容易被忽略**——本包的3-7-14节奏本身就是骚扰红线防护：**一次跟进只带一个东西**、**她明确拒绝立刻停**、**不换号联系、不通过别人打听**。

## 四、交付前统一检查清单（15项，逐项过）

**行业关（8项）**
1. 有无收益承诺（含软化版）？
2. 有无疗效/效果承诺？
3. 有无病名＋指标、体质词？
4. 有无恐吓推演、后果渲染？
5. 有无医疗身份暗示、无资质头衔？
6. 是否做到"决策前告知身份与产品"（信息遮蔽检查）？
7. 案例是否去标识化、是否含收入数字或效果暗示？
8. 引用数字的口径是否核对过、是否学员所给？

**平台关（7项）**
9. 有无导流到站外？
10. 有无诱导交易/虚假稀缺？
11. 有无诱导互动？
12. 有无绝对化用语？
13. 有无编造数据/资质/获奖？
14. 是否构成骚扰（频次/时段/无视拒绝）？
15. 有无群发或拉群动作？

**🔴 任何一项为"是" → 改完再交付。** 有一项拿不准 → 往保守方向改。

## 五、话术替换表（给学员看的版本）

| 🔴 别说 | ✅ 改说 |
|---|---|
| "用一个月就能改善" | "用起来是什么感觉，你可以先试一小段时间自己感受" |
| "我这个月赚了三万" | "我这一行做了X年，服务过多少人"（讲经历不讲收入） |
| "跟着我做肯定有收入" | "我能给你的是支持和路径，别的我不敢打包票" |
| "今天最后一天" | "这个随时可以定，你什么时候方便都行" |
| "加我微信我给你发详细方案" | "我先把要点跟你说清楚，你看你需不需要细看" |
| "你是气血虚所以总累" | "你是最近总觉得累、没精神吗？"（🔴 让她自己说） |
| "我们家孩子吃了三个月考试提高了" | "有个客户的孩子当时也是这个情况，她后来自己觉得轻松多了"（🔴 感受，且必须学员给） |

## 六、学员端话术（🔴 不用术语）

给学员讲合规时不出现"门禁/红线表/违禁词"这类词，说：

> 「我给你把关的就是一件事：**这话你发出去会不会被投诉**。收益、疗效、绝对化的词一律不写；案例里的人一律不出现真名。这几条是硬线，其余的你自己拿捏。」

**🔴 唯一豁免**：沁珮老师明确说"这次不考虑违禁词"时，方可放宽——学员端无此权限。

## 七、合规门禁的失效边界（🔴 门禁不是万能盾）

⛔ **门禁能管住"说什么"，管不住"学员自己怎么说"。** 下面几种情况门禁不适用：

| 情况 | 🔴 为什么门禁管不住 | 该怎么处理 |
|---|---|---|
| 学员自己把包里的方案截图发到客户群 | 本包不控制学员二次编辑 | 给学员"发之前扫一遍"的自检话术（见第四节清单） |
| 学员用的是自家品牌的产品资料 | 本包不知道品牌方的话术口径 | 提醒学员：**品牌方的宣传口径以品牌方审核过的为准**，本包只管通用红线 |
| 学员在朋友圈/群里发的长文（不是一对一） | 本包只管一对一私聊场景 | 转朋友圈包（qinpei-wechat-trust）的合规门禁 |
| 客户在对话里要求"你保证能治好" | 客户在逼你承诺 | 🔴 立刻拒绝并说明边界："这个我不能保证，也不该跟你保证" |
| 私聊中涉及具体病症（客户自述病情） | 涉及医疗建议 | 🔴 **不给任何用量/疗程/疗效建议**；可以说"这个我不懂，你问医生" |
| 涉及价格承诺、返利政策 | 学员自己承诺了品牌政策 | 提醒学员：价格与政策以公司最新公示为准，AI 不编 |
| 学员想用本包做群发/一对一营销 | 场景不匹配 | 🔴 本包不做群发，转社群包（qinpei-community-ops-trust） |

🔴 **通用边界**：门禁是**交付前的最后一道**，不是全部。真正的合规责任在**人**——本包能保证"AI 给的每一句不踩线"，保证不了"学员自己发出去的不踩线"。所以凡是涉及承诺类内容，一律提醒学员自己再核一遍。

🟢 **理论锚点**：合规门禁锚定直销行业的"信息不对称"风险——承诺之所以危险，是因为它把无法保证的结果说成了可保证。🔴 **失效边界**：**低风险品类**（非健康、无功效宣称）不需要同等强度门禁；本包面向大健康赛道，所以门禁强度按**最高档**设，不因品类降级。
