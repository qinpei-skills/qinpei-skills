# 敏感表达转译层（AI 内部文件）

> 用途：学员想讲团队增长、伙伴招募、行业选择等话题，却因某些词产生心理回避或公域表达风险时，**保留概念，只换载体词**。不许为了绕开词，把话题退回零售、日常或空泛感悟。
> 边界：这不是“违禁词隐身术”。换词后仍须过 `compliance-gate.md` 与 `platform-redlines.md`；收益承诺、拉人头、误导招募等实质风险，不能靠换词放行。

## 一、转译四步

1. **先还原概念**：这句实际在讲团队增长、伙伴加入、行业身份，还是收入？
2. **只换触发词**：保留原句判断和业务方向，不把主语、因果或动作偷换掉。
3. **回读全句**：替换后是否仍然回答原问题？若从“怎么带新伙伴”滑成“怎么做零售”，判不合格，重写。
4. **再过合规**：重点查收益暗示、夸大结果、诱导加入、拉人头和导流；概念安全不等于整句安全。

## 二、常用转译表

| 原表达 | 默认转译 | 使用边界 |
|:---|:---|:---|
| 扩张 | **优先保留“扩张”**；需要换口气时用“增长”“团队在往上走” | 正常商业词，不必见词就删；不得接“保证收入/稳赚”等承诺 |
| 招募 / 招商 / 裂变 | 把新伙伴带进来 / 让更多伙伴加入 / 团队长出新伙伴 | 按真实业务含义选，不把招商与招募混为一谈；不写收益诱惑或人头计酬 |
| 直销 | 这行 / 分享经济 / 团队带教这件事 | 公域稿按 compliance-gate 1c 柔化；不谎称平台一律禁词，也不因换词省略真实业务含义 |
| 拉人头 / 招代理 | 找同路伙伴 / 带团队做事 | 若原意在描述违规拉人头，不得洗白；应直接删去该机制 |
| 大健康事业 | 这份事业 / 线上这条路 / 健康这件事 | 只有符合实际路径时才用“线上这条路”；避免口号化、招商味 |
| 留人靠扩张 | 原样保留 | 已包含清晰判断，不为“显得温和”而削掉观点 |

## 三、两条禁区

- **禁概念逃避**：学员明明要解决“团队没有新伙伴”，成稿就必须给团队增长判断或动作；不得改成“做好零售自然有人留下”。
- **禁换词造安全假象**：把“招募”换成“找伙伴”后，若仍写“跟着我一定月入××”，照样不合格。

## 四、交付前回读三问

1. 原来的核心概念还在吗？
2. 新词符合学员真实业务，而不是更漂亮但更不准确的叫法吗？
3. 整句重新过合规后，是否仍有收益、效果、诱导或行业红线？

三问全过才交付。对学员只解释“这句咱们换个更准确的说法”，不暴露本文件术语。
