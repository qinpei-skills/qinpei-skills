# 个人IP定位诊断 · 使用说明（v1.1.0）

> 帮大健康 / 分享经济团队长，搞清楚"我到底该立什么人设、发什么内容"。
> 不会写提示词？跟它聊天就行。

---

## 一、这是啥

一个 AI 诊断搭子。你跟它聊聊你的现状（你是谁 / 帮谁 / 怎么帮），它给你**定位方向**——不发一堆方案，只给"该往哪走"的判断，犀利、直接、不灌鸡汤。

**它只给方向，不写文案**。要写故事、发朋友圈，它会告诉你去哪个技能包。

**适合谁**：做了很久却不知道"该立什么人设"、发圈没人理、内容没方向的团队长。

## 二、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序）：**
1. 把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好）
2. 装好后在输入栏「+」→「添加技能」里启用

**电脑端（Win / Mac 桌面版）：**
1. 解压 `IP定位诊断技能包.zip`，得到 `qinpei-ip-diagnosis` 文件夹
2. 把文件夹放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 手机、电脑装的是同一份，用法一样；纯对话诊断，不产文档，手机用最方便。

## 三、第一次怎么说

**直接抄**：
> "帮我诊断一下我的IP"

**带具体问题**：
> "我发圈没人理，是不是我人设不对？"

**系统测**：
> "我想系统测一下自己的IP定位起点"

## 四、它会怎么工作

1. 先问你是"带问题来"还是"系统测"（选一个就行）
2. 问你 3 件事：你是谁 / 帮谁 / 怎么帮（答不全也没关系）
3. 给你文字结论：现状总结 + 定位方向 + 卡点
4. 你确认"OK"后，它告诉你去哪个技能包落地（写故事 / 装修朋友圈）

## 五、注意事项

- 它**不写具体文案**——那是"我的故事""朋友圈信任经营"技能包的活
- 它**不编数据**：你没讲到的，它不会替你编"很成熟"
- 诊断只给方向，决定权在你自己
