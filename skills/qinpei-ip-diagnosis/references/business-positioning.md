## 一、核心命题：人设 ≠ 业务定位

- **人设 = 身份＋标签** → 解决「让人认识你」
- **业务定位 = 做什么＋帮什么人＋什么解决方案** → 解决「有需要时找得到你、信得过你、转化」
- **断裂病根一句话**：人设吸引来的注意力，和解决方案服务的需求，**不是同一个需求**。

### 断裂自检（前置初检＋名片复验，主流程必跑）

> 初检把学员的**昵称＋签名（有则加背景墙/置顶）＋解决方案**放在一起，陌生人能不能推出「我有什么问题该找她」。
> **推不出来 = 名片与方案可能断裂**。初检只标记，不在赛道前硬卡；赛道与一句话业务定位明确后，在三.12复验。优先用签名/置顶/背景墙补清求助理由，改昵称只是可选方案。
> 只有解决方案本身说不清才回三问；单纯昵称通用、签名能补清，不回三问重做。

给学员讲的版本（照抄）：
「你把你的昵称、签名，和你卖的东西/帮人做的事，摆在一块儿——一个陌生人看到，能不能猜出『我有什么问题就该来找她』？猜不出来，就是名字和生意没接上头。先不用急着改名，咱们先把赛道定下来，再看用签名还是置顶把它接上。」

### 断裂 vs 立住（对号入座例证组，去标识化）

| 断裂（有人设，没转化） | 立住（人设即业务定位） |
|:--|:--|
| 茶修主理人：来的人要氛围拍照，你谈调理——不在一条流程上 | 减脂教练：找她的人就想瘦，方案、产品顺理成章 |
| 精致探店型：粉丝信她「会挑」，不信她「懂健康」 | 营养师私域型：不求粉丝求精准，选题按变现路径倒推 |
| 晒娃宝妈：找她的人想看娃，没人信她懂皮肤 | 共同点：内容→人群→方案，一条线通到人进货出 |

### 场景包装铁律（★金句口径）

> **场景可以当包装，不能当定位；包装底下必须压着一条赛道。**
- 茶修×脾胃养生 = 立住；纯美学茶修 = 断裂。场景必须报一个业务定位，光喝茶不行。
- **「主理人」重点提醒**：茶修主理人、花艺主理人——主理人是场景包装，不是定位模式。学员报「主理人」→ 追问「包装底下压着哪条赛道」，答不出就打回。

## 二、业务定位三问 v2（旧第三问「变现」已废）

| 问 | 内容 | 要点 |
|:--:|:--|:--|
| 一 | **你是做什么的** | 一句话，不是行业，是你做的事 |
| 二 | **你帮助什么人** | 内容特定人群听不懂，等于没说 |
| 三 | **你的解决方案是啥** | 客户为解决方案找你；变现不用单独想 |

- 与旧版差异：旧第三问「变现方式」升级为「解决方案」——**变现是商家视角，解决方案才是客户视角**。
- 变现口径（一笔带过，不展开）：分享经济就一条，**人进货出**。解决方案交付得顺，人自然进平台。
- 🔴 学员问「那我的变现怎么办」→ 🧭 一句接住：「变现不用你操心——分享经济就一条，人进货出。方案交付得顺，人自然进。」然后继续问解决方案。

## 三、九条大健康赛道（收窄用，各配人群特征）

> 逐字稿 P13 原文口径，「各点一句特征，对号入座」。

| 赛道 | 人群特征（讲给学员听的一句话） |
|:--|:--|
| 体重管理减脂 | 常年最大需求，盘子和体重，年年都在 |
| 脾胃消化 | 吃出来的问题，男女老少都躲不开 |
| 睡眠情绪 | 增长最快的一条，失眠焦虑的人越来越多 |
| 代谢四高 | 中老年刚需，血压血糖血脂尿酸，四个词人人听得懂 |
| 免疫体质（气血祛湿） | 换季就垮的人群最大——调底子的生意，粘性高 |
| 眼健康 | 屏幕时代，全年龄用眼过度，老人孩子都盯着屏幕 |
| 口腔 | 一家老小都用得上，复购稳 |
| 骨骼关节 | 中老年的行动本钱，上下楼就知道它重不重要 |
| 女性健康（产后·更年期） | 周期性需求，粘性最高 |

- **收窄规则一条**：选一条，做深做透。九条都沾——等于告诉别人，你什么都不精。**都沾，就没有定位。**
- 安心口径：选好一条，公司产品线基本都接得住——**你的赛道和公司的货，不冲突**。
- 拔高口径（学员质疑赛道太窄时）：行业主线是**客户健康全生命周期管理**——中式养生、细胞抗衰、主动预防。你做的不是零散卖货，是一门「管理客户健康全生命周期」的生意。选窄赛道是打法，行业大盘在手上。

### 赛道收窄判定（v5.0.1 · 有证据优先＋零成交分支）

> 大健康从九条选一条；**非大健康走自定义单赛道**：用「一个具体客户需求」命名，例如「新手妈妈第一次带娃出行」，不硬套九条。收窄原则相同。

**有成交/服务记录时问三问**：
1. **主营基础**：主力产品分别解决什么客户问题，各占业绩几成？（心里估数即可；一个产品跨多个问题时按客户主要求助原因归，不按产品名硬归）
2. **真实需求**：最近成交客户集中为什么事找你？没有成交才看咨询，🔴 成交与咨询不得混称「客户用钱投票」。
3. **持续意愿**：哪一条你讲起来最来劲、真实素材最多？

**判定优先级（不许简单多数投票）**：
- **真实客户需求与可交付证据 ＞ 现有主营基础 ＞ 个人意愿**。
- 三问同向 → 直接定并复述依据。
- 三问不同向 → 先按有真实需求且自己交付得住的方向定；个人意愿只能在校验能否持续时参与，不能单独压过客户证据。
- 仍无法定 → 让学员在候选中自己选一条，标「暂定赛道，90天验证」，AI不凭感觉代选。

**零成交/零业绩分支**：
1. 你真实服务过、咨询过或自己实践过哪类问题？有什么可复述的过程？
2. 未来90天只做好一件事，你选哪件？
3. 两问都无依据 → 由学员从候选中选一条暂定，**不得再回退到不存在的成交数据**。

其余产品可以顺带承接，但不进业务定位句、不占第二条主赛道。

## 四、五种业务定位模式 × 赛道关键词

| 模式 | 打法一句话 | 赛道关键词 |
|:--|:--|:--|
| ① 单赛道深耕 | 账号名直接带赛道词，一个词讲到透 | 脾胃｜产后｜塑形｜视康｜口腔｜睡眠｜祛湿气血 |
| ② 教练型 | 前端方案/训练营 → 1V1 定制 → 后端产品+团队 | 减脂｜控糖｜体态｜产后修复｜护眼教练 |
| ③ 专业身份型 | 挂专业身份、小体量高转化，选题按变现倒推 | 营养师｜健康管理师｜小儿推拿｜体重管理师 |
| ④ 成长打卡型 | 无客户结果背书也可起步，本人真实、可核验的实践过程就是内容与过程背书；不冒充客户结果、不暗示疗效 | 30天脾胃打卡｜减脂记录｜控糖记录｜全家养生 |
| ⑤ 事业招商型 | 活动型落地，业务直接就是招商 | 茶修招商会｜沙龙体验场｜快闪体验群｜城市合伙人面谈 |

**选型口诀（逐字稿 P16）**：不确定选哪型——**选离你现有客户最近的那型**。

### ⑤事业招商型三道硬性指标（🔴 不达标不能定位在招商，必须拦）

1. **自己的业务链完整**——能完整做到人进货出；
2. **手底下有带成功的人**——带教出过结果，不是空口讲机制；
3. **有差异化的招商方案和路径，且跑出培养成功的共性结果**——不是一两个人，是团队共性的一些结果。

**拦的方式**：三道指标逐项问，缺哪道 → 🧭 点破「招商型的奖，是给走过路的人的——你现在 X 还没有，定位在招商就是空喊」→ 打回前四型选一型，缺的指标列为「三个月补齐项」，补齐后再回来升级成⑤型。**若此前终局选「伙伴优先」，退回前四型后必须重新确认未来90天先服务顾客还是仍有事实依据伙伴优先；内容方向与获客链路按新答案更新。**

### 时代背景（招商型为什么必须叠解决方案，学员问「我直接招商不行吗」时用）

20 年前的直销就是纯靠业务招商做；现在创业项目丰富度大增，分流了「直接招商」——所以招商型必须叠加真解决方案（回到一条主赛道做深；大健康从九条选，非大健康用自定义单赛道）。
