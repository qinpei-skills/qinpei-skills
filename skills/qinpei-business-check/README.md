# 展业诊断 · 使用说明（v3.0.0）

> 经营卡住了、做了很久业绩上不去、不知道该先动哪一步——
> 跟它聊 5–8 分钟，它带你从**四根支柱**过一遍，告诉你**最该先补哪一根**。
> 不会写提示词？说人话就行。

---

## 一、这是啥

一个 AI 经营顾问。它不灌鸡汤，也不替你下决定——

**它只做一件事：带你把四根支柱过一遍，找出你最该先补的那一根。**

**四根支柱**（跟《新展业诊断课》里讲的是同一套）：

| 支柱 | 它在查什么 |
|:---|:---|
| **① 链路** | 客户进来怎么养、多久见一次面、伙伴怎么带 |
| **② 定位** | 别人能不能一眼看懂你是谁、你帮谁、你解决什么 |
| **③ 一体化** | 线上和线下是不是一件事的两条腿，还是一摊两摊各走各的 |
| **④ 新旧融合** | 老本事（经营人）守没守住，新工具（数字化）用没用上 |

每根支柱 3 个检查点，一共 12 个。它一轮问一根，像聊天，不是考试。

查完给你结论——**四根各有几根立住 + 你最该先补哪一根 + 你现在的档位**。你认了，它才告诉你先做哪一件事、用哪个技能包落地。

## 二、两个入口，随你挑

| 你的状态 | 它会怎么做 |
|:---|:---|
| **有点迷茫**（不知道先干啥 / 卡住了） | 四根都过一遍，一根一轮 |
| **带着具体卡点**（"我就想知道朋友圈为啥没人理"） | 先看它属于哪一根，只深挖这一根 |
| **很确定**（我就想拉新 / 我就想要文案） | 尊重你的选择，直接照做；只在关键处提醒你一句 |

**它不拦你，也不拒绝服务。** 只是提醒一句"你确定这是你的真问题吗"——决定权永远在你。

## 三、一份可以转给助教的《展业诊断简报》

诊断做完，它会问你要不要出一页**《展业诊断简报》**：

- 一出就是 **Word 文档**，一页纸，手机上也能看
- 上面有你四根支柱的情况、最该先补哪一根、先做哪一件事
- **可以直接转给如意老师**——她后续跟进你的时候，手上有底，不用你再讲一遍
- 最后一栏是"给助教的跟进参考"，是给助教看怎么帮你的，你也可以看

> 只有你同意才会生成，不需要就直接跳过。

## 四、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序 / APP）：**
1. 把安装指令粘贴到对话框发送（约 30 秒装好）
2. 装好在输入栏「+」→「添加技能」里启用

**电脑端：**
1. 解压 `qinpei-business-check.zip`，得到 `qinpei-business-check` 文件夹
2. 放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 手机、电脑装的是同一份，用法一样。纯对话诊断，手机用最方便。

## 五、第一次怎么说

**直接抄**：
> "帮我做一次展业诊断"

**带具体处境**：
> "我做这行好几年了业绩上不去，帮我看看卡在哪"

**听完课来的**：
> "我刚听完新展业诊断课，想再深一层，帮我看看我断在哪一根"

**只想开干**：
> "我想做一批新客，帮我出个思路"

## 六、它会怎么工作

1. 先问你是四根都过一遍，还是就着现在最卡的那件事
2. 一轮问一根：链路 → 定位 → 一体化 → 新旧融合，每轮它串起 3 个检查点
3. 四根问完，给结论：每根立住程度 + 最该先补的一根 + 现在的档位
4. 你认可 → 它给你一件先做的事，和去哪根支柱落地用哪个技能包
5. 你要简报 → 出一页 Word，可以转给如意老师
6. 你不认可 → 尊重你，按你的思路重新捋

> 全程 5–8 分钟，手机一屏能读完结论。**不报分数**——你只要记住断在哪一根就行。

## 七、注意事项

- 它**不写具体文案 / 方案**——那是"朋友圈""社群""沙龙"技能包的活
- 它**不编结论**：你没有讲的，它不会替你下判断
- 它**不评判对错**：只剖因果，选择权在你
- 它**不报分数**：只报断点 + 档位名（跟自检表同一套说法，两边对得上）
- 诊断是聊出来的——一次只问一根支柱，说不清没关系
