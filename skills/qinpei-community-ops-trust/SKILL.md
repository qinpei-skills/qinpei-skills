## 💬 A 层：零门槛对话（说人话就行）

用户不需要写任何提示词。AI 根据用户的一句大白话，自动判断意图 + 追问 + 出内容。

> **强弱使用者分流（v2.0 新增）**
> - **弱使用者 / 第一次用**：走「诊断优先入口」，AI 主动问清 7 个维度，一步步带你产出，不要求你会表达。
> - **强使用者 / 老手**：直接说要做什么（"排下周兴趣群内容""帮我建个垂类打卡群"），AI 跳过诊断，直接出内容；也可用文末 B 层手动指令。
> - **同一句话两种接法**：用户说"帮我排下周群内容"，若未说群类型 → 默认走诊断问一句群类型；若说了群类型+客户 → 直接出。

### 🧭 总入口：诊断优先四步法（v2.0 核心）

> 不管用户要做哪件事，**优先触发一次轻量诊断**，再产出内容。诊断不是目的，是让内容"对路"。

**诊断 7 维度（一次问 1-2 个，已知的不问）：**

| # | 维度 | 问什么 | 为什么 |
|:---:|:---|:---|:---|
| 1 | **有无群** | 你已经有群了，还是从0开始建？ | 决定走"建群"还是"优化现有群" |
| 2 | **群类型/目标** | 这想做成哪种群？（兴趣/会员服务/垂类打卡/养伙伴围观/事业） | 决定内容基调与占比（见核心方法论二） |
| 3 | **群成员画像** | 群里主要是谁？（上班族/宝妈/老人/混合） | 决定固定栏目时段与话题口吻 |
| 4 | **当前卡点** | 现在最头疼什么？（冷场/不成交/没人带/不会排期） | 决定本次产出重点 |
| 5 | **可投入时间** | 你每天/每周能花多久在群上？（几分钟/固定时段） | 决定排期密度，避免给"做不到"的方案 |
| 6 | **业务类型/赛道** | 你做哪一行？（从赛道案例库匹配，见核心方法论十二） | 决定钩子、案例、专业口吻，让内容"亲切" |
| 7 | **当前群清单/精力** | 现在手头已经管着几个群？分别是哪类？你精力能顾过来几个？（对照五类群漏斗自查） | 决定"该新建 / 该合并洗群 / 该聚焦"——避免重复建群、精力稀释（联动模块一·合并洗群、模块二·群标配要素三模块） |

**四步连续动作（诊断 → 目标 → 拆解 → 产出）：**

```
第1步 诊断：收集7维（能跳过的跳过）→ 形成"群画像卡"（含第7维"当前群清单/精力"，用于判断"新建 / 合并洗群 / 聚焦"）→ **默认同时产出「我的展业群地图」一页纸**（见核心方法论二·2.4），让学员一眼看清群矩阵全貌与下一步
第2步 目标：基于画像，明确本次要达成的1个目标（如"激活沉默群""排一周养客内容"）
第3步 拆解：把目标拆成2-3个具体动作（如"先出破冰话题→再排固定栏目→最后给钩子"）
第4步 产出：逐个动作出内容，每条按"内容产出四标签"处理（见核心方法论十一）
```

> 🔑 **跳过机制**：如果用户已清楚说"就帮我排下周兴趣群内容，客户是宝妈"——维度 2/3 已知，直接跳到产出，不要重复问。诊断是为"没方向的人"服务的，不是流程枷锁。

### 六条路，各走各的：

#### 路 ①：从 0 到 1 建群

AI 先问群目的（一次一个），再出完整建群方案：

> 💡 **若用户提到"已购客户"**，AI 主动比对「会员服务群必做条件」（2.2）：已购≥20人 / 需持续指导使用 / 有会员体系 / 有复购潜力 任一满足 → 主动提醒"你已满足独立建【会员服务群】条件，可并行建（精力不够则先保兴趣群+垂类打卡群）"，不漏掉这个判断。

```
Q1: 这个群主要服务谁？想达到什么目的？
    👤 "我是做艾灸的，想养一养40岁以上的客户"

Q2: 你手头大概有几个可以拉进来的人？
    👤 "有二三十个老客户微信"
```

→ 用户答完立即出：
1. **群类型确认**（五类群对应，见核心方法论二）
   > 💡 **混合群（已购+未购同拉）处理**：若用户老客户里既有已购、又有未购，先建【兴趣群】作统一入口，**已购客户不退出本群**；达会员服务群条件时额外拉进会员服务群、买方案包时拉进垂类打卡群——多群共存、靠价值递进流转、不踢人（见 2.2"客户可多群共存"）。
2. **群标配要素三大模块**（价值定位 / 人群定位 / 功能描述，见核心方法论二·6）—— **先想清楚逻辑，再出文案**
3. **群公告 + 欢迎语五要素**（结合三层信任价值体系，见核心方法论三）
4. **破冰钩子**（A-E 五版选一个，见核心方法论三）
5. **建群节奏表**（第1天→第1周→第2周起，见核心方法论三）

> 💡 顺序很关键：先给「三大模块」让学员把群想清楚（为谁、什么人、干什么），**确认后再出公告/欢迎语/排期文案**。学员完全没思路时，AI 先按五类群速查生成三模块初稿，再反问补完（见 2.6 落地方式）。

> 💡 人数不做硬性要求。3 个人也能开张（小群反而更容易热），先有"铁杆5-10人"再滚雪球更稳。

> 💡 **极简 / 完整双模式（默认极简）**：路①默认只出「群类型 + 三大模块精简版（每模块一句话）+ 群公告雏形」的极简方案，5 秒能看懂；学员说"再细一点 / 给我完整版"，再展开公告全文、欢迎语五要素、破冰钩子、建群节奏表。别一上来堆满屏，吓退新人。

#### 路 ②：排一周群内容（五类群模板）

AI 只问两件事：**什么类型的群？客户是什么人？**

```
Q1: 这是兴趣群 / 会员服务群 / 垂类打卡群 / 养伙伴围观群 / 事业群？
    👤 "兴趣群，主要科普养生知识"

Q2: 群里客户主要是上班族 / 宝妈 / 老人？
    👤 "主要是上班族，也有几个宝妈"
```

→ 用户答完立即出**该类型群的一周排期表**（见核心方法论七），并标注：
- 每条内容的**信任层**（第一层认识你 / 第二层认可你 / 第三层信任你）
- 每条内容的**钩子 + 行动指令**（内容离业务更近，见核心方法论十一）
- 固定栏目的**建议时段**（按客户类型，由学员自行定具体几点）
- 产品/事业内容**占比**是否合规

> 💡 排期"按星期排固定栏目"即可，**不必排到每天每个时间点**（保持轻量，具体几点由学员按客户作息定）。

> 💡 **极简 / 完整双模式（默认极简）**：路②默认出「一周栏目骨架」（周几 + 栏目名 + 一句钩子），一屏看完；学员说"再细 / 给我完整排期表"，再展开信任层、钩子+行动指令、建议时段、占比校验等完整字段。

#### 路 ③：诊断群活跃度 / 要不要洗群

AI 先问 3 个问题（一次一个），走「诊断优先四步法」第1步：

```
Q1: 这是什么群？（兴趣/会员服务/垂类打卡/养伙伴围观/事业）
    👤 "兴趣群，艾灸客户的"

Q2: 建了多久了？
    👤 "快5个月了"

Q3: 群里虽然安静，但有没有人私下找你下单、或者介绍朋友来的？
    👤 "有，每个月还是有几单，就是群里没人说话"
```

→ 用户答完立即出**诊断结论 + 动作建议**（见核心方法论八）：

```
✅ 诊断结论：
  · 活跃率估算：偏低（<5%），但【有产出】
  · 生命周期：兴趣群 3-6 个月封顶，你已接近上限
  · 结论：这是"闷声出单群"，【不洗】

建议动作：
  1. 低频维护 + 私聊跟进（别急着解散，它在帮你出单）
  2. 用"核心用户带节奏"激活群氛围（见路④）
  3. 到了6个月如果产出也停了，再按洗群SOP操作
```

> 🔑 **核心心法**：洗群看"产出"，不看"热闹"。群安静但有单 = 不洗；群热闹但不成交 = 转化路径问题，也不是洗群。

AI 问：想聊什么主题？群现在什么状态？

→ 立即出：
1. **互动五步骤执行方案**（见核心方法论四）

```
   这就是把零售素材里"群托"改成的合规版——核心用户带动。
```

#### 路 ⑤：事业群带教（团队长培养伙伴）

AI 问：你现在有几个伙伴？他们处在什么阶段（新人/骨干/带头人）？

→ 立即出**事业群带教全链路方案**（见核心方法论十）：

```
✅ 事业群带教方案：

【伙伴分层】
  · 新人：刚起步，需要陪跑第一周
  · 骨干：能出单，需要话术复盘往上走
  · 带头人：能独立带，需要目标分解+表彰

【带教全链路】
  1. 招募/邀约：用"一对一咨询"钩子筛选有意愿的人
  2. 培训/上手：给工具（六大维度/四段式/排期模板）+ 陪跑第一周
  3. 实战带教：每周固定带教时间 + 话术复盘
  4. 转化/出单：帮伙伴走通"养客→处关系→挖需求→邀客户→给方案"第一单
  5. 表彰/毕业：标杆案例上墙 + 目标分解激励

【关键心法】
  · 带教≠培训：教的少而精，动作 > 原理
  · 先去做再完美：给伙伴舞台，别等"学完再干"
  · 培养优秀人才是核心：事业群不是发号施令，是训练场
```

### 🤖 AI 轻量模式触发机制（默认轻量，按需展开）

> 原则：默认一屏讲完、不堆长文。逻辑梳理 / 案例 按需展开，不重。但出现以下信号时，AI 主动"多说一句"，把隐性问题显性化。

**A. 轮次判断（同一节点打转）**
- 学员连续问 ≥3 轮仍在同一节点反复（如反复问"群怎么没人聊""我该发什么"）→ AI 主动切到「逻辑梳理」模式：先给群标配要素三模块 / 群间流转图，不再硬出文案，先想清楚再动手。

**B. 语义判断（深层信号）**
AI 从学员的话里识别两类隐性问题，主动介入：
- **深层运营逻辑不清**：出现"群到底干嘛的""我建了好几个群但都没用""不知道发什么" → 触发模块二「群标配要素」先想清楚（价值/人群/功能三模块），对症。
- **事业信心不坚定**：出现"这行能不能做""别人会不会觉得是拉人头""我带不动人" → 触发一句沁珮心法（经营人 > 经营流量；先去做再完美；成交是多次低压力接触），**不举具体数字、不指名案例**（模块六已取消独立案例库，案例仅作隐式养分）。

**轻量呈现规则**
- 默认一屏讲完，不展开长文；
- 案例 / 详情默认折叠，学员问"举个例子""再细说"才展开；
- 信心类信号触发时，用"轻量一句"而非整段，避免沉重。

## 📖 核心方法论

### 一、群运营闭环总框架

建群不是终点，是养客的起点。所有群的内容，最终要走到这条闭环上：

```
养客 → 处关系 → 挖需求 → 邀客户 → 给方案
  ↑                                    │
  └──────────── 复购/转介绍 ───────────┘
```

- **养客**：用内容（科普/生活/案例）让群友认识你、认可你
- **处关系**：互动五步骤，把陌生变熟悉
- **挖需求**：在聊天里发现群友的真实痛点
- **邀客户**：顺滑引出线下/私聊深度服务
- **给方案**：一对一给个性化建议（这时候才谈成交）
- **关键认知**：群是"养客场"，不是"成交场"。线上养熟，线下/私聊成交。

### 二、五类群定义与群间流转体系（v3.0 重构）

> 群的目的必须非常清楚，再拉人。人不怕少，怕目标模糊。
> v3.0 把 v2.0 的"4 类并列模板"升级为**一条漏斗/闭环**：兴趣群（验货）→ 会员服务/垂类打卡（已购）→ 养伙伴围观（养潜在伙伴）→ 事业群（带教）→ 伙伴自建兴趣群（闭环）。并**完全剔除闪群**（短期活动/微课拆给独立技能包，团购/首发套"垂类打卡群"逻辑——我们只做高价值社群运营内容）。

#### 2.1 命名约定（用团队长自己的话，不绑任何品牌课程术语）

本技能包面向多品牌学员（某营养保健品牌/某美妆品牌/某营养品牌/某美妆品牌/自主品牌等），**不用任何一家课程的黑话**，全部改用日常业务语言，降低上手门槛：

| 参考课程术语 | 本包采用 | 差异说明 |
|:---|:---|:---|
| 养生兴趣群（蓄水池） | **兴趣群** | 泛指一切未转化 + 潜在伙伴的蓄水池 |
| 主题售后服务群 | **会员服务群** | 直指"已购会员的长期服务" |
| 主题服务群（打卡） | **垂类打卡群** | 强调"垂类解决方案包 + 7/21/90 天周期" |
| 点将分享官 / 事业围观 | **养伙伴围观群** | 直指"养潜在伙伴"功能 |
| 事业群 | **事业群** | 同名，本包定位为"带教训练场" |

#### 2.2 五类群节点体系（漏斗 + 闭环）

对齐「六步展业链路」（拓客→养客→邀约→成交→养潜在伙伴→赋能伙伴）：

| 节点 | 群名 | 服务谁 | 核心目标 | 六步链路坐标 | 是否必须 |
|:---:|:---|:---|:---|:---|:---:|
| 1 | **兴趣群**（养客/验货） | 未转化 + 潜在伙伴 | 验货：展示真在做、给价值、建认知、邀线下 | 拓客·养客 | ✅ 必须 |
| 2 | **会员服务群**（长期售后） | 已购未伙伴 | 售后答疑、陪伴式顾问服务 | 成交后服务 | ⚠️ 条件必做 |
| 3 | **垂类打卡群**（7/21/90 天） | 买解决方案包的客户 | 驱动使用→见效→复购/跨品 | 成交·复购 | ✅ 必须（短平快出效果） |
| 4 | **养伙伴围观群** | 事业意向者 | 沉浸影响→启动事业 | 养潜在伙伴 | ✅ 独立节点（大团队做；小团队用 B 路径替代） |
| 5 | **事业群**（带教训练场） | 已开资格伙伴 | 学做教、出单、培养人 | 赋能伙伴 | ⚠️ 条件必做 |

> **节点 4 与 5 区别**：养伙伴围观群是"还没办手续、在门外看"；事业群是"已开资格、在门里练"。同一人从"意向"到"起步"的两站。

**会员服务群「必做条件」**（满足任一即建议独立建）：
1. 已购客户 ≥20 人且分散，1on1 跟进跟不上，需一对多统一服务
2. 产品需持续指导使用（内服周期、护肤流程、仪器操作等），售后答疑是刚需
3. 所在平台/品牌本身有会员层级体系，需统一运营会员权益
4. 有"气氛组"或帮手能承担长期群维护（精力够）
5. 客户有复购/跨品潜力，需长期养（非一锤子买卖）

**可不建 / 合并掉的情况**：
- 已购 <15 人且精力有限 → 并入**兴趣群**统一服务，或纯 1on1
- 产品简单无需指导 → 用**垂类打卡群**替代售后即可
- 个人独运营无帮手 → 靠 兴趣群 + 垂类打卡群 + 1on1，不硬建

> 原则：**会员服务群与垂类打卡群不是单选题**。多数团队两者都做，精力不够时垂类打卡群（短平快出效果）优先保。
> **客户可多群共存**：已购进了会员群，不必退出兴趣群；标签重叠正常，群间靠"价值递进"流转，不靠"踢人"。

#### 2.3 群间流转 SOP（让群接上业务结果）

```
                 ┌─────────────────────────────┐
                 │   兴趣群（养客/验货）          │  ← 最宽，免费进
                 │   展示真在做·给价值·建认知      │
                 └──────────────┬──────────────┘
           购买任何产品 ↓  （不是拉人头，是先当客户）
        ┌────────────────────────┴────────────────────────┐
        ↓                                                  ↓
┌──────────────────┐                          ┌──────────────────────┐
│ 会员服务群(长期)  │   解决方案包/主理人包      │  垂类打卡群(7/21/90天) │
│ 售后·答疑·陪伴   │  ─────────────→          │ 驱动使用→见效→复购    │
└──────────────────┘                          └──────────┬───────────┘
                                                          │ 体验价值/复购/跨品
                                                          ↓ 回兴趣群继续养 OR 进养伙伴
        ┌─────────────────────────────────────────────────────┘
        │ 展现事业兴趣 / 爱邀请人进群 / 主动问"怎么赚钱"
        ↓
  ┌─────────────────── 两条发现伙伴路径 ───────────────────┐
  │ A. 有实力大团队：拉进【养伙伴围观群】                      │
  │    看案例/服务/新人成长 → 沉浸式影响 → 启动事业            │
  │ B. 个人/小团队：在【兴趣群】里看谁最爱邀请人              │
  │    → 私聊 1on1 → 启动事业                                │
  └───────────────────────────┬─────────────────────────────┘
                               ↓ 办手续/开资格
                    ┌──────────────────────────┐
                    │   事业群（带教训练场）      │  ← 长期，1 个，深度信任
                    │   学做教·出单·培养人        │
                    └────────────┬─────────────┘
                               ↓ 赋能毕业（顾客服务顾客）
                    伙伴自建自己的【兴趣群】 → 闭环：顾客影响顾客
```

**流转触发条件（skill 教给学员的判断点）**
- 兴趣群 → 已购：学员主动私信"你这产品怎么买" / 参与打卡报名
- 垂类打卡 → 复购/跨品：打卡第 N 天晒变化 + 问"还能再调吗"
- 兴趣群 → 养伙伴（B 路径）：某人连续邀请 ≥3 人进群、或反复问事业机制
- 养伙伴围观 → 事业：沉浸 2-4 周后主动表达"我也想试试"
- 事业群 → 毕业：独立出单 + 能带 1 个新人 → 鼓励开自己的兴趣群

**流转钩子表（客户不主动时，学员主动发钩子触发流转）**

> 核心思路：学员不能等客户自己走。每个群都埋了"钩子"，观察到信号时主动发一句话把人往下一站推。钩子要轻、给价值、不推销。

| 流转方向 | 学员主动发钩子的时机（观察信号） | 钩子话术示例（可改） | 触发目的 |
|:---|:---|:---|:---|
| 兴趣群 → 垂类打卡/会员 | 某人反复问产品但没买；或群活跃 7-14 天后 | "你一直关心 XX，刚好开一期 21 天打卡营，本群老朋友优先体验，我拉你进？" | 让围观者先当客户，从"看"到"用" |
| 兴趣群 → 养伙伴（B路径） | 某人累计邀请 ≥3 人进群；或反复问"你这怎么赚钱" | "你每次都带朋友来，挺有召集力的～想不想看我背后怎么做的？私下聊两句" | 识别苗子，1on1 启动事业 |
| 垂类打卡 → 复购/跨品 | 打卡晒变化 + 问"还能再调吗" | "你这变化明显！顺带把睡眠/气血也调下？下期主题我给你留位" | 复购跨品，延长客户 LTV |
| 垂类打卡 → 兴趣群回流 | 打卡结束，活跃客户不想散 | "营结束了，但养生不停～拉你回主群，平时干货和案例都在那" | 不流失，持续养 |
| 养伙伴围观 → 事业群 | 沉浸 2-4 周，有人问"我也想试试" | "你看 XX 起步 1 个月就出单了，想正式起步我帮你办手续，进事业群带你" | 启动事业，转正 |
| 事业群 → 自建兴趣群 | 独立出单 + 能带 1 新人 | "你现在能带了，开个自己的兴趣群，我帮你站台，顾客服务顾客" | 闭环裂变，顾客影响顾客 |

> skill 落地方式：诊断/排期时，AI 在每个群节点末尾自动附"可主动发的流转钩子 1-2 条"并标注"何时发"，学员照着发就行，不费脑。

#### 2.4 群矩阵诊断画布（默认先做减法 · 首次诊断默认产出「我的展业群地图」）

**这是「首次诊断默认产出物」**——学员第一次来做诊断，AI 在收完维度后默认附上这张「我的展业群地图」一页纸，让他一眼看清"我有几个群、各服务业务哪一步、下一步往哪转"，而不是散在多处。学员也可随时说"帮我理一下我的群"主动调出。AI 依次问 4 个维度，输出**最小必做集 + 可删清单**：

| 输入维度 | 选项 | 对群矩阵的影响 |
|:---|:---|:---|
| ① 展业阶段 | 纯客户运营 / 想发展伙伴 / 已有团队 | 决定要不要事业群、养伙伴群 |
| ② 精力/团队 | 个人独运营 / 1-2 人帮手 / 有团队 | 决定会员服务群是否并入、角色分工 |
| ③ 产品形态 | 单品复购 / 解决方案包 / 多品类 | 决定垂类打卡群的"包"怎么设计 |
| ④ 当前已有群 | 列举 | 决定哪些保留、哪些合并/洗掉 |

**输出模板**
> 你的最小群矩阵 = ① 兴趣群（1 个，必须）+ ③ 垂类打卡群（1 个，必须）
> + 条件补充：客户多/有精力 → 加 ② 会员服务群；想发展伙伴 → 加 ⑤ 事业群；大团队 → 加 ④ 养伙伴围观群。
> 建议你**先删掉**：___（重叠/无产出的群），别让群拖累业务。

#### 2.5 合并 / 洗群机制（敢做减法，人不能丢）

> 底层逻辑：群多 = 群废；做得少 = 做得久。死群比没群更伤信任。学员要有"该合就合、该洗就洗"的底气，且知道洗完人去哪。

**一、什么时候该合并 / 洗群（触发原因）**
| 信号 | 判断 | 原因 |
|:---|:---|:---|
| 某群人数 <15 且无增长 | 合并到主群 | 小群维护成本 > 产出，精力应集中高价值群 |
| 多个相似标签小群（如"养肝群""祛湿群"都小） | 合并成"四季养生群" | 主题碎、人散，合并后内容更聚焦、活跃度更高 |
| 群活跃率 <5% 且 1 个月无任何人私聊下单/转化 | 洗掉 | 已成"死群"，留着损耗信任、占用注意力 |
| 群目标已完成（如训练营结束、活动收尾无后续） | 洗掉/归档 | 使命结束，不硬撑 |
| 群偏离业务（变闲聊群/广告死群/纯红包群） | 洗掉 | 不再服务展业，反而稀释 IP 专业感 |

**二、具体操作方式（step by step）**
1. **提前公告（提前 3 天）**：在群里说"这个群完成阶段使命啦，感谢陪伴～重要干货我整理好发你"。给心理缓冲，不突然。
2. **末次价值输出**：解散前发一份"收尾礼"（一篇干货 / 一个打卡表 / 一次答疑），让人带走价值，不空手走。
3. **引导迁移**：明确告诉留存客户"想继续跟着我的，进【兴趣群/会员群】（附二维码/邀请）"，给清晰去处。
4. **私聊重点客户**：高潜力 / 已购未转化事业客户，1on1 单独邀请到正确群，确保不流失。
5. **解散 / 归档**：到时间点击解散，或设为"只读归档"保留资料供回看（不占运营精力）。

**三、洗掉后的下一步动作（人不能丢）**
| 客户类型 | 洗群后去哪 / 做什么 |
|:---|:---|
| 高潜力客户（问过事业/爱邀请人） | 1on1 私聊跟进 → 引到 养伙伴围观群 或 直接启动事业 |
| 已购未复购客户 | 邀请进 会员服务群 或 下一期 垂类打卡群 |
| 普通围观客户 | 引导进 兴趣群 留存；朋友圈/公众号持续触达 |
| 全部留存客户 | 资料沉淀：把群里的干货转成"钩子资料/打卡表"发给每人，延续价值 |
| 洗掉的群本身 | 复盘：为什么废？是主题不对 / 节奏错 / 没人带？写一句教训，下个群避坑 |

> skill 落地方式：诊断到"有该洗的群"时，AI 不只说"建议洗"，而是直接给【公告文案 + 迁移指引 + 重点客户清单模板 + 下一步动作清单】，学员复制即用。

#### 2.6 群标配要素清单（建群前先想清楚，再出文案）

> **底层逻辑**：学员连"群怎么运营"都没理清，直接给文案他接不住。所以**任何群，在出文字之前，先产出这三大模块**——先想清楚，再发文案。这是"逻辑梳理"层，和"内容产出"层是两回事。

**输出原则：先大类后小类，不细碎。** 只分三个大模块，每个模块里用"要点 + 自问"呈现，不给冗长条目。

##### 群标配要素三大模块（通用模板）

**① 价值定位** —— 这个群为谁、解决什么问题
- 一句话群价值（如"帮产后妈妈用对减脂方案，不饿肚子瘦下来"）
- 自问：如果群友只记住一句"这个群对我有啥用"，应该是哪句？

**② 人群定位** —— 什么人、从哪来（人相关放一起）
- 适合标签的人：列举 2-3 个共性标签（如"已购减脂包 / 产后 1 年内 / 试过节食失败"）
- 从哪来：引流来源（朋友圈/公众号引流的陌生客、老客转介绍、线下活动扫码、已有群筛选）
- 自问：这批人现在处于什么阶段（未成交 / 已购 / 事业意向）？跟你的关系是哪一层？

**③ 功能描述** —— 解决什么问题、输出什么内容、什么节奏、什么角色（全归功能）
- 输出内容：每周固定栏目 + 价值主张（结合六大维度 / 三层信任，不硬广）
- 运营节奏：发什么、周几发、每天几条（参考各群排期模板，不在此展开）
- 角色分工：见下方「极简角色分工」
- **群公告与欢迎语（价值体系）**：并入功能描述——公告讲清"群是什么+核心内容+群规+价值确认+引导动作"（结合三层信任：认识你→认可你→信任你），欢迎语第一天带价值体系落地（详见核心方法论三）
- 自问：这个群在六步链路里站在哪一步？它要帮业务达成什么？

##### 五类群标配要素速查（先大类后小类，轻量版）

| 群 | 价值定位（为谁解啥） | 人群定位（标签+来源） | 功能描述（节奏/角色/内容） |
|:---|:---|:---|:---|
| **兴趣群** | 没成交的人验货：看你是否真在做、真有价值 | 未转化+潜在伙伴；来源：朋友圈/公众号引流、线下活动、转介绍 | 养认知+建信任；1 人运营；内容偏科普/生活/案例 |
| **会员服务群** | 已购的人被服务好、用对、用出感觉 | 已购未伙伴；来源：成交客户邀入 | 售后答疑+顾问陪伴；精力有限可并入兴趣群；不硬推 |
| **垂类打卡群** | 买方案包的人驱动使用→见效→复购 | 已购解决方案包；来源：兴趣群转化/直接购包 | 7/21/90天打卡；主线打卡+追踪+轻转化；短平快 |
| **养伙伴围观群** | 犹豫的人先进来看，想干 | 事业意向者；来源：兴趣群识别/转介绍 | 幕后+喜报+公开课；轻钩子不硬邀；1 人可运营 |
| **事业群** | 已开资格的人学做教、出单、带人 | 已开资格伙伴；来源：围观群转化/直接起步 | 带教+科普+品牌；团队长训练场；可设气氛组 |

##### 极简角色分工（默认不分工，达条件才设）

> 学员基本是个体创业者，1-2 人运营，**默认不分工**——自己就是唯一运营，群主即内容、即气氛。别一上来搞角色体系，那是大团队的负担。

**触发"分工"的条件（同时满足才建议设）：**
1. 核心团队成员 **> 5 人**（有可调动的帮手）
2. 同时在运营 **> 5 个群**（个人盯不过来）
3. 其中有**垂类打卡群 / 兴趣群**需要"氛围带动"（非纯专业群）

**满足条件时的极简配置（仅两类角色，别再多）：**
- **1 主运营**：负责内容输出、决策、重点客户跟进（专业事一人扛）
- **气氛组（若干）**：只做点赞、接龙、提问、带节奏——**不负责专业内容**，纯活跃气氛

> 对应你课程里的"炭精组"概念，本包统一叫**气氛组**，降门槛、去某家品牌黑话。

**skill 落地方式**：学员说"帮我建个群"或"给我个群方案"时，AI 先产出上面「三大模块」框架（价值/人群/功能），**不急着给文案**；若学员完全没思路，AI 先按五类群速查生成三板块初稿，再反问"你这个群主要服务谁、想达成什么"补完。等三模块确认，才进排期模板出文案。

#### 2.7 群间流转剧本（带天数节奏的完整动作链）

> 2.3 的「流转钩子表」是"一句话话术"。这里补**每条方向的完整动作链（带天数节奏）**，让学员照着 step by step 走，不卡在"发完钩子之后呢"。

**剧本1：兴趣群 → 垂类打卡群（让围观者先当客户）**
- 观察信号：某人反复问产品怎么用/效果，或群活跃满 7-14 天
- D1：私发钩子"你一直关心 XX，刚好开一期 21 天打卡营，老朋友优先体验，我拉你进？"
- D3：拉进垂类打卡群 @ta 参加第1天打卡开启，群内接龙
- D7：打卡晒变化 + 引导"你也来记录？"，自然带出复购/跨品
- **转化点**：第 14-21 天体验出价值后，顺滑复购/转介绍（不硬推）

**剧本2：兴趣群 → 养伙伴（B路径·小团队）**
- 观察信号：某人累计邀请 ≥3 人进群 / 反复问"你这怎么赚钱"
- D1：私聊"你每次都带朋友来，挺有召集力的～想不想看我背后怎么做的？私下聊两句"
- D3：1on1 展示日常服务/带团队真实一天（事业幕后），轻钩子不逼单
- D7：给"适合什么样的人"自测，持续私聊浸染（若有养伙伴围观群则拉进）
- **转化点**：沉浸 2-4 周表达"我也想试试" → 办手续进事业群

**剧本3：垂类打卡 → 复购 / 跨品**
- 观察信号：打卡第 N 天晒变化 + 问"还能再调吗"
- D1：回应"变化明显！顺带把睡眠/气血也调下？下期主题我给你留位"
- D3：发"相关产品怎么搭"科普（模板B 周四栏目），轻引导
- D7：复购/跨品下单或报名下期
- **转化点**：结业时做"下一周期/跨品"转化，不烂尾

**剧本4：垂类打卡 → 兴趣群回流**
- 观察信号：打卡结束，活跃客户不想散
- D1：群内"营结束了，但养生不停～拉你回主群，平时干货和案例都在那"+ 邀请
- D3：回兴趣群后 @ta 参加下周固定栏目，延续养
- **转化点**：持续养，下次新品/活动再激活

**剧本5：养伙伴围观 → 事业群**
- 观察信号：沉浸 2-4 周，有人问"我也想试试"
- D1：私聊"你看 XX 起步 1 个月就出单了，想正式起步我帮你办手续，进事业群带你"
- D3：拉进事业群，安排陪跑第一周（模板D 周二带教时间）
- D7：首次交作业/话术复盘，建立节奏
- **转化点**：独立出单 + 能带 1 新人 → 毕业开自己兴趣群

**剧本6：事业群 → 自建兴趣群**
- 观察信号：伙伴独立出单 + 能带 1 新人
- D1：公开表彰"你现在能带了，开个自己的兴趣群，我帮你站台"
- D3：帮其建群、给三模块初稿、站台第一次分享
- D7：顾客服务顾客，闭环裂变
- **转化点**：其群活跃 → 你做"群的群"，放大团队

#### 2.8 业务结果基准与轻量复盘（让群运营对上业绩）

> 群不是"养着好玩"，每类群都要服务一个业务结果。本技能包不编新数字——以下锚定文档已有健康度基准（群转化率≥3%达标、活跃率分级、核心活动参与率10-20%），**倒推每群该盯的结果指标**，让学员知道"我这群这月该产出啥"。

**每群业务结果基准（倒推目标，按群类型）**

| 群类型 | 核心业务结果（该盯什么） | 健康参考（锚定已有基准） |
|:---|:---|:---|
| 兴趣群 | 每月有成员进下一站（垂类/会员/事业意向）的比例；私聊咨询/加好友数 | 群转化率≥3%达标（成交÷群人数）；靠"价值递进"流转，不靠踢人 |
| 会员服务群 | 复购率 / 转介绍数（被服务好自然来） | 复购靠服务，不靠群喊"快买"；精力有限并入兴趣群 |
| 垂类打卡群 | 打卡完成率 + 结业转化（复购/跨品/转事业） | 周期结束必做"结业+转化"不烂尾；已转化群产品占比≤50% |
| 养伙伴围观群 | 意向→事业转化率（多少人从"看"到"想干"） | 沉浸2-4周表达"想试试"→ 启动事业；不硬邀不逼单 |
| 事业群 | 新人首单周期 / 骨干晋级率 / 带教出单数 | 培养人>卖货；毕业标准=独立出单+能带1新人 |

> 用法：不要把数字当 KPI 压学员。用"自身环比"看增长（这月比上月多几个进下一站），比绝对值更准、更不焦虑。

**轻量复盘四问（周/月各做一次，5 分钟）**

学员照着答，AI 可主动在每月末温和提示一次：
1. **这月哪类群有产出？（单/复购/转介绍/事业加入）** —— 有产出的保住，别洗
2. **哪类群一直在养、没动静？** —— 看是"闷声出单"（不洗）还是"定位错"（重启内容/合并）
3. **群间流转发生没？（多少人从兴趣→垂类/事业）** —— 没流转 = 钩子没发或没发对，回看 2.3/2.7
4. **我精力顾得过来几个？** —— 超了就合并/聚焦（联动第7维与 2.5 洗群）

**指标看板（一句话模板，AI 默认月产出，配合 2.4 展业群地图）**
> 我的展业月报：活跃群__个 / 本月产出（单__·复购__·转介绍__·事业__） / 流转__人 / 下一步__

### 三、从 0 到 1 建群 SOP（欢迎语 + 公告 + 破冰）

#### 群欢迎语五要素（来自群运营基础课）

1. **群是什么**（一句话价值，如"这是XX养生交流群，分享中医调理知识，帮大家少走弯路"）
2. **群核心内容**（每周固定栏目，如"每周三养生小课堂，每周六案例分享"）
3. **群规和群文化**（如"不发广告、不私加人、友好交流"）
4. **群价值确认**（再强调一次加入能得到什么）
5. **引导动作**（欢迎新人 + 引导自我介绍 / 领福利）

#### 群公告结构（群运营基础三问衍生）

- **服务谁**：群成员共性标签（至少 3 个，如"办卡用户 / 中华养生 / 热爱生活"）
- **提供什么价值**：群是做什么的
- **如何提供价值**：每周固定时间栏目（形成期待）

> 示例群公告：
> "【本群是什么】XX养生交流群，每周分享中医调理干货，帮大家少走弯路。
> 【你来得到什么】每周三养生小课堂、每周六真实案例分享、不定期福利。
> 【群规】不发广告、不私加群友、友好交流。
> 【进群动作】发一条自我介绍（你是谁+最想改善的养生问题），群主送你一份见面礼🎁（具体钩子看群主置顶）"

#### 破冰钩子多版本（引导群友发言的"诱饵"）

> 核心逻辑：**引导群友发言（自我介绍/投票/晒图）+ 配一个钩子福利**。钩子不是只有红包，经销商更常用的是"一对一咨询/免费体测/小礼物/活动名额"。下面给 5 个版本，由学员按自己的产品和客群选。

| 版本 | 钩子内容 | 适合场景 | 话术示例（可直接套） |
|:---|:---|:---|:---|
| **A. 一对一咨询** | 自我介绍后，群主免费私聊答疑/出方案 | 咨询服务型（中医体质/营养/护肤） | "进群发一条自我介绍，我抽 3 位免费做 1 对 1 体质分析 👇" |
| **B. 免费体测/体验** | 自我介绍+到店/到货领一次免费检测或体验装 | 有线下或实物产品（艾灸/护肤/体检） | "自我介绍+你最想改善的问题，到店免费体测一次（限前 10 名）" |
| **C. 小礼物/样品** | 自我介绍领实物小样、试用装、养生茶包 | 有低成本实物赠品（茶包/贴/手册） | "发自我介绍就能领一份养生小礼包，群主私你地址📦" |
| **D. 活动名额** | 自我介绍优先锁定线下沙龙/线上课/体验活动席位 | 有活动承接（茶修/沙龙/微课） | "本周六申时茶会，自我介绍报名优先留座，仅 8 席" |
| **E. 资料/工具包** | 自我介绍领一份电子干货（自查表/食谱/打卡表） | 纯线上、无实物成本（最适合新人起步） | "发自我介绍，私你一份《体质自查表》电子版，自己就能测" |

> 💡 选钩子 3 原则：① 成本可控（新人优先 E 或 A，几乎零成本）② 和群目的挂钩（兴趣群用 A/E 养认知，垂类打卡群用 D 促到店/复购，事业群用 A 展专业）③ 限时限量（"前 10 名/本周有效"制造稀缺）

#### 建群节奏（从 0 到 1）

| 时间 | 动作 | 说明 |
|:---:|:---|:---|
| 第 1 天 | 发欢迎语+公告 + 引导 3-5 人自我介绍破冰 | 用"发一条自我介绍 + 领钩子福利"降低门槛 |
| 第 1 周 | **密集破冰**：每天 3-5 个低门槛话题 + 小额福利 | 前14天活跃率>40% = 破冰成功，要把活跃用户训出来 |
| 第 2 周起 | 进入固定栏目节奏（用核心方法论七排期模板） | 从"破冰"过渡到"价值输出" |

破冰话题示例（低门槛）：
- "大家平时最困扰的亚健康问题是什么？投票👆"
- "一句话介绍自己+你的养生小习惯"
- "猜猜今天分享的主题？提示：和'寒'有关"

> 反例（行业踩坑）：建群3天就冷场，根因是**进群路径和分层没设对** + 没固定节奏，用户不知道怎么参与就潜水。所以"欢迎语说清价值+固定栏目"是第一周救命绳。

### 四、群互动五步骤 + 话题库

#### 互动五步骤（用于固定栏目和日常激活）

```
1. 前一天预告 → 2. 提前2-6小时预热 → 3. 主题互动（抛出话题）
   → 4. 结束后总结答案 → 5. 第二天促进行动
```

#### 好话题的 3 个特征（来自零售素材 UGC 案例抽象）

1. **具体场景**：人人都能对号入座（"你有没有一到换季就干咳？"）
2. **人人可答**：不需要专业知识，张嘴就能说（投票/接龙/晒图）
3. **自然带出专业**：你做"总结者"，在回答里轻轻植入知识点

**可套用的话题模板：**
- 投票型："秋天你最怕哪种不适？A 干咳 B 皮肤干 C 睡不好（投票👆）"
- 晒图型："今天泡了什么养生茶？晒出来我帮你看看体质对不对🍵"
- 接龙型："一句话说说你今年最想改善的身体问题，接龙走起"
- 故事型："我有个客户坚持灸了一个月，变化挺明显的，你们想听吗？"

> ⚠️ 注意：行业素材里"群托/水军刷屏控评"的手法**禁用**——我们用"核心用户/KOC带动"（见核心方法论九），真实信任才是底色。

### 五、内容制作六大维度（群也用 · 内嵌共享方法论）

> **内嵌声明**：以下六大维度与朋友圈技能包完全一致，已内嵌本技能包，**本技能包可独立使用，无需另行安装朋友圈技能包**。若已安装朋友圈技能包，两者方法论一致，可互相印证。

| 维度 | 核心逻辑 | 群里怎么用 |
|:---|:---|:---|
| **认知升维** | 打破错误认知，做"导航仪" | 周一认知误区科普 |
| **情绪疗愈** | 承认客户的累，做"解语花" | 深夜情绪共鸣 |
| **生活美学** | 健康生活的质感，做"种草机" | 茶桌/早餐/运动打卡 |
| **事业轻感** | 分享积极改变，做"同行者" | 事业群带教 |
| **过程纪实** | 展示真实努力，做"透明人" | "为了选好产品对比10家" |
| **认知普惠** | 一句话干货，做"布施者" | 早安养生tip |

**使用规则**：六大维度轮着来，不要连续3天同一维度，群会"扁"。

### 六、三层信任体系（群版 · 内嵌共享方法论）

> **内嵌声明**：同核心方法论五，已内嵌，独立可用。

群是一个**三层的信任系统**。每一层缺了，下一层全白搭。

| 层 | 目的 | 怎么建 | 发布频率 | 内容示例 |
|:---|:---|:---|:---:|:---|
| **第一层：认识你** | 让群友知道你是真实的人 | 发真实生活内容 | 每天至少1条 | 早安tip/工作照/生活碎片 |
| **第二层：认可你** | 让群友认可你的专业度 | 发专业观点/行业认知 | 每天至少1条 | "补钙三个误区""为什么越节食越胖" |
| **第三层：信任你** | 让群友相信你能解决问题 | 发客户案例/方法SOP | 隔天1条 | "一个客户反馈""我是怎么帮她解决的" |

**⚠️ 重要认知：线上养客 vs 线下成交**
- 群不是用来成交的，是用来养客的
- 线上（朋友圈/社群）：养客 → 建立认知 → 让客户想见你
- 线下（活动/私聊/体验）：成交 → 建立深度信任 → 让客户想再来

### 七、群日常排期 SOP（按五类群排）

> 群内容要"栏目化"：每周固定栏目，让用户形成期待。和朋友圈"一周发圈计划"一个逻辑，但群用**固定栏目**而非每天随机刷。

#### 模板A：兴趣群一周内容排期（目标：养客户/验货 · 产品占比 ≤ 30%）

| 星期 | 固定栏目 | 内容维度（六大维度） | 信任层 | 钩子+行动指令 |
|:---:|:---|:---|:---:|:---|
| 周一 | 认知升维 | 打破误区（如"你以为湿气重才拔罐？错"） | 二·认可你 | 投票"你中了几条"→ 私聊领自测表 |
| 周二 | 生活美学 | 一条生活+养生小确幸（配图） | 一·认识你 | 晒图接龙"你的养生角落"→ 评论区互动 |
| 周三 | 🔥养生小课堂 | 知识科普（互动五步骤走完整流程） | 二·认可你 | 预告周四答疑 → 群内报名 |
| 周四 | 客户见证 | 经同意的反馈/改变故事 | 三·信任你 | "想同款方案？私我"→ 引导咨询 |

#### 排期铁律（写进技能包给学员的提醒）

1. **固定栏目固定时间（具体几点由学员按客户作息定）**——用户会形成"周三晚上有课"的期待，比随机发更稳。
2. **每天主线 1-2 条，别刷屏**——过度打扰必退群。
3. **产品/事业内容占比**：兴趣群 ≤30%、会员服务群/垂类打卡群 ≤50%、事业群可高但也要穿插生活。

### 八、群活跃度诊断清单（要不要洗群，看"产出"）

#### 核心原则

> **洗群 ≠ 看群热不热闹，是看"产出"。**

- 群安静，但到了生命周期（兴趣群/会员服务群/垂类打卡群按各自周期；事业群 3~6 个月、可延长至一年）→ **洗**。
- 群安静，但没到生命周期、有人互动（哪怕少）、**有销售/有转化/有事业加入** → **不洗**，这是"闷声出单"的群，低频维护+私聊跟进即可。
- 群热闹但零成交 → 不是洗群问题，是**转化路径**问题（福利拉动的虚假活跃）。
- **不要**用"多少天没人说话"当死规则——用**百分比 + 产出**综合判断。

> 📚 **原课程体系怎么写**（来自群运营基础课「群的基本结构与运营分工」）
> 课程把群分为长期群与快闪群两类并定义周期。本包**剔除短期活动群（快闪/微课拆给独立技能包）**，只保留高价值社群运营内容。
> 周期对齐：
> - **长期群：3~6 个月**（可持续链接，难点是持续运营）—— 兴趣群、会员服务群、事业群归此类
> - **垂类打卡群：7/21/90 天**（按解决方案包周期，短平快出效果）—— 打卡结束即"结业+转化"
>
> ✅ **已确认（沁珮拍板）**：兴趣群 / 会员服务群 生命周期 **3~6 个月（最多不超 6 个月）**；事业群 **3~6 个月，可延长至一年**（团队带教周期长，旧人毕业+新人注入，可持续运营）；垂类打卡群按 7/21/90 天各自周期计。

#### 群活跃度量化基准（行业公开数据 2024-2025）

> 活跃率 = 日均发言人数 ÷ 群总人数

| 活跃率 | 等级 | 判断 |
|:---:|:---|:---|
| ≥ 20% | 高度活跃（优质社群） | 健康，维持 |
| 10% ~ 20% | 中度活跃（正常健康） | 健康，维持 |
| 5% ~ 10% | 轻度活跃（有待激活） | 轻度激活，不洗 |
| < 5% | 低活跃 / 潜在死群 | 看产出和生命周期决定 |

辅助指标：
- **核心活动参与率**：健康中等群应稳定在 **10%-20%**（参与活动人数÷总人数）
- **群转化率** ≥ 3%（成交人数÷群总人数）即达标，自身环比增长更关键
- **单日退群率 > 3%** → 红色预警，内容出问题
- **48小时无互动成员占比 > 70%** → 群进入"脑死亡"状态（参考值）

> ⚠️ 这些百分比是**健康度信号，不是洗群判决**。洗群的硬指标只有一个：**生命周期到了 + 产出停滞**。

#### 诊断决策矩阵（结合沁珮观点 + 数据）

| 互动率 | 有产出？（销售/复购/事业加入） | 生命周期 | 结论 | 动作 |
|:---:|:---:|:---:|:---|:---|
| < 5% | ✅ 有（哪怕少） | < 生命周期 | **不洗** | 闷声出单群，保持低频维护 + 私聊跟进 |
| < 5% | ❌ 无 | 已到/接近生命周期 | **洗** | 按洗群SOP执行（见下） |
| < 5% | ❌ 无 | 远未到生命周期 | **先救内容** | 不是洗群，是群定位/内容错了，重启互动五步骤 |
| 5%-10% | 有/无 | — | **激活** | 轻度激活，不用洗 |
| ≥ 10% | — | — | **健康** | 维持节奏 |

#### 两个典型"假死群"的判别

**① 只有群主发、没人回，但有人私聊下单**
→ 有产出，**不洗**。群氛围弱而已，用"自己人带节奏"+ 互动五步骤激活。
（行业案例：某美妆品牌给**休眠用户（30天无互动）**寄"你很久没来看我了"手写小样，唤醒率 41%，ROI 1:8——说明沉默用户里藏着产出。）

**② 群很热闹（接龙/红包积极）但不成交**
→ 福利拉动的**虚假活跃**，不是洗群问题，是转化路径问题。
→ 动作：把互动引导到交易页 / 私聊一对一挖需求（养客→处关系→挖需求→邀客户→给方案）。

#### 群的自然生命周期

| 群类型 | 建议生命周期 | 到期处理 |
|:---|:---|:---|
| 兴趣群 | 3-6 个月（最多不超6个月） | 不活跃且无产出 → 洗 |
| 会员服务群 | 3-6 个月 | 不活跃且无产出 → 洗或并入兴趣群 |
| 垂类打卡群（7/21/90天） | 按打卡周期 + 可延长跟进 | 周期结束做"结业+转化"，不活跃无产出→洗或转兴趣群 |
| 事业群 | 3-6 个月（可延长至一年） | 持续注入新伙伴，旧人毕业 |

> 行业参考：社群典型 **90 天生命周期**（1-14天破冰、15-45天活跃、46-75天转化、76-90天重启/沉淀）。到了重启期，用"筛核心20%开小群做会员专属，原群低频维护"策略。

#### 洗群 SOP（具体操作见核心方法论二·2.5 合并/洗群机制）

> 洗群不是"看热闹"，是看"产出 + 生命周期"。完整触发原因、5 步操作（提前公告→末次价值→引导迁移→私聊重点→解散归档）、洗后下一步动作（按客户类型分流），见 **核心方法论二·2.5**。

精简口诀：提前 3 天预告 → 末次价值输出 → 引导迁移到正确群 → 重点客户 1on1 不流失 → 到点解散/归档。洗完人不能丢，资料沉淀成钩子资料延续价值。

### 九、群成员角色识别

> 群里不是所有人一样。认出角色，你才知道"该对谁用力"。

#### 四类角色（零售版功能分层 + 我们知识库画像整合）

| 角色 | 特征 | 你怎么用 |
|:---|:---|:---|
| **强IP / 群主（你）** | 定调者、内容源、信任锚 | 你负责"定调+输出价值+总结"，不抢话但镇场 |
| **核心用户 / KOC** | 活跃、爱分享、有影响力、信你 | **重点维护**：让TA先答、先晒，带动氛围（这就是把"群托"改成的合规版） |
| **普通成员** | 大多数，偶尔互动或潜水 | 用互动五步骤激活，别指望人人都聊 |
| **潜水者** | 不说话，但可能默默看、甚至私聊下单 | 别急着踢——"假死群"里藏着产出（见核心方法论八） |

#### ⚠️ 禁用"群托/水军"控评手法

零售社群素材多次出现"群托刷屏、转移负面"——属控评/刷单灰色手法，**与我们"真实信任经营"定位冲突，全部不用**。

**替代方案：核心用户/KOC 带动氛围**
- 从活跃群友里筛选 KOC（私聊问建议、给特殊感与参与感）
- 让 KOC 在固定栏目里"打样"（先晒茶/先分享），群主做"捧场王+总结者"
- 真实互动比刷屏控评更稳、更长久

### 十、事业群带教 SOP（独立模块 · 团队长培养伙伴）

> 事业群不是发号施令的地方，是**团队长的训练场**。核心目标是**培养优秀人才**——帮伙伴从"用的人"变成"做的人"。

#### 伙伴分层（不同层不同带教重点）

| 层级 | 特征 | 带教重点 |
|:---|:---|:---|
| **新人** | 刚起步，不会开口 | 陪跑第一周，给工具+话术模板，先去做 |
| **骨干** | 能出单，但卡在某个环节 | 话术复盘、卡点突破，往上走 |
| **带头人** | 能独立带小群/带人 | 目标分解 + 表彰，给舞台 |

#### 带教全链路（去标识化版，融合教育品牌团队运营精华）

```
1. 招募/邀约
   → 用"一对一咨询"钩子（核心方法论三 A版）筛选有意愿的人
   → 不是拉人头，是找"事业目标坚定"的伙伴

2. 培训/上手
   → 给工具：六大维度 / 黄金四段式 / 排期模板 / 三层信任
   → 陪跑第一周：一起建群、一起排内容，做给他看

3. 实战带教
   → 每周固定"带教时间"（模板D 周二）
   → 话术复盘：把伙伴遇到的卡点变成群内公开课

4. 转化/出单
   → 帮伙伴走通第一单："养客→处关系→挖需求→邀客户→给方案"
   → 先去做再完美，别等"学完再干"

5. 表彰/毕业
   → 标杆案例上墙（模板D 周三"伙伴案例"）
   → 目标分解 + 正向激励，让伙伴看见自己的成长
```

#### KOC 培育机制（零售素材融合）

- 从活跃群友筛选有意愿/有影响力的伙伴
- 私聊问建议、给"内测资格/优先名额"等特殊感
- 让TA在群里带节奏，自然成为"自己人"

#### 关键心法（沁珮方法论）

- **带教 ≠ 培训**：教的少而精，动作 > 原理（成年人学习是问题导向、即时有用）
- **先去做再完美**：给伙伴舞台，在实战里长本事，不是先听课
- **培养优秀人才是核心**：事业群的价值不是你多能说，是伙伴因为你而成长

### 十一、内容产出四标签（v2.0 双模式 · 不强制）

> **决策（沁珮拍板）**：不强制每条都标四标签。给学员两个选择——**简洁模式**直接出可用内容；**完整模式**在内容后附"四标签"说明，方便复盘和带教。

**四标签定义：**

| 标签 | 含义 | 作用 |
|:---|:---|:---|
| **① 目标层** | 这条服务哪个群目标/转化阶段（养客/复购/事业/激活…） | 让每条内容"有方向"，不瞎发 |
| **② 信任层** | 第一层认识你 / 第二层认可你 / 第三层信任你 | 保证三层均衡，不偏科 |
| **③ 钩子设计** | 用什么钩子引发互动或私聊（投票/晒图/咨询/打卡/资料…） | 内容离业务更近，能"收" |
| **④ 行动指令** | 希望群友做什么动作（发言/私聊/到店/打卡/转发/邀约） | 把"看了"变成"做了" |

**两种模式怎么用：**

- **简洁模式（默认）**：AI 直接出群内容文案，不附加标签。适合老手、赶时间、只要能用。
- **完整模式（可切换）**：AI 出内容后，附一段四标签说明，如：
  ```
  【四标签】目标层：养客-破认知 ｜ 信任层：二·认可你 ｜ 钩子：投票自测 ｜ 行动：私聊领表
  ```
  适合带教伙伴、做培训、想搞清"为什么这么写"的人。

> 💡 AI 在产出时主动问一句："要带四标签说明吗？还是直接出内容？"——学员选，不默认强制。排期表里默认带"钩子+行动指令"列（见核心方法论七），因为那是"内容离业务近"的硬要求；四标签完整说明按需开关。

## 📖 补充方法论：群日常运营提醒

### 群的"轻维护"节奏

- **@全体**：每周 ≤ 2 次（过度打扰必退群）
- **固定栏目**：每周 1-2 次即可，重在"固定"而非"多"
- **日常互动**：看到群友发言就接，做"捧场王"，比定时发干货更拉近距离
- **退群预警**：单日退群率 > 3% → 立刻自查近期内容

### 群的合规底线

- **不夸大**：不用"治愈/根除/最有效/第一"
- **不制造焦虑**：鼓励接纳，不恐吓
- **建议咨询**：涉及诊断/停药，引导找正规医生

## 💡 进阶玩法

1. **群矩阵**：兴趣群（广，验货）→ 会员服务群/垂类打卡群（深，已转化）→ 养伙伴围观群（养潜在伙伴）→ 事业群（带人），闭环递进。
2. **内容日历**：每周日花 10 分钟让 AI 生成下周群内容库，每天挑着发。
3. **KOC 孵化**：从兴趣群识别活跃用户 → 私聊培养 → 转事业群，形成人才漏斗。
4. **假死群激活**：别急着洗，先私聊"休眠用户"送个小福利（行业唤醒率可达40%+）。
5. **事业群毕业制**：老伙伴"毕业"去开自己的群，你做"群的群"，放大团队。
6. **垂类打卡群结业转化**：7/21/90天打卡结束，立刻做复购/跨品/转事业引导，不烂尾。
7. **赛道定制**：诊断时套"赛道案例库"，让 AI 说出你的行业口吻，亲切又专业。

## 📚 合规发布最后一道防线

在群发任何内容前，心里默念这三句：

- **我不治病**：群里绝不说"治好了XX病"
- **我不绝对**：群里绝不说"最有效"、"第一"
- **我是分享**：多用"我个人觉得"、"这是我自己的经验"、"建议咨询医生"

> - 功效宣称：用"养护/舒压/辅助/日常调理"替代"治愈/根除/抗癌/治病"
