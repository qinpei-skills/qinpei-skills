# 模板01 · 价值观/认知口播（AI 生成前必加载本模板）

> **这一格干什么用**：让刷到你视频的人觉得"这人说得对，我认同"——认同你的人才会关注你。适合讲：你为什么坚持做这行、你怎么看行业里的乱象、你的做事底线。
> **双版本规格（默认双稿齐出，学员指定单版才单出）**：
> - 📱 **60秒内版**：约240字（上限260）——1个观点+1个例子，节奏快
> - 🖥️ **3分钟中视频版**：约700字（上限750）——同一内核展开：观点+2-3层递进+例子讲透+小结论收
> - 默认两版都出，先60秒后3分钟，学员指定单版才单出；3分钟版是展开不是灌水。

---

## 第一步：选一个"嘈杂场景"（你的观众正在经历的）

价值观口播的起点不是"我要讲道理"，是**观众心里正憋着的那口气**。让学员选一个：

| 场景 | 观众心里的那句话 |
|:---|:---|
| A. 被贴标签 | "你们做这个的，不就是卖保健品的吗" |
| B. 被质疑 | 家人反对、朋友疏远，"正经工作不好吗" |
| C. 看不惯乱象 | 同行夸大宣传，把客户当韭菜，自己看不下去 |
| D. 自我怀疑 | "行情这么难，是不是我不适合干这行" |
| E. 想被看见 | 明明认真做事，却没人知道这行的好 |

> 学员说不上来 → AI 问一句："最近有没有哪句话、哪件事，让你特别想说'不是这样的'？"——那句话就是这条视频。

---

## 第二步：按结构填空（四件套）

### 【开头 · 判断】第一句 = 判断句（前5秒立住：判断句+紧跟的人设句=判决书）

从下面的起手里选一句式改写（读 `references/hook-library.md` 第二节）：
- 身份反差型：`都说做养生这行的心最黑，恰恰是这行人里，我见过最多较真的人`
- 时间资历型：`做这行第N年（换成你真实的年头），我最怕别人跟我说的一句话是："你们不就是卖药的嘛"`

### 【人设句 · 紧跟开头】第二三句就立住"凭什么我讲" 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】，禁只报年头。

🔴 人设不拖到中段、不单独磨叽一段——紧跟开头一句就给：

- 判断句后面**马上接**：`我【填：做这行的年头】年，【填：一个真实身份，比如"给街坊邻居做调理的"】`＋一个真实处境细节【填】
- 例：`都说干养生这行的心最黑。（判断）→ 我做了8年，见过的较真人，比哪个行业都多。（人设句，紧跟）`

### 【第三段 · 干货】我的认知 = 一个反差判断 + 一个具体例子

价值观格的"干货"不是知识点，是**你看事情的角度**：
- 判断：`这行有没有乱象？有。但乱的不是行，是人。`
- 例子：【填：你亲眼所见的一个对比——一个乱象细节 vs 一个认真做事的细节】
- （只讲一个观点。想讲第二个 → 拆成下一条）
- 3分钟版加：为什么这行会这样（一层行业观察）＋第二个例子，层次递进不换观点

### 【收尾 · 钩子 + CTA】价值观落地 + 勾住下一条

- 金句收（从你的理念里长出来，不抄名言）：`【填：你常挂在嘴边的那句话，比如"养生不是花钱，是过日子"】`——🔴 学员从没给过理念 → 出稿前必须先问一句：「这行里你最常跟客户说的一句话是什么？」拿到真理念才写，禁凭空造金句
- **钩子**（🔴 必问学员、永不代编——你真有的才算数）：
  - 系列钩：`【填：你真打算做的系列，比如"这是我看这行的第3条，下一条讲XX"】`
  - 主页钩：`【填：你主页真放了的东西，比如"我主页放了四季食养清单"】`
  - 没有钩子 → 最稳默认：`关注我，这类内容我每周都讲`（问一句"你每周真能更吗？"）

## 完整示例骨架（60秒内版；标【填】处学员填真事）

> **主题：被贴标签（场景A）**

都说干养生这行的心最黑。【开头·判断】

我做了【填：X】年，见过的较真人，比哪个行业都多。【人设句·紧跟】见过【填：真实场景——比如凌晨一点，一个做养生的姐妹还在翻客户体检单，就为给人家配得更准一点】，也见过【填：你见过的乱象——比如有人把一款东西吹得包治百病，卖完就换城市】。所以别人说"你们不就是卖保健品的嘛"，我不辩解——行不行，看人，不看行。【认知展开】

我们这行里，真有一批人，是把客户的身体当自己家老人的身体在操心。这批人不发声，声音就全是那些人的了。【干货收】

养生不是花钱，是过日子。【金句】认同的，关注我——【填：钩子，你真有的才算数，比如"下一条我讲讲这行里最容易被骗的三种人"／"我主页放了给家人的四季食养清单"】。【钩子+CTA】

**（60秒内版约240字。3分钟版在【认知展开】和【干货收】之间加两层：为什么这行会变成这样（一层行业观察）＋第二个真实对比例子，钩子和开头不变。示例中"较真的人""凌晨翻体检单"仅为骨架示意——学员必须换成自己亲历的真实细节，AI 不得代编；钩子位同理，AI 不得代编承诺。）**

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 第一句是判断句？没有"大家好/今天聊"铺垫？没有"这话扎心"式点破？
- [ ] **人设句紧跟开头了吗（第二三句内立住）？**没有拖到中段？
- [ ] 人设段是"身份+真实处境"，不是在吹证书和头衔？
- [ ] 全稿只有一个观点？（第二个观点已建议拆条）
- [ ] **结尾有钩子吗？钩子是学员真有的东西吗？**（AI 没有代编任何承诺？）
- [ ] 【填】位都有填写引导？AI 没有代编任何人物细节？
- [ ] 合规四关过闸：无体质词（已转场景词）/ 无功效词 / 无敏感行业词 / CTA 在最稳档？
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 版本对版吗？（60秒内版240字±10% / 3分钟版700字±10%，按含【填】占位的交付稿计；学员回填后超上限 → 帮压缩复测）
- [ ] 时长标注了？附了一句拍摄提示？
