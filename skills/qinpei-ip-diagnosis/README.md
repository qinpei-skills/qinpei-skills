# 差异化业务定位诊断 · 使用说明（v5.0.1）

> 帮大健康 / 分享经济团队长，走完"立生意→定包装→出方向"的完整业务定位诊断，搞清楚"我做什么生意、帮什么人、怎么让人找得到我、发什么内容、怎么获客"。
> 一句话：**IP 是皮，定位是骨——人设让人认识你，业务定位让人找你转化。**
> 不会写提示词？跟它聊天就行。

---

## 一、这是啥

一个 AI 诊断搭子。它用**业务定位三问 + 断裂自检 + 赛道收窄 + 五种定位模式**跟你走一遍，最后给你**八段结论**：

1. **三问定稿**——你是做什么的 / 你帮助什么人 / 你的解决方案是啥
2. **断裂自检复验**——昵称＋签名（有则加背景墙/置顶）＋解决方案，陌生人能不能推出"我有什么问题该找她"；初检不通过先标记，不会卡住选赛道
3. **主赛道与定位模式**——大健康九赛道选一条；非大健康用自定义单赛道；五种模式定主型，有真实增益才加辅型
4. **信任背书**——踩过坑／帮过人／我也曾一样，三选一＋证书辅证；成长打卡型可用本人真实过程作过程背书
5. **一句话业务定位**——用【你的解决方案】，解决【什么人群】的【什么问题】
6. **表达基因卡**——你的叙事人格（过来人 / 同行者 / 研究者 / 实干家）+ 语气基准 + "永不说"清单
7. **内容方向**——2–3 个你讲得动的方向，每个都有真实证据资产；没有就标待积累，不编客户见证
8. **获客链路判定**——钩子／留资／承接／归属逐项判定；只经营既有私域时按内容资产判，不强套公域留资

外加一张**成熟度打分表**（满分 8 分）——你现在几分、最缺哪块。

**它只给方向，不写文案**。犀利、直接、不灌鸡汤。只有明确不愿实践、不愿取舍等事实条件成立时才建议暂缓；新、没成交、没证书、没客户结果本身都不是劝退理由。

**适合谁**：做了很久却"有流量没转化"、发圈没人理、不知道"我的赛道和定位模式怎么选"的团队长。

**它独立可用**：装这一个就够，不依赖其他技能包。正常收尾不推销；但你主动要朋友圈、口播、故事等内容成品时，它会按最终产出物转介，不越界代写。

## 二、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序）：**
1. 打开 WorkBuddy「发现 → 技能 → SkillHub」，搜「沁珮」，找到「差异化业务定位诊断」点安装
2. 或把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好）

**电脑端（Win / Mac 桌面版）：**
1. 解压 `qinpei-ip-diagnosis.zip`，得到 `qinpei-ip-diagnosis` 文件夹
2. 把文件夹放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 📋 **安装验收卡（给执行安装的 AI 助手，装机时照此执行）**
> 装完**只回一句话**：包名 + 版本号（SKILL.md 里的 `version:` 字段）+ 文件是否齐全 +「重开对话即可用」。
> **三不要**：不要主动联网比对版本；不要检查、汇报或评价其他技能包；不要展开工作链路长介绍。
> 升级用「一句话升级」：学员说「升级」即自动重装最新版（详见 SKILL.md）——装机环节禁止主动运行。

> 手机、电脑装的是同一份，用法一样；纯对话诊断、默认不生成文档（学员主动要报告时可导出），手机用最方便。

## 三、第一次怎么说

**直接抄**：
> "帮我做一下业务定位诊断"

**带具体问题**：
> "我发圈没人理，是不是我定位不对？"

**系统测**：
> "我想系统测一下自己的业务定位起点"

**问赛道和模式**：
> "我的赛道怎么选？我适合哪种定位模式？"

## 四、它会怎么工作

1. 先分流：完整诊断、单项断裂/赛道、文案自检、内容成品转介，各走各的，不让小问题重跑全套
2. 完整诊断先问"带问题来"还是"系统测"，再问终局优先顾客还是伙伴
3. 问**业务定位三问**：你是做什么的 → 帮什么人 → 解决方案是啥
4. 跑**断裂初检**：通用昵称不会在这里被硬卡；赛道定完后用完整公开名片复验
5. 收**一条主赛道**：大健康九选一；非大健康自定义；零成交走真实实践＋90天意愿，不再要求提供不存在的成交数据
6. 判**定位模式**：主模式必有；招商型过三道硬指标，被拦后重新确认顾客/伙伴优先级
7. 挖**信任背书**：经历/结果/共情；成长打卡可用真实过程背书
8. 收成一句话业务定位，再定表达基因
9. 定内容方向（必须挂真实证据资产）＋判获客链路
10. 按**入场原始状态**打分；没提到的标待补，不再按0分，也不因低分自动劝退
11. 给八段文字结论；你确认后，它先问是否保存，**你同意才记画像**

> **v5 最大的变化**：底座从"人设四要素"升级为**差异化业务定位**——先立生意（三问），再谈表达（基因后置为包装层）。新增断裂自检、九赛道收窄、五种定位模式（含招商型三道硬指标）；结论从六段升为**八段**。理论底座是 2001 年诺贝尔经济学奖的柠檬市场 + 信号传递——**成本，就是可信度**。

## 五、它记得住你

诊断完并征得你同意后，它会把三问、一句话业务定位、表达基因卡、定位模式等存进你自己的记忆；你拒绝保存也能拿到完整结论。
- 下次再来找它 → 它会先说"我记得你的画像是这样……这次还沿用吗？"，不用重新讲
- 被劝退过的学员再回来 → 它会先复核当初约定的"三样东西"攒齐没有，攒齐才进正式诊断
- 如果你以前用过沁珮的其他技能包、留过画像 → 它也会读出来问你，沿用就在原基础上补，不沿用就重新问
- 用过旧版（v4 四要素口径）的画像 → 字段照用，不让你重讲已经答过的内容

## 六、注意事项

- 它**不写具体文案**——只给业务定位、模式这些方向；你说"帮我写10条朋友圈"，它会转介对应内容技能并给可复制需求句，不代写也不硬拉回问诊
- 它**不编数据**：你没讲到的，它不会替你编"很成熟"
- 诊断只给方向，决定权在你自己
- 它可能比之前"较真"（会追问、会打回"帮所有人""我很专业"这类回答；断裂自检不过关会当场点破）——这是故意的，为了给你真判断
- **不是所有人都该马上做定位**：如果你业务基本功还没过关，它会直接建议你先做业务，三个月后带结果回来
- **招商型有三道硬指标**：业务链完整、带出过人、招商方案有共性结果——缺一道它会拦，不让你空喊招商
- 嫌它话多就说「简单说」，想看全貌就说「展开」——结论永远是八段完整的
