# 沁珮技能包全家桶（qinpei-skills）

沁珮把长期使用的团队展业与信任经营方法，沉淀成一组可被 AI 调用的技能（Skill）。
本仓库公开技能源码与发行包，供学员安装、使用和二次学习。

> 核心逻辑：**技能是方法，不是交付物。** 真正值钱的是「教你怎么用、陪你练、帮你批作业」的服务。

## 当前技能清单（11 个）

| 技能 | 版本 | 作用 |
| --- | --- | --- |
| `qinpei` | 1.12.1 | QP展业管家：识别需求、检查安装并路由到对应技能（说「qp」触发） |

| `qinpei-salon-ops-trust` | 2.3.0 | 线下沙龙信任经营：策划、邀约、执行、跟进与复盘 |
| `qinpei-storytelling` | 2.3.0 | 故事力提效：从真实经历提炼故事并完成发布自检 |
| `qinpei-ip-diagnosis` | 5.0.1 | 差异化业务定位诊断：三问、赛道、模式、背书、表达与获客链路 |

其中 `qinpei` 与 `qinpei-profile` 是核心入口；其余技能按实际需求安装。

## 安装方式（SkillHub 优先）

新学员统一从 **WorkBuddy 技能中心 / SkillHub** 安装，搜索发布者 **`indiv-qinpei`** 或对应技能名。

也可以把下面这句话直接发给 WorkBuddy：

```
请根据 https://skillhub.cn/install/skillhub.md 安装 @indiv-qinpei/qinpei
```

装好后说「**qp**」，由 QP展业管家判断该用哪个技能；不要一次装满所有包。

## 升级

已安装 SkillHub 版本的学员，可直接对 WorkBuddy 说「升级沁珮技能包」或通过技能中心更新。

- 只升级已经安装的技能，不借机安装无关技能。
- 学员画像、学员档案和自行保存的内容不属于发行包，不应被覆盖或删除。
- GitHub 保留同名 zip 镜像，原有文件路径不变；历史安装说明仅为旧链路兼容保留。

## GitHub 仓库内容

- `skills/`：11 个技能的公开源码。
- `skillhub-zips/`：对应的 zip 发行包；SkillHub 最新 10 包已于 2026-11-25 对齐。
- `skills-catalog.md`：版本清单与同步验收表。
- `CHANGELOG.md`：公开版本变更记录。

## 开源与隐私边界

- 本仓库技能以 **MIT 协议**开源，可自由使用、修改、再分发。
- 公开版本不包含学员画像、学员档案、访问令牌或私有凭证。
- 案例与示范不得被当作真实业绩承诺；大健康内容仍须遵守平台合规与就医边界。
