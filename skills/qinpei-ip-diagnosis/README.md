# 个人IP定位诊断 · 使用说明（v4.1.1）

> 帮大健康 / 分享经济团队长，走完"定位→表达基因→内容地基→获客链路"四层 IP 生意诊断，搞清楚"我是谁、我怎么说、做什么内容、怎么获客"。
> 不会写提示词？跟它聊天就行。

---

## 一、这是啥

一个 AI 诊断搭子。它用**IP 信任体系四要素**跟你走一遍，最后给你**六段结论**：

1. **四要素结论**——你是谁 / 你凭什么 / 你给什么 / 你带来什么
2. **一句话定位**——用【你的方案】，解决【什么人群】的【什么问题】
3. **表达基因卡**——你的叙事人格（过来人 / 同行者 / 研究者 / 实干家）+ 语气基准 + "永不说"清单
4. **IP 类型**——你适合做哪种 IP（专家型 / 故事型 / 陪伴型 / 工具型），以哪种为主、拿哪种补
5. **内容方向**——2–3 个你讲得动的内容方向，各有名目和依据
6. **获客链路判定**——你的获客四件套（钩子 / 留资 / 承接 / 归属）最断的一环 + 一句修法

外加一张**成熟度打分表**（满分 8 分）——你现在几分、最缺哪块。

**它只给方向，不写文案**。犀利、直接、不灌鸡汤。业务基本功没过关的学员，它会直接劝退——这不是敷衍，是保护。

**适合谁**：做了很久却不知道"该立什么人设"、发圈没人理、不知道"我适合做什么类型"的团队长。

**它独立可用**：装这一个就够，不依赖、不检查、不提及任何其他技能包。

## 二、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序）：**
1. 把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好）
2. 装好后在输入栏「+」→「添加技能」里启用

**电脑端（Win / Mac 桌面版）：**
1. 解压 `qinpei-ip-diagnosis.zip`，得到 `qinpei-ip-diagnosis` 文件夹
2. 把文件夹放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 📋 **安装验收卡（给执行安装的 AI 助手，装机时照此执行）**
> 装完**只回一句话**：包名 + 版本号（SKILL.md 里的 `version:` 字段）+ 11 个文件是否齐全 +「重开对话即可用」。
> **三不要**：不要主动联网比对版本；不要检查、汇报或评价其他技能包；不要展开工作链路长介绍。
> 升级手册（references/upgrade.md）**仅在学员明确说"升级到最新版本"等升级触发词时**才执行——装机环节禁止主动运行。

> 手机、电脑装的是同一份，用法一样；纯对话诊断、默认不生成文档（学员主动要报告时可导出），手机用最方便。

## 三、第一次怎么说

**直接抄**：
> "帮我诊断一下我的IP"

**带具体问题**：
> "我发圈没人理，是不是我人设不对？"

**系统测**：
> "我想系统测一下自己的IP定位起点"

**问类型**：
> "我适合做什么类型的IP？"

## 四、它会怎么工作

1. 先问你是"带问题来"还是"系统测"（选一个就行）
2. 走**四要素**：你是谁 → 你凭什么 → 你给什么 → 你带来什么（一个一个来，答不全也没关系）
3. 挖**表达基因**：你的叙事人格 + 常说 3 句 + "永不说" 3 句——你以后所有内容都从这张卡长出来
4. 收成**一句话定位**（`用【方案】解决【人群】的【问题】`）
5. 判**IP 类型**（四问定类型：讲干货还是讲故事 / 因为什么被信任 / 最容易产出什么 / 每天多少时间）
6. 定**内容方向**（2–3 个，各有名目和"为什么是你能讲"）
7. 判**获客链路**（钩子 / 留资 / 承接 / 归属四件套，找出最断的一环）
8. 按 4 个信号打分（满分 8 分）——不管哪种模式都会打分
9. 给你文字结论，你确认"OK"后，它把你的定位**记下来**——下次直接来找我，不用重新讲

> **v4 最大的变化**：从"给你三样东西"升级为**六段结论**——多出表达基因卡（决定你怎么说话）、内容方向（决定你讲什么）、获客链路判定（决定流量怎么接住）。另外业务没跑通的学员会被**劝退**，并约定三个月后带着"三样东西"回来复查。

## 五、它记得住你

诊断完，它会把你的定位、表达基因卡、IP 类型**存进你自己的记忆里**。
- 下次再来找它 → 它会先说"我记得你的画像是这样……这次还沿用吗？"，不用重新讲
- 被劝退过的学员再回来 → 它会先复核当初约定的"三样东西"攒齐没有，攒齐才进正式诊断
- 如果你以前用过沁珮的其他技能包、留过画像 → 它也会读出来问你，沿用就在原基础上补，不沿用就重新问

## 六、注意事项

- 它**不写具体文案**——只给定位、类型这些方向（你说"帮我写 10 条朋友圈"，它会拒绝并把你拉回正题）
- 它**不编数据**：你没讲到的，它不会替你编"很成熟"
- 诊断只给方向，决定权在你自己
- 它可能比之前"较真"（会追问、会打回"帮所有人""我很专业"这类回答）——这是故意的，为了给你真判断
- **不是所有人都该马上做 IP**：如果你业务基本功还没过关，它会直接建议你先做业务，别急着立 IP
- 嫌它话多就说「简单说」，想看全貌就说「展开」——结论永远是六段完整的
