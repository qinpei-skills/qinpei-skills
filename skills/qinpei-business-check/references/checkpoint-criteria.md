# 12 检查点完整判据（内部文件 · 不给学员看）

> 读取条件：每轮问诊判"立住/半立/没立"需要精确比对时读本文件；学员追问"我这算哪个水平"时也读。
> 来源：与《新学员自检表》Q1–Q12 逐条同判据，保证 skill 与课程、自检表**三方同构**。
> ⚠️ 本文件含 A–D 与分数——**一个字都不许说给学员**（见 SKILL.md §〇 铁律）。

---

## 判读纪律（先读这五条）

1. **只按学员自述判**，模糊处**选项式逼一次**（"是 A 那种还是 B 那种？"），禁止脑补。
2. 学员没讲的，按**弱**算，并当场追问："这一项你没细说，我先按偏弱算，是不是实际情况？"
3. **一轮一个回合**，不要一次问完 12 个。
4. 判完**心里记**，不报分、不说档位——结论文里只出"立住/半立/没立"。
5. 学员答"你看着办" → 按已采集信息走完，结论标注"基于你目前说的，我的判断是……"，留修正空间。

## 一、链路（Q1–Q3）

### 检查点 1 · 客户进来怎么养（Q1）

问法："新客户加了你微信之后，你一般会做什么？有固定动作吗，还是看情况？"

| 档 | 表现 | 判定 |
|:--:|:---|:--:|
| A | 一进来就有固定动作：看得到我的朋友圈、被打了标签，知道怎么了解我 | 立住 |
| B | 有养的动作，但想起来才做，没有固定节奏 | 半立 |
| C | 加了先放着，靠偶尔群发、朋友圈刷到 | 没立 |
| D | 基本不养，加完就等着找机会推销 | 没立 |

### 检查点 2 · 多久见一次面（Q2）

问法："你手上的客户，最近一次跟你见面是什么时候？平时大概多久能约出来一个？"

| 档 | 表现 | 判定 |
|:--:|:---|:--:|
| A | 每周至少约到 1–2 场线下（体验、小聚、一对一） | 立住 |
| B | 每月有一两次线下接触 | 半立 |
| C | 很少线下，主要靠线上聊 | 没立 |
| D | 几乎不见面，全靠线上发链接 | 没立 |

### 检查点 3 · 伙伴怎么带（Q3）

问法："你带的伙伴，举个例子——她第一次跟客户谈的时候，你在干嘛？"

| 档 | 表现 | 判定 |
|:--:|:---|:--:|
| A | 有闭环：我做你看 → 你做我看 → 复盘 → 独立，能带出人 | 立住 |
| B | 有带教意识，但不成体系，时带时不带 | 半立 |
| C | 主要是开会、群发资料，没有一对一陪跑 | 没立 |
| D | 基本不带，靠他自己悟 | 没立 |

## 五、判档（内部用，学员侧只出档位名）

### 判档算法（必须与自检表 100% 一致）

**12 个检查点按 A=4 / B=3 / C=2 / D=1 折算 → 累加得总分 → 套四档区间。**

| 总分 | 档位名 | 一句话画像 |
|:---:|:---|:---|
| 12–20 | 四根都还没立住 | 还在用老打法 |
| 21–29 | 有动作，没体系 | 在动，但没有标准动作 |
| 30–38 | 三根站稳，一根拖后腿 | 差一块短板 |
| 39–48 | 四根都在路上 | 已经跑起来了 |

> **为什么不能凭"感觉"判档**：只有跟自检表用同一个算式，学员"表单算出来 36 分、skill 说另一个档"这种事才不会发生——这是三方同构的锚点。
> **但分数只在内部用**，学员侧一个字都不报（见 SKILL.md §〇）。

### 主断点判定

四根里**小分最低**的那根 = 最该先补的一根。

**并列怎么办（重要）**：**不许机械按"链路→定位→一体化→新旧融合"取前者**——那会系统性地永远报链路。
并列时必须用**一个能分辨的追问**区分，例如：

> "你这两块听着差不多，我问一个能区分开的：最近一个月，你是更缺人聊，还是更缺人见面？"

追问后仍分不出 → 才按顺序取前者，并在心里标注"这两根接近，先补哪根都行"。

### 一个已知边界（遇到时不要慌）

**总分档位和断点可能看起来打架**。例：某学员四组得分 11 / 12 / 11 / 5，总分 39 → 档位落到"四根都在路上"，但断点明显在最低那根。

**处理原则**：
- 档位**照报**（保持与表单一致，不自己改区间）
- 但引导语**必须按断点那根说**，不许照搬"你已经跑起来了"这种话
- 正确说法："你整体底子不错，就是这一根明显拖后腿——先补它。"

记住：**档位说的是"整体水平"，断点说的是"先补哪一根"**，两件事，不冲突。

### 四档位对应的引导语（要出简报或学员追问时用）

| 档位 | 引导语 |
|:---|:---|
| 四根都还没立住 | 你现在不是"招数不够"，是底盘还没打好。别急着学新工具——先把最基础的那一根立起来，挑一件做满 7 天。 |
| 有动作，没体系 | 你力气没少花，问题是"凭感觉做"，没有固定动作。先别加新动作——把已经在做的那件事，改成"每次都这么做的三步"。 |
| 三根站稳，一根拖后腿 | 你的底子已经在了，卡住你的就是最弱的那一根。别全面开花——这个月只补它。一根通，你的信任资产就强一步。 |
| 四根都在路上 | 你已经在正确的路上，动作也成体系了。现在缺的不是"学新东西"，是放大和复制——把你会的事，变成别人也能照着做的东西。 |
