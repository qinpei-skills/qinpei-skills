# 365 视觉系统规范（全产品统一，禁止擅自改色/改版）

## 一、配色（4 色，固定）
| 角色 | 色值 | 用途 |
|:--|:--|:--|
| 暖米底 | `#F7F2E9` | 全图背景，扁平无渐变无阴影 |
| 黛青 | `#23403B` | 主文字、价签、基础版编号 |
| 赭橙 | `#C56B30` | 365 数字、升级版强调、升级版编号 |
| 竹绿 | `#7C9B6E` | 副标题、点缀、分隔线 |

## 二、字体
- 标题：黑体（系统 sans-serif，如 PingFang SC / 思源黑体）
- 金句 / 引用：宋体（Songti SC / 思源宋体）
- 一律用系统字体渲染，中文零乱码（不要用 AI 生图直接出中文）

## 三、品牌锚点
- 左上角：「沁珮私房课」标识（黛青小字）
- 视觉符号：365 数字 ＋ 日历意象（圆环 / 年历）
- 右下角：可放价签「¥365/年 · 一天一块钱」（黛青圆角 pill + 暖米字）

## 四、编号规则
- **无底色、无加粗**，作为右上角角标
- 基础版：黛青；升级版：赭橙（保留版本区分）
- 示例：基础版「技能2 社群运营」；升级版「技能2 社群运营 · v2.0」

## 五、详情页 / 长图
- **不固定 3:4 高度**，按文案自然撑开，导出时实际高度 = 内容高度
- 竖向长图宽度固定 1080，封面横版 1280×720
- 内容必须完整显示，不留白截断

## 六、升级版强调
- 赭橙主色 ＋ `v2.0 / Pro` 角标，与基础版拉开区分
- 升级版文案对应更高阶能力（如技能1升级版 = 朋友圈信任经营 Skill v2.0 六大功能）

## 七、文案铁律
- **「经销商」一律替换为「团队长」**（全产品统一）
- 不夸大、用真实数字（沿用数字真实规则，禁止编造「出单率22%→58%」类）
- 售卖页规避违禁词：成交 / 获客 / 拉新 / 私域 等
- 整体封面标题只写「365年度会员」，不带「训练营」三字

## 八、尺寸速查
| 类型 | 尺寸 |
|:--|:--|
| 封面（横） | 1280 × 720（16:9） |
| 详情页 / 长图（竖） | 1080 宽 × 内容自适应高 |
| 讲师海报 | 1080 宽 × 自适应 |
| 权益总览 / 学习地图 | 1080 宽 × 长图 |
| 技能包图标组 | 1280 × 720 或自适应 |
