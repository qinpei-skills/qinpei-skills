# 模板07 · Vlog 日常（AI 生成前必加载本模板）

> **这一格干什么用**：活人感——前七格都在"讲"，Vlog 是"过日子"。让观众看到生活里的你，信任才立体。粉丝是先认识"那个人"，才认识"那个老师"的。
> **规格**：Vlog 天然短平快，**默认1分钟内**（口播旁白 80-150 字+画面），学员特别要求再做3分钟加长版。
> **⚠️ Vlog 不硬套四件套**——它有自己的轻结构。但开头铁律不豁免：第一句仍然是判断句/画面钩子，照样禁铺垫禁称谓。

---

## 先选类型（学员的一句话判断法）

| 学员说 | 选哪型 |
|:---|:---|
| "拍拍我一天怎么过的" | → 一日切片型 |
| "今天去见了个客户/办了个事" | → 一事记录型 |
| "就是想随便聊聊" | → 随口说型 |

---

## 类型A · 一日切片型（最常用）

**轻结构**：画面钩子 → 3-5个生活镜头 → 一句感受收（不硬CTA）

**镜头清单（给学员的拍摄小抄，每条5-10秒，手机随手拍）**：

| 镜头 | 拍什么 | 秒数 |
|:---|:---|:---|
| ① 开场钩子 | 一个有信息的画面：摊开的工作台/一壶刚泡的茶/排好的一排艾条 | 5秒 |
| ② 一天的开始 | 早上的第一件事（泡茶/整理台面/出门） | 8秒 |
| ③ 干活的画面 | 工作状态：给客户准备的东西/笔记/走到哪拍到哪 | 10秒 |
| ④ 一个人的时刻 | 午休/翻书/窗边发会儿呆（活人感最强的镜头） | 8秒 |
| ⑤ 收尾画面 | 天黑收工/一盏灯/当日小结的手写便签 | 5秒 |

**旁白写法**（80-150字，画外音配着镜头走）：
1. **开场钩子一句**（判断句）：`【填：一句关于"你这一天"的判断，比如"干养生这行的，一天是从给客户挑东西开始的"】`
2. **中段两三句**（跟着镜头走，不解说画面——说画面外的话）：`【填：比如镜头②画面是泡茶，旁白说"这壶茶不是给自己喝的，是给下午来的姐妹备的"】`
3. **感受收一句**（不升华）：`今天就这样。日子是一天一天过出来的。`

## 类型B · 一事记录型

**轻结构**：事的钩子 → 事中画面2-3个 → 一句落点

- 镜头：出发/到场/一个关键瞬间（各5-10秒）
- 旁白：`【填：这件事最有戏的一句开头，比如"今天这位姐妹，是三年老客户介绍来的"】`→ 中段两句交代 → 落点一句
- 🔴 事的画面涉及他人 → 发布前打招呼；客户咨询类内容**不拍不剪不提具体内容**（隐私红线）

## 类型C · 随口说型

**轻结构**：无镜头设计，坐着对镜头说60-90秒（当天的真实感触）
- 开头仍然要判断句：`【填：今天最想说的那句判断，比如"今天有人问我累不累，我愣了一下"】`
- 只说一个感触，说完就收
- 这型最检验"活人感"——AI 的事是帮学员把口癖和废话顺掉，**不帮他打磨成播音腔**

---

## Vlog 通用规则

1. **糙一点更好**——Vlog 精修=广告，手机直出+轻微剪裁最对味；旁白有口癖没关系，那是身份证
2. **开头铁律不豁免**：第一句判断句，禁"大家好今天记录一下我的日常"（Vlog 最容易犯，改稿重点盯）
3. **不硬 CTA**：Vlog 的收尾就是感受句，关注是观众自发行为——最多软一句"这日子我天天记"，禁"关注我看更多"
4. **人设不贴标签**：不写"一个爱生活的养生人"这种自我介绍式旁白——镜头里的生活本身就是人设（人设句硬度标准管的是四件套格；Vlog 轻结构按本格规则走，属通用铁律的格内豁免，与兜底条款不冲突）
5. **合规不松**：Vlog 里的产品画面只出现不讲解；拍艾灸/调理过程注意镜头里**不出现身体敏感部位**，面部出镜需同意
6. **镜头清单是建议不是命令**：学员临时遇到好画面就拍，Vlog 的灵魂是"抓到"，不是"拍到"

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 开场钩子是判断句/有信息的画面，不是"今天记录一下我的日常"？
- [ ] 旁白跟镜头是错开的（不解说画面，说画面外的话）？
- [ ] 全程零硬 CTA、零自我介绍式贴标签？
- [ ] 镜头清单给了（每条5-10秒、手机可拍）？
- [ ] 涉及他人的画面提醒过同意？客户隐私内容零出现？
- [ ] 合规过闸：产品只出现不讲解、身体敏感部位不入镜？
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 旁白字数标注了（80-150字）？糙感保住了（没修成播音腔）？
