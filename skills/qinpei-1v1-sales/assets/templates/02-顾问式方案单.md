# 模板02 · 顾问式方案单（给方案时用）

> 用法：心结已破 → 才填这张单。🔴 三件套缺一不可。

---

## 一、她要的结果（🔴 用她的原话）

```
她的原话：________________________________
翻译成一句共识：____________________________
```

## 二、她的真顾虑（她没说出口的那条）

```
她明说的顾虑：________________________________
她真正担心的（AI 判断 + 学员确认）：____________
```

## 三、两个方向（🔴 最多两个，给了判断标准让她选）

### 方向一：____
- 这是什么：____________________________
- 适合什么样的人：________________________
- 要先付出什么：__________________________
- 判断标准（到某时间点看哪个数字）：________

### 方向二：____
- 这是什么：____________________________
- 适合什么样的人：________________________
- 要先付出什么：__________________________
- 判断标准：________________________________

**🔴 她问"到底该选哪个"→ 「你觉得哪条更适合你？我们一起验证。」**

## 四、判断标准（🔴 必须可对账）

```
第3天看：____（是/不是）
第7天看：____（是/不是）
第14天看：____（是/不是）→ 🔴 线下见一次
第30天看：____（是/不是）
```

## 五、真料位（🔴 学员没给的一律留【填】，AI 不代编）

```
价格：【填：你的真实价格】
成交/效果数字：【填：你的真实数字】
案例细节：【填：案例真实细节，🔴 不写真名】
客户原话：【填：她原话说的那句】
```

## 六、本轮收口

```
今晚就能做的最小动作：______________________
退路（不合适怎么办）：______________________
跟进时间：第3天____ ／第7天____ ／第14天🔴线下____
本轮Advance：她 ______ 了
```

---

## 🔴 交付前四问（AI 自检）

1. 三件套齐了吗？（她的结果 / 她的真顾虑 / 判断标准）
2. 有没有替她做决定？（有 → 改成选项+判断标准）
3. 有没有一句她说不出口的话？（这是给她的原话，不是你的话）
4. 有没有承诺收益或疗效？（有 → 立刻改）
