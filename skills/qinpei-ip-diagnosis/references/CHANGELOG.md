# 版本历史（CHANGELOG）

> 本文件只记录版本演进，AI 执行时无需读取。当前版本以 SKILL.md frontmatter 的 `version:` 为准。

*v3.0.7（驾驶舱版 · 2026-09-22）：SKILL.md 改为「驾驶舱 + references/」渐进式披露结构——案例库/反常识/名片公式/画像写入/升级流程/版本历史拆为按需加载文件，主文件 474→约 310 行。行为规则零删减只搬家；新增红线「案例数字=示范口径非学员数据」。*

*v3.0.6（结论硬门禁版 · 2026-09-17）：①新增「🔴 最终结论硬门禁」放第一屏——结论必须四段逐项（四要素固定表述 / 一句话定位句式 / IP 类型只许四类选主辅 / 内容方向），禁止自创要素名（你为谁、你怎么做）与自创类型名（陪跑型），收尾前自检不过就重写。②四要素定义按沁珮口径修正：要素1 = 角色+人群+问题一项定死；要素2 补问证书资质（辅证）；要素3 = 结果蓝图、结果前置；要素4 = 行动和方法（带着干的路径），不是结果。*

*v3.0.5（缓存免疫 · 2026-09-13）：升级流程里取版本表、下载 zip 的地址统一加 `?t=$(date +%s)` 时间戳参数，根治「读到旧版本表→比对出已是最新→升级静默不执行」。*

*v3.0.4（分发域名统一 · 2026-09-12）：版本表与 zip 地址统一指向新的分发中心域名（可随内容更新、链接恒定）。*

*v3.0.3（一句话升级版 · 2026-09-12）：新增《🔄 版本自检与升级》——学员说一句「升级到最新版本」就自动取线上版本表比对、覆盖升级，不用再复制安装口令；升级只覆盖技能本体，学员的资料卡与档案不受影响。*

*v3.0.2（入口补强版 · 2026-09-12）：①新增「信息不足绝不出定位」；②新增「匹配不上有回退」——套不上单一 IP 类型时给"主+辅"混合判断并说明依据。*

*v3.0.1（赛道分类移除版 · 2026-09-11）：删除「2 条赛道」整节（按客单价划分不适配大健康/分享经济实际经营场景）。原赛道案例改写为案例五；「收窄人群、做到不可替代」洞察保留。*
