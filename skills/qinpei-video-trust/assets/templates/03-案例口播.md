# 模板03 · 案例口播（AI 生成前必加载本模板）

> **这一格干什么用**：案例是转化主力——观众不信你说的道理，但信"真的有这样的人"。适合讲：你带过的伙伴怎么走出来的、你的客户怎么一步步变好的。
> **双版本规格（默认双稿齐出，学员指定单版才单出）**：
> - 📱 **60秒内版**：约240字（上限260）——只讲一个人的一个转折
> - 🖥️ **3分钟中视频版**：约700字（上限750）——加"当时怎么想的""过程中卡在哪"两层细节
> **两小格**：带伙伴案例（团队长向，优先推荐）/ 客户调理案例（强合规版）。
>
> **⚠️ 本格是全包合规风险最高的格**——案例三格铁律一条都不能松，【填】永不代编（编造风险会从学员外溢到终端客户身上）。

---

## 案例三格铁律（本格生死线，生成前先背，生成后逐条对）

1. **第三人称**——讲"我有个伙伴/我有个客户"，不讲"你"（不指向观众，不制造对号入座）
2. **生活语言讲困扰**——只讲生活状态（"晚上翻来覆去睡不着"），🔴 禁病名+数字（"失眠症5年"）、禁体质词（转场景词，见 compliance-gate 关1）
3. **只讲执行动作**——她做了什么，一样一样列（调作息/换了吃法/坚持泡脚），🔴 禁"所以就好了"式绝对因果
4. **只讲状态感受**——现在的主观状态（"现在能一觉睡到天亮，白天人有劲了"），🔴 禁"调理好了/根治/痊愈/X天见效"
5. **尾句软声明**——每条案例稿结尾必带一句："每个人情况不一样，我讲的只是她的路"
6. **【填】永不代编**——伙伴/客户的姓名、细节、进展，学员没给的一律【填：…】+填写引导

## 小格A · 带伙伴案例（团队长向，优先推荐）

> **干什么用**：给团队长学员拍——他的伙伴、他的带教对象看了觉得"说的是我"，转发就是破圈。观众看完要么想被你带、要么想学你怎么带人。

**结构**：伙伴的困境（事实）→ 我怎么帮他拆的（教练动作）→ 他现在的状态 → 给观众的启示

1. **【开头】困境反常识化**（判断句钉出来，不用"我有个学员"也不用疑问句）：
   - `带团队最可惜的一种伙伴：不懒、课也听，就是不出结果——问题根本不在努力上`
   - `【填：伙伴类型，比如"跟你干了三年的老人"】突然说不干了——她不是累了，是【填：真实原因】`
2. **【人设句·紧跟开头】**：`我带团队【填：真实年头】年，这样的伙伴我自己带过【填：真实数量】个` 🔴 硬度标准：年头＋至少一个成果数字（带出伙伴数/培养主理人数/场数，四者占其二），缺的按流程问学员或【填】留白，禁"这些年""带过太多"式虚写。
3. **我怎么拆的**（教练动作，本格的干货段）：
   - 【填：你当时帮他做了什么——一次谈话/一个动作调整/帮他重新定位。要具体到"你说了一句什么话"】
   - 🔴 禁把功劳写成"我一带她就出单了"（绝对因果）——写成"我帮她把XX理顺了，后面是她自己一步一步走出来的"
4. **他现在的状态**（感受式）：
   - 【填：真实进展——"上个月她第一次自己开了场小型分享会"。禁编数字：出单率/收入涨幅】
5. **【收尾】启示 + 钩子 + CTA**：
   - `带团队带的是什么？不是带业绩，是带人把路走顺。关注我——【填：钩子，你真有的才算数】`

**示例骨架**：

带团队最可惜的一种伙伴：不懒、课也听，就是不出结果。【开头】

我带团队【填：真实年头】年，这样的伙伴我自己带过【填：真实数量】个。【人设句·紧跟】前阵子我有个伙伴【填：化名/姓氏】，跟着做了快两年，朋友圈也发、课也上，就是没动静。她跟我说想放弃。我坐下来陪她把每天的活儿捋了一遍，发现问题不在人，在顺序——她把八成时间花在【填：她的真实卡点，比如"反复学新课"】上，真正见人的动作一个礼拜做不了两次。我帮她把顺序倒过来：【填：你给的调整，具体到动作】。后面就是她自己一步一步走出来的。【怎么拆的】

上个月，她【填：真实进展，一个具体动作/状态，不编数字】。【现在的状态】

带团队带的不是业绩，是把人把路走顺。每个人情况不一样，我讲的只是她的路。关注我——【填：钩子】。【收尾】

**（60秒内版约240字；3分钟版在【怎么拆的】里加"她当时怎么反应的""中间卡在哪一次"两层细节。约700字。【填】必须学员真事，AI 永不代编。）**

## 小格B · 客户调理案例（强合规版）

> **干什么用**：养生调理类学员拍——第三人称讲客户从困扰到状态变好的过程。**全包合规要求最严的格子**，案例三格铁律逐条过。

**结构**：她的困扰（生活语言）→ 她试过的弯路 → 跟着我做了什么（动作清单）→ 现在的状态（感受）→ 软声明收

1. **【开头】困扰场景化**（画面感开头，不从"我有个客户"开始）：
   - `【填：一个画面，比如"有个姐妹跟我说，她已经有两年没睡过一个整觉了"】`
2. **【人设句·紧跟开头】**：`做这行【填：真实年头】年，这样的姐妹我接待过【填：真实数量】个` 🔴 硬度标准：年头＋至少一个成果数字（服务客户数/办过场数/带出人数，四者占其二），缺的按流程问学员或【填】留白，禁"接待过太多"式模糊量级。
3. **她试过的弯路**（增加真实感）：
   - 【填：她之前试过什么没用的，一笔带过。🔴 禁点名其他品牌/产品踩雷】
4. **跟着我做了什么**（重点段，只列动作）：
   - 【填：动作清单——把作息调了/吃法换了/坚持了什么外治法，一样一样列。🔴 每一条都不能带"因为…所以好了"的因果链】
5. **现在的状态**（感受式，禁因果禁疗效）：
   - 【填：她的主观状态——"现在她跟我说，晚上十一点躺下就能睡着"。🔴 禁"调好了/根治了/三个月见效"】
6. **【收尾】软声明 + 钩子 + CTA**：
   - `每个人情况不一样，我讲的只是她的路。关注我——【填：钩子】`

**合规红线回抄（本格生成后 AI 逐条对，一条不合格整条重写）**：
- 🔴 病名+指标数字 → 不出现
- 🔴 绝对因果（"因为泡脚所以好了"）→ 拆成"做了什么+现在的感受"
- 🔴 "调理好了/根治/痊愈" → 改状态描述
- 🔴 体质词（气血弱/寒湿）→ 转场景词（"手脚常年冰凉"）
- ✅ 尾句软声明必须在
- ✅ 全程第三人称，不指向观众（"你要是也这样"→ 不说）

## 案例格通用规则

1. **一个案例一个点**——案例说明的道理超过一个，砍掉次要的
2. **人设句紧跟开头**——困境句后第二句就立住"我见过多少"
3. **钩子必问学员、永不代编**（同 SKILL.md 钩子档位表）
4. **数字零编造**——伙伴进展、客户状态，学员没说的数字一律【填：你的真实数字】
5. **防对号入座**——提示学员：讲伙伴/客户案例用化名或姓氏，发之前最好跟当事人打个招呼（既是尊重也是信任）

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 开头是判断句钉出困境，不是"我有个学员/客户"、不是疑问句、没有"大家好/姐妹们"铺垫？
- [ ] **人设句紧跟开头了吗（第二三句内）？**
- [ ] 小格选对了吗（带伙伴/客户调理）？
- [ ] **案例三格铁律六条逐条过了？**（第三人称/生活语言/只列动作/状态感受/尾句软声明/【填】零代编）
- [ ] 合规红线回抄逐条对过？（无病名数字/无绝对因果/无疗效词/体质词已转）
- [ ] **结尾钩子是学员真有的东西吗？**
- [ ] 全稿口语？长句已砍短？
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 版本对版吗？（60秒内版240字±10% / 3分钟版700字±10%）
- [ ] 时长标注 + 拍摄提示（案例格提示：讲"她现在的状态"那一刻放慢，带笑意）？
