# 模板 · #4 钩子资料（自测表 / 打卡表生成）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。
> 交付格式：**默认 .docx（Word 文档）**，学员能直接打开、转发客户；手机无法存文件 → 先文字版 + 问是否导出。

## 一、钩子类型匹配（按赛道自动匹配，学员可改）

| 赛道 | 找意向钩子 | 养关系钩子 | 促成交钩子 |
|:---|:---|:---|:---|
| 中医养生/湿气 | 湿气自测表 | 21天祛湿打卡表 | 1对1体质辨证 |
| 减脂塑形 | 体质自测表 | 21天调体质打卡表 | 体验营名额 |
| 美业护肤 | 肤质自测表 | 7天养颜打卡表 | 护肤体验1次 |
| 母婴育儿 | 孩子积食自查表 | 育儿打卡表 | 育儿微课体验 |
| 视康 | 远视储备自查清单 | 护眼打卡表 | 视力筛查体验 |
| 茶修 | 体质茶饮匹配表 | 卯时茶打卡表 | 茶修体验课 |
| 通用兜底 |《【填：主题】自测表》 |《21天【填：主题】打卡表》 | 1对1【填：主题】咨询体验 |

> ⚠️ 赛道没覆盖（头疗/孕产艾灸/口腔/康复/营养/睡眠/心理等）→ 根据画像"帮什么人+解决什么"**自动生成定制钩子**（如头疗→《头皮健康自测表》）。定制后同样走"有没有资料→没有帮生成"流程。
>
> ⚠️ **钩子必须跟赛道走**：上表是示例，不是标准答案。学员来自**整个大健康赛道**，非中医赛道（口腔/视力防控/康复理疗/营养补充/睡眠/心理/运动/健康食品等）**不许套"体质辨证/祛湿/气血"这类中医钩子**——按学员自己行业的说法定制（口腔→《牙龈健康自测表》、营养→《日常膳食缺口自查表》、睡眠→《睡眠质量自评表》）。

## 二、自测表模板（找意向用 · 5-8题 · 简单优先）

```
【标题】《【填：如湿气】自测表》——测一测你的【主题】到什么程度了

【开场】（一句话价值+引导）
"花1分钟测一测，看看你的【主题】情况。测完私信我，帮你看看方向。"

【题目】（5-8题，每题是否/打分，简单口语）
1. 【填：症状问题】？（如：舌苔是不是厚得能刮下来一层？）
2. 【填：症状问题】？（如：大便是不是总粘马桶？）
3. 【填：症状问题】？（如：下午是不是腿肿、犯困？）
4. 【填：症状问题】？
5. 【填：症状问题】？

【结果提示】（简单分级，不诊断）
- 中 3 条以下：【填：轻度提示话术，如"有点苗头，注意作息饮食"】
- 中 3-4 条：【填：中度提示话术，如"需要认真调一调了"】
- 中 5 条以上：【填：重度提示话术，如"该系统调理了，建议私信聊聊"】

【落款】"测完截图发我，我帮你看一眼～"（+ 学员微信号/二维码位置）
```

> 先给简单的；学员追问"能不能再详细点"再生成深度版。

## 三、打卡表模板（养关系用 · 21天/7天）

```
【标题】《【填：如21天祛湿】打卡表》

【规则】（一句话）
"每天完成打卡内容，在对应格子里打勾，坚持21天。"

【打卡表】（表格：日期+打卡内容+感受）
| 天数 | 打卡内容 | 今日感受 |
|:---:|:---|:---|
| Day 1 | 【填：具体动作，如"晚上11点前放下手机"】 | （学员填） |
| Day 2 | 【填：具体动作】 | |
| ... | ... | |
| Day 21 | 【填：收尾动作，如"记录21天变化"】 | |

【收尾鼓励】"打卡满21天，私信我领一份小礼物/方案～"
```

## 四、交付格式铁律
- 默认 .docx：标题居中加粗、问题编号+勾选框、打分区域用表格（python-docx 排版）
- 生成后明确告诉学员文件在哪、能直接打开
- 手机端无法生成 → ①先给文字版完整内容 → ②问是否导出（腾讯文档/手机长图/回电脑端生成）
- 若 python-docx 不可用 → 兜底 HTML，不用 .md
- 生成后询问：要不要配套手机长图版（PNG）？

## 检查清单（AI 交付前对照）
- [ ] 钩子类型和学员画像/赛道匹配（或学员已确认定制钩子）
- [ ] 自测表：5-8题、口语化、有结果提示分级（不诊断不承诺）
- [ ] 打卡表：天数+动作+感受三要素齐全
- [ ] 无功效承诺（"测完就知道你有没有湿气"→"测完帮你看看方向"）
- [ ] 已标注"这是参考模板，请按你的实际情况调整后再用"
- [ ] 交付格式为 .docx（或手机文字版降级）
