# 验收标准 · 产出物合格线（AI 交付前必对照）

> 读取条件：AI 出完每份产出物、交付前，必须对照本表自查；达标才交付。交付时告诉学员"我按×条标准查过，你重点看这几条"。

## 一、产出物合格线

### ① 名片装修方案（模板 01）
- [ ] 五位置（头像/昵称/背景墙/签名/置顶）全部给到
- [ ] 每处是"可直接用"的成品（昵称直接能改、签名直接能复制）
- [ ] 置顶三条覆盖：故事型+价值型+案例型
- [ ] 无品牌名/无功效承诺/无编造数字

### ② 朋友圈文案（模板 02）
- [ ] 五条铁律自查：口语化/有画面/有比喻/有具体动作/结尾想互动
- [ ] 黄金四段式四段齐全（标题/场景/方法/行动）
- [ ] 有钩子且确认过学员有没有资料（没有→已生成或已提示）
- [ ] 无品牌名/无强功效词/无绝对化用语/无编造数字结果
- [ ] 正文 ≤99 字，第四段已放评论区（四段式默认走分流）
- [ ] 一条只解决一个认知
- [ ] **比喻是按学员赛道现造的**（没照抄模板示例原句）
- [ ] **赛道用语对得上**：非中医赛道没出现"湿气/阳气/脾胃"等中医词；赛道不在知识库列表内时，调用了模型自身的大健康知识，没降质

### ③ 一周发圈计划（模板 03）
- [ ] 周一～周日完整 7 天，每天 2-3 条
- [ ] 每行有：时间 + 信任层 + 维度标签 + 内容摘要（一句话，不是空泛主题）
- [ ] 三层信任：第一层每天≥1条 / 第二层每天≥1条 / 第三层隔天≥1条
- [ ] 产品/事业圈 ≤ 总条数50%；每发1条产品配≥1条生活
- [ ] 六大维度轮着用，不连续3条同一维度
- [ ] 可视化总览图已生成（show_widget）
- [ ] 内容摘要用的是学员真实画像，不是通用模板

### ④ 钩子资料（模板 04）
- [ ] 钩子类型和学员画像/赛道匹配（或学员已确认定制钩子）
- [ ] 自测表：5-8题、口语化、有结果提示分级（不诊断不承诺）
- [ ] 打卡表：天数+动作+感受三要素齐全
- [ ] 无功效承诺；已标注"参考模板，按实际调整"
- [ ] 交付格式为 .docx（或手机文字版降级）

## 二、内容饱满度三件套（每份产出物必达）
1. **场景/痛点例子**：先给一个具体场景（让学员一眼知道"这说的是谁"）
2. **可直接用的文案**：逐句、口语化、复制即用（引号括起来，能直接发）
3. **落地动作**：有数字、有顺序的具体动作（如"今晚11点前放下手机""明晚私聊领资料的"）

> 自检：从头到尾读一遍——如果某环节只有一句概括（如"发一条生活圈"），**不合格**，必须展开到"能直接照着发"。宁可写得啰嗦，不可写得空。

## 三、返工机制（学员说"不对"就按标准改）
- 学员不满意 → 对照合格线**逐项检查，只改不合格的那一项，不重新生成一版**
- 返工话术：「你指的是哪条？我按标准查了，这条缺了'具体动作'（标准是给可执行动作），我补上，你看行不行」
- 学员说"太像广告/太假/不像我" → 对照五铁律/四步改造法逐项改，不整篇重写

## 四、内容力自检分支（交付后顺口一问）
- 「想再稳一点的话，说『帮我过一遍内容』，我按共鸣/价值/人感三关帮你查一遍。」
- 三关：**共鸣**（客户会不会觉得"说的就是我"）／**价值**（干货够不够）／**人感**（像不像人话、有没有 AI 腔）
- 纪律：只点最该改的 1 条，不列一堆
