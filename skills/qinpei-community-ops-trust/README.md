> 帮大健康 / 分享经济从业者，用 AI 把微信群从"广告死群"升级为"信任运营场"。

## 一、这是什么

一个 WorkBuddy AI 技能包。激活后，你用大白话跟 AI 说"我想建个群养客户""帮我排这周群内容""我的群要不要洗"，AI 就自动给你出完整方案——群公告、欢迎语、一周排期、互动话题、事业带教全都有。

**适合谁**：做艾灸 / 减脂 / 视康 / 茶修 / 护肤 / 体质食疗 / 抗衰 / 钙片 / 女性健康 / 儿童喂养 / 睡眠调理……任何需要运营私域微信群的大健康从业者、团队长。

## 二、怎么安装（手机 / 电脑都能装）

**手机端（推荐，用 WorkBuddy 小程序）：**
1. 把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好；或从 GitHub 仓库获取安装链接）
2. 装好后在输入栏「+」→「添加技能」里启用

**电脑端（Win / Mac 桌面版）：**
1. 把技能包 zip（如 `社群运营技能包v3.0.4_新升级.zip`）下载到电脑
2. 打开 WorkBuddy，把 zip 文件**直接拖进对话框**
3. 发一句："请帮我安装这个技能"
4. 安装完成后，在对话里说"帮我做社群运营"或"激活社群运营技能包"即可使用

> 手机、电脑装的是**同一份**技能，用法完全一样。

> 技能包内已**内嵌**朋友圈技能包的核心方法论（六大维度 / 三层信任 / 黄金四段式），**独立可用，不用再装朋友圈技能包**。若你已装朋友圈技能包，两者方法论一致，可配合使用。

## 三、五类群漏斗（v3.0 核心）

群不是并列的，是一条**从陌生人到事业伙伴的漏斗**。建群前先定类型，内容基调完全不同：

| # | 群类型 | 目标 | 服务对象 | 必做否 | 典型周期 |
|:---:|:---|:---|:---|:---:|:---|
| 1 | **兴趣群** | 养认知、建立第一层信任 | 未成交/潜在客户 | 首选必建 | 长期运营 |
| 2 | **会员服务群** | 已购客户专属服务与复购引导 | 已购买产品客户 | ≥20人+有复购潜力时建 | 长期运营 |
| 3 | **垂类打卡群** | 打卡带教、行为改变、转化复购/跨品 | 已购+有意向的客户 | 有垂类产品时建 | 7/21/90天 |
| 4 | **养伙伴围观群** | 让潜在伙伴"围观"你如何带人、带事业 | 有事业意向但未正式加入者 | 团队长必建 | 按需开启 |
| 5 | **事业群** | 带教培训、目标对齐、复制展业能力 | 核心事业伙伴 | 团队长必建 | 长期运营 |

**流转方向**：兴趣群 → （购买后）→ 会员服务群 / 垂类打卡群 → （有意向）→ 养伙伴围观群 → （正式加入）→ 事业群

**个人经营者最少做 2 类**：兴趣群 + 垂类打卡群
**团队长最少做 3 类**：兴趣群 + 垂类打卡群 + 事业群
**系统强大可跑满 5 类**，根据展业目标决定，不为了"全"而建

## 四、怎么用（三种姿势）

**姿势一：第一次用 / 不会表达 → 诊断优先**
直接说："帮我诊断一下我的群"。AI 会问 7 个维度（有无群 / 类型 / 画像 / 卡点 / 时间 / 赛道 / 当前群清单与精力），再出内容。

**姿势二：老手 / 赶时间 → 直接说**
"排下周兴趣群内容，客户是宝妈" → AI 直接出，跳过诊断。
默认先出**极简版**（骨架），你说"再细一点"才展开完整字段。

**姿势三：手动指令 → 文末 B 层**
复制技能包里的「指令 0~6」模板，填空发给 AI，精准产出。

> 💡 不用记编号！直接说一句人话就行，AI 自动识别你要干嘛。

## 五、内容产出四标签（双模式，不强制）

每条群内容可带 4 个标签，方便复盘和带教：
- **目标层**：养客 / 复购 / 事业 / 激活
- **信任层**：认识你 / 认可你 / 信任你
- **钩子设计**：投票 / 晒图 / 咨询 / 打卡 / 资料
- **行动指令**：发言 / 私聊 / 到店 / 打卡 / 转发 / 邀约

AI 产出时问你："要带四标签说明吗？还是直接出内容？"——**不强制**，你选。

内置 15 个真实赛道：视康、减脂塑形、茶修、艾灸、儿童健康喂养、40+体质调理、护肤抗衰、睡眠调理、脾胃肠胃调理、敏感肌、中医体质、气血湿寒、女性抗衰、钙片骨骼、乳腺健康。诊断时套用，AI 自动按你的行业口吻出内容。

## 七、产出格式（手机 / 电脑都能拿到）

- 学员向方案（群方案 / 排期 / 公告 / 话术等）**默认输出 Word 文档（.docx）**，生成后告诉你在哪、能直接打开；你想放桌面/某个文件夹，跟它说一声就行
- **手机上用**：它会先给你文字版完整内容，再问你要不要导出（腾讯文档 / 手机长图 / 回电脑端生成）
- 不输出 .md 文件（学员不熟悉）；如 python-docx 不可用则兜底 HTML
