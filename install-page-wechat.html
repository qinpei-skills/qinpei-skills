它能帮你做这 5 件事
1

装修微信名片

头像建议、3 个昵称、个性签名、背景墙，外加置顶三条朋友圈（故事 / 价值 / 案例各一条）

2

写一条朋友圈

认知升维 / 情绪疗愈 / 生活美学 / 事业轻感 / 过程纪实 / 认知普惠，六个方向任选，自动配业务钩子

3

排一周发圈计划

按「认识你→认可你→信任你」三层信任配比排满一周，配一张彩色日历总览图，照着发就行

4

改你写的朋友圈

把草稿粘给它，四步改造：洗稿重塑 → 视角转换 → 合规脱敏 → 植入行动引导。改几次它就开始学你的风格

5

公众承诺打卡

发起一个挑战，它写好首条承诺 + 每日打卡模板；哪天坚持不下去了，它给你写一条"我为什么还在坚持"

怎么用

1点上面的「复制安装指令」，提示"已复制"就行
2打开 WorkBuddy，在对话框里长按粘贴，发送
3手机保持亮屏别切走，等它说"装好啦"，再说一句你想写什么
小提示：装之前建议先把模型切成 DeepSeek，会更快。
