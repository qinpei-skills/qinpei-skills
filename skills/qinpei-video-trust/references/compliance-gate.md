# 合规门禁（AI 内部文件 · 每条口播稿交付前必读）

> 本文件是大健康/分享经济口播内容的合规总闸。**AI 做合规判断必须读本文件，禁止凭记忆。**
> 🔴 **叠加层**：本文件四关之外，还必须过 `platform-redlines.md`（平台八类红线，全平台违禁词 SOP，源自平台违禁词案例库 26 页解读）——**四关管行业词，八类管平台红线，两套全过才交付。**

## 关1 · 大健康合规词表

### 1a. 体质词 → 场景词转化表（自动替换，写稿时执行）

学员跟 AI 聊天可以说体质词，**上视频的稿子里不能出现**。生成稿时逐词扫描替换：

| 体质词（禁止上稿） | 场景词（替换为） |
|:---|:---|
| 气血弱 / 气血不足 | 一到换季脸色就差 / 蹲下站起来眼前发黑 |
| 寒湿重 / 体内有寒 / 宫寒 | 手脚常年冰凉 / 一吃凉的就难受 / 那几天疼得直不起腰 |
| 脾胃虚 / 脾胃不和 | 吃什么都不长肉 / 稍微吃多就堵得慌 / 吃点硬的就不舒服 |
| 湿气重 / 祛湿 | 早上起来眼皮肿 / 整个人沉沉的提不起劲 / 头发一天就油 |
| 阴虚 / 阳虚 / 上热下寒 | 嘴上起泡脚冰凉 / 上面燥下面冷 / 五心烦热改成手心脚心发热睡不着 |
| 失眠体质 / 神经衰弱 | 三年没睡过一个整觉 / 凌晨三点睁眼到天亮 / 一有点动静就醒 |
| 体质差 / 免疫力低 | 换季必感冒 / 别人没事我先倒 / 一累就要缓好几天 |
| 毒素 / 排毒 | （整句重写：讲具体感受，如"吃了一周清淡的，整个人轻快了"） |

**原理**：体质词=自我诊断（涉医疗语汇，视频平台判定为医疗内容）；场景词=生活描述（零风险且更共鸣）。**同病相怜的钩子没变弱，反而更真。**

### 1b. 功效禁词表（出现即改写）

| 禁词类型 | 示例 | 改写方向 |
|:---|:---|:---|
| 治疗承诺 | 治好/根治/痊愈/调理好了/不再复发 | 改为状态描述："她说最近睡得踏实了" |
| 绝对因果 | 吃了XX就好了/用了XX就通了 | 拆因果：只讲"做了什么动作+当下感受" |
| 病名+指标 | 血压从160降到120/结节变小了 | 换生活语言："体检报告上的箭头少了一个"（且需学员确认真实） |
| 绝对化 | 最有效/第一/100%/彻底 | 删除或改"我自己体感明显的" |
| 医疗动作 | 诊断/治疗/开方/用药 | 不出现；改为"体质辨证与生活方式调养分享" |
| 疾病名 | 高血压/糖尿病/结节/肿瘤（作为自己或客户的病症陈述） | 用困扰描述替代："被体检单吓到过的""家里老人常年吃药的" |

**科普格特别规则（未开放，先行写入）**：讲健康知识走"破谣型"最稳（"都说XX能XX，其实不是"）；讲行业知识、带团队知识零监管风险，优先做。

### 1d. 视力赛道转化表（v0.5.0 新增，源自杜鹃题四题实测）

视力/近视赛道是医疗宣称重灾区，**逐词执行**：

| 违规表述（禁止上稿） | 替代表述（场景化/现象化） |
|:---|:---|
| 视力**康复**（"康复"是治疗词） | 视力**防护** / 视力保健习惯 |
| 近视率 XX% / 我国青少年近视人数（无出处数据） | "每个班都有一片小眼镜"（现象级陈述） |
| 控制/降低度数、恢复视力 | 帮孩子**养成**用眼好习惯 / 把护眼动作做在日常 |
| 近视不可逆/可逆（医学定性表态） | 不碰医学定性，只讲"防护做得早，孩子少受罪"式生活判断 |
| 专利产品+功效（"专利技术改善视力"） | 专利可**陈述**（"手里有几项专利"），🔴 禁接任何功效后果句 |
| 眼轴/散光/屈光度等医学名词科普 | 转译成家长语言："看东西眯眼、凑得很近，就是信号" |

> 铁律同关1：学员聊天可以说，上视频的稿子不能出现。近视赛道稿件按本表逐词扫描后才可交付。

## 关2 · 引流 CTA 档位（收尾话术硬约束）

| 档 | 说法 | 规则 |
|:---|:---|:---|
| ✅ 最稳（默认） | "关注我，这类内容我每周都讲" / "我主页整理了一份XX清单，自己去拿" | 主页简介里写联系方式=平台默认容忍区 |
| ⚠️ 次稳 | "评论区聊聊你的情况" / "你们那儿是不是也这样，评论区说说" | 用了必须提醒学员**置顶一条评论**承接 |
| 🔴 禁（永不出现） | "加我微信" / "私信我" / "评论区扣1/扣2领资料" / "粉丝群等你" | 口播里说=限流/违规风险；资料钩子放主页或置顶评论文案里 |

**学员自带稿子里的违规 CTA**：改稿时一律降档到最稳档，并告诉学员"原来那句我帮你换了个说法，那句在视频里说容易限流"（不吓唬，说清利害）。

**钩子与 CTA 的分工（v0.2）**：CTA 管"关注我"这半句（按上表档位）；钩子管"勾住看下一条"那半句（下期预告/主页资料/系列感）——钩子档位表见 SKILL.md 通用层第四节，🔴 必问学员、永不代编。

## 关3 · 案例位【填】铁律

1. 故事/案例中**具体人物、具体情节、具体数字**，学员没提供的一律写 `【填：一句话引导】`，AI **永不代编**。
   - 正确：【填：她当时最难受的一个细节，比如"半夜给孩子盖被子自己却疼醒"】
   - 🔴 错误：直接写"有位王姐半夜疼醒了"（王姐是编的）
2. 示例骨架中的数字必须紧跟标注"（示例数字，换成你真实的）"。
3. 学员填完回传 → AI 只做顺口化和合规扫描，**不添加学员没说的细节**。

**为什么这么严**：学员的稿子直接面向终端客户播出——AI 编一个细节，违规和失信风险就转嫁到学员身上。宁可稿子有洞，不许稿子有假。

## 关4 · 声明句式库（按内容类型自动附尾）

| 内容类型 | 附尾软声明（口播最后一句或文案区） |
|:---|:---|
| 涉及客户状态变化的 | "每个人情况不一样，我分享的只是她的经历，不构成任何建议" |
| 涉及产品/服务介绍的 | "分享的是我自己的使用体验，不是医疗建议" |
| 涉及调理/养生方法的 | "体质辨证与生活方式调养分享，不涉及医疗诊断与治疗" |
| 涉及保健食品的 | "保健食品不是药物，不能代替药物治疗" |
| 涉及收入/事业变化的 | "这是我自己/我伙伴的真实经历，不代表每个人都能一样" |

**用法**：不是每条都挂——只在该条内容**触碰了对应场景**时挂，且换口语化表达（"说清楚啊，这只是她的情况，每个人不一样"），不写成免责声明腔。

## 交付前 30 秒过闸流程（AI 默默执行）

1. 扫体质词 → 有，替换场景词
2. 扫功效禁词（1b 全表）→ 有，改写
3. 扫行业敏感词（1c）→ 有，替换
4. 查 CTA 档位 → 禁档，降档
5. 查【填】位 → 有无代编痕迹
6. 该挂的声明挂了吗
7. 全过 → 交付；任一不过 → 重写该处再过一遍
