# 模板03 · 异议拆解卡（客户说贵/再想想/不买时用）

> 用法：客户一句异议 → 先跑预防检查 → 判定心结型 → 填这张卡 → 给话。

---

## 一、预防检查（🔴 先做，不能跳）

```
她说：「________________________」

□ 我是不是在她没说要什么时就报了价？ → 是：错报在先，先认自己的问题
□ 我是不是一次推了太多东西？      → 是：信息过载，缩到一件事
□ 我是不是跳过了决策人？          → 是：她要回去问人，找决策人，别催她
□ 我是不是没给过任何低门槛验证？  → 是：补一个可反悔的验证方式
□ 我是不是从没讲过我们的差异？    → 是：比较维度是我的漏洞
□ 我是不是在跟一个不需要的人硬聊？→ 是：考虑出局

自查结论：□ 是我的问题（先说"大概率是我前面没问清"）  □ 不是，往下拆
```

## 二、心结判定

```
□ 不信型　她的原话：____________________
   破法：换框（讲机制不讲神话）→ 归因拉回（具体的人具体的事）→ 降级验证（先试一小步）
□ 拖延型　她的原话：____________________
   破法：拆合理化 → 找那件具体的事 → 给最小动作（不是"你定"，是"今晚做这一步"）
   ⚠️ 她是真忙（有明确时间节点）→ 不拆不催，给个时间点
□ 比价型　她的原话：____________________
   破法：算账（单价拆成单位成本）→ 换维度（不比单价，比结果和风险）→ 给退路
   ⚠️ 同类产品确实更便宜 → 不贬低同行，给"买哪个"的判断标准
□ 无所谓型 她的原话：____________________
   破法：价值前置 + 弱连接 + 允许出局
```

## 三、给她的话（🔴 一句主线 + 一句转圜，学员用自己的嘴说）

```
主线（回应她的顾虑，不是回应价格本身）：
「________________________________________________」

转圜（给她一个不用拒绝的理由）：
「________________________________________________」

🔴 检查：这句话是学员自己说得出来的吗？说得出来就用，说不出来我改。
```

## 四、比价型专用 · 算账话术（🟡演绎，学员换语气）

```
你别只看这一次的价钱。你算一下你要用多久、一次多少钱——它比的是你现在用的那个东西，不是它的标价。
价格是明面上的。你可以再看看别处——我更想让你看的是：买完之后出问题，你找谁。
你先别急着定。你把两边的差列出来，差在哪一块，就按那块重要来定。
```

## 五、这轮的 Advance 与动作

```
这轮结束，她 ______ 了：____________________________
今晚就能做的最小动作：____________________________
跟进：第3天____ ／第7天____ ／第14天🔴线下____
退路：__________________________________________
```

## 六、允许出局（🔴 判定该放时用）

```
出局的信号：□ 明确说不需要 □ 明确要求别联系 □ 连续3次已读不回 □ 第14天推脱 □ 一直客气从不推进

收尾一句：「____________________」（只说这一句，之后不主动联系）
冷却复访点：____（判定冷却时填）
```

---

## 🔴 合规四查（每次给话前）

1. 有没有收益承诺？（含"一般""大部分人"软化版）
2. 有没有疗效承诺？
3. 有没有贬低同行？（🔴 不贬同行，只讲我们多了什么）
4. 客户名、案例细节是不是真的？（没给就留【填】）
