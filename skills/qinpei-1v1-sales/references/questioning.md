# 三层提问法 · 销售版全量

> 状态：v1.0.0-dev｜来源：1对1咨询交付板块「选择期学员问诊法·三层提问法」（两批六场实战验证）＋结构化销售范式（That's right 认同技术）
> 🔴 铁律：**每层1-2问，问完停3秒**。一次问三个以上 = 把话堵死。

---

## 一、三层推进的骨架（销售版）

| 层 | 干什么 | 推进逻辑 | 问完期待她说什么 |
|---|---|---|---|
| 事实层 | 把模糊感受变成可对账的数字 | "我觉得不行" → "到底是哪一块不行" | 一个具体数字或一个具体事实 |
| 选择层 | 把纠结变成选择 | 二选一、三选一，逼她站边 | 她自己说出选哪个 |
| 假设层 | 站未来回看，倒推今天 | "三年后你怎么介绍自己" | 一个关于方向的话 |

**🔴 顺序铁律**：事实没清，不许跳选择层（她不知道自己在意什么，选不了）；选择没落，不许跳假设层（她还没决定，方向是空的）。

## 二、事实层问法库（把"我觉得"变成数字）

> 🟢 实证：以下问法来自六场真实咨询的记录，学员可直接换赛道用。

### 成交与现状
- 「你现在一个月在这件事上大概花多少钱？」
- 「上个月你自己成交了几个？都是怎么成交的？」
- 「最近三个月，你主动私聊过几个客户？」
- 「你身边问过你这个的人，大概有几个？」

### 现有做法
- 「你现在是怎么解决这个问题的？」
- 「你上一次解决类似的情况是什么时候？当时怎么做的？」
- 「试过几次？每次的结果分别是什么？」

### 卡点定位（🔴 最实用的一问）
- 「你犹豫的是哪一部分？」（问完停3秒）
- 「如果这个解决了，你会不会买？」
- 「除了这个，还有别的原因吗？」

### 客户侧
- 「你自己用的话，最想要的是什么？」
- 「谁会用这个东西？家里谁说了算？」
- 「如果她（他）说不需要，你会怎么办？」

### 时间与精力
- 「你每天能拿出多少时间在这件事上？」
- 「这三个月最占你时间的是什么？」

### 目标口径（🔴 顾问式销售必问）
- 「你说的'做起来'，具体指什么口径？多少个人？多少钱？多长时间？」
- 「这个数字你是想去达成，还是想去证明？」

## 三、选择层问法库（逼她站边）

> 🟢 实证：来自六场咨询实录的二选一话术，学员可直接换赛道。

### 价值向
- 「你是嫌这个价格贵，还是不确定它对你有没有用？」
- 「你是想先自己用出效果，还是想现在就把它做成长期的一件事？」

### 客户 vs 伙伴
- 「你要的是更多客户，还是更对的人？」
- 「你说的拓客，是想要更多顾客，还是想换人带？」

### 短期 vs 长期
- 「你要的是这个月的收入，还是三年后的那条线？」
- 「你现在花时间的事，是为了这个月，还是为了以后？」

### 行动向
- 「先把自己的能力练出来，还是先把人手拉起来？只能选一个。」
- 「先全员铺开，还是先让一两个人跑出样板来？」
- 「你是想拉新，还是怕激活已经有的存量？」

### 决策向（🔴 客户型慎用，别把客户逼到墙角）
- 「如果今天就定下来，你最担心的是什么？」

### 行业 vs 平台（🔴 伙伴轨道专用）
- 「你选的是平台，还是这个行业？」

**🔴 选择层纪律**：给了选项就**停**。她选之前不补充第三个选项、不解释每个选项多好多坏——解释多了她回到"再想想"。

## 四、假设层问法库（站未来回看）

- 「三年后你希望别人怎么介绍你？——做过好几个平台，还是深耕这一行好多年？」
- 「如果三年后你没做这个选择，你最可能后悔什么？」
- 「你这一生要做的是哪个行业？平台会变，行业不会。」
- 「你现在担心的这个结果，三年后还重要吗？什么才重要？」
- 「一年后他们都能独立谈事——他们是'学会了话术'，还是'看到了你的样子'？」

## 五、追问四式（她不给你要的东西时）

| 情形 | 处理 | 示例 |
|---|---|---|
| 答非所问 | 换更小的切口 | 「我没问清楚，我想问的是……」（🔴 不重复原问题） |
| 沉默 | **不催，停3秒** | 沉默后说出来的往往是真话 |
| 给套话 | 追事实 | 「就是没方法」→「你最近一次用新方法是什么时候？结果呢？」 |
| 要答案 | 交回决定权 | 「你觉得哪条更适合你？我们一起验证」 |

## 六、That's right 认同技术（把"嗯"变成"对"）

> 来源：结构化销售范式（区分敷衍与认同）。🟡演绎，学员按自己语气改。

**四步**：
1. **听** —— 让她说完，不插话
2. **复述** —— 用她的话重复一遍
3. **给情绪标签** —— "所以你不是嫌贵，是怕花了钱没效果，对吧？"
4. **总结 + 等她说"对"** —— 说完停住，等她接

**🔴 关键区分**：
- 她的「**嗯**」「**是的**」「**对**」= 敷衍，不是认同
- 她的「**对，就是这样**」「**我就是这样想的**」= 真认同

**认同之后才能做的动作**：往下一层推进 / 给方案 / 落锤。
**没拿到认同之前不许做的动作**：给方案、催决定、加码。

## 七、好问题五项检查（AI 反问学员用，不是问客户）

> 来源：结构化提问范式。AI 在给学员"问什么"之前，自己先过这五项。🔴 学员版可简化成两句：「这个问题问的是谁？他是真能答上来吗？」

| # | 检查 | 不合格的样子 |
|---|---|---|
| 1 | 对象是谁 | "你觉得怎么样？"（谁觉得？） |
| 2 | 目标是什么 | "你有什么想法？"（想什么？） |
| 3 | 冲突在哪 | 问题里没有任何张力 → 她会给套话 |
| 4 | 约束是什么 | 没边界 → 答案无法落地 |
| 5 | 反馈怎么收 | 问完不知道下一步做什么 → 🔴 违反M4 Advance |

**不合格的宽问题 → 换小切口**：
- "你有什么想法？" → "这次你最想先解决哪一件？"
- "你为什么不做？" → "上一次想做是什么时候？当时卡在哪？"

## 八、问法库使用纪律

1. **一次不超过2个问句**（M5）
2. **问完停3秒**——不问完不接话，不自己填空
3. **能用她的原话问，就不要换成你的话**（她的原话比你的专业词更有杀伤力）
4. 🔴 **不问她答不上来的问题**（"你为什么想改变？"——她答不上来只会说套话）
5. 🔴 **不在她情绪起来的时候追问**（先接住情绪，再问事实）
6. 🔴 **不给宽问题**（宽问题=套话机器，套话机器=拿不到真信息）

## 九、每条问法的失效边界（🔴 用之前先扫这张表）

⛔ **"问法本身正确"不等于"这场对话适用"**。下面每条问法都有它失效的时刻——用错比不问更伤。

| 问法 | 🔴 什么时候不适用 | 该换成什么 |
|---|---|---|
| 事实层：把模糊感受变成数字 | 她刚哭过/刚发了一通火/刚被你上一句刺激到 | 先接情绪，一句都不问（问＝逼供） |
| 事实层：问她试过什么 | 她是老客且你们很熟、她从没买过（新手客户） | 问"你平时是怎么解决这个问题的" |
| 卡点定位（"到底哪一块不行"） | 她还没用你的东西（没用过就不知道哪块不行） | 先问她"最想要哪个变化"，把卡点留到用后 |
| 目标口径（"你想达到什么"） | 她是被家人拉来买的、她自己是"完成任务"心态 | 问"家里人最希望看到什么变化"——决策人换了，目标就换 |
| 选择层：客户 vs 伙伴 | 🔴 **零售客户场合绝对禁问**（"你是想自己买，还是想一起干"＝直接把客户推走） | 只在轨道B用；轨道A问"你自己用还是送人" |
| 选择层：短期 vs 长期 | 她已经明确说自己要马上（"我今天就要"） | 别逼她站队，直接给最小动作（成交技巧，不是顾问式） |
| 选择层：行业 vs 平台 | 她连你是谁都不清楚（还没建立基础信任） | 先回到心结识别，别急着上高层框架 |
| 决策向（"家里谁说了算"） | 她自己就是决策人（一个人住/单身/自己买） | 直接问"你自己定还是需要跟谁商量" |
| 假设层："三年后你希望别人怎么介绍你" | 她是纯零售客户（🔴 轨道A禁用） | 只在轨道B用；轨道A改问"你现在最想改变的一件小事是什么" |
| 假设层：站未来回看 | 她从没做过销售/从没带过人（轨道B的新手） | 先用"你现在最想挣到的一笔钱是什么"这类具体锚 |
| 追问四式 · 追问事实 | 她明确说"我不想聊这个" | 停，换话题或收尾（追问＝不尊重边界） |
| 追问四式 · 沉默停3秒 | 她在开车/开会/带孩子（物理上没法回） | 改文字或改约时间，别等 |
| 好问题五项检查 | —— | 这条是**AI 反问学员**用的自我检查，不问客户 |

🔴 **通用边界**：单次对话里三层推进（事实→选择→假设）**不是必须走完**。她在事实层就已经说清并愿意推进 → 直接进方案；她连事实层都不肯答 → 先处理心结，别硬上层次。

🟢 **理论锚点**：三层提问法锚定 GROW 模型（Growth/Reach/Objective/What/how/Why）——先探事实再定方向，是教练式对话的通行结构。🔴 **失效边界**：GROW 假设对方**有自觉、有表达欲、有时间思考**；对"怕被销售"或"完全没兴趣"的客户，直接上假设层=审讯。
