# 领域知识底盘（AI 生成文案时的"内容粮仓"）

## 🧭 赛道口径（先读这一条·决定你能不能接住学员）

> **下面列的 5 个领域是"常见赛道示例"，不是封闭清单。**
> 学员覆盖的是**整个大健康赛道**——中医养生只是目前学员最多的一类，绝不是全部。

**AI 按学员实际赛道分三种情况处理：**

| 情况 | 怎么处理 |
|:---|:---|
| 赛道**在列表内**（中医养生/减脂塑形/护肤抗衰/母婴育儿/创业） | 读对应领域段落，按里面的痛点库 + 选题角度生成 |
| 赛道**不在列表内**，但属于大健康细分（口腔/视力防控/康复理疗/营养补充/睡眠/心理/慢病管理/运动/功能医学/母婴护理/体检/医美/健康食品……） | **调用大模型自身的大健康知识**，按同一套逻辑（痛点→角度→维度→四段式）现场生成。**不许因为库里没有这个段落就降质、套模板、或说"这个我不太懂"** |
| 赛道**跨领域**（如"中医+减脂""护肤+内调"） | 两边都参考，取交集——用主赛道的痛点做骨架，副赛道的角度做包装 |

**❌ 赛道红线（最重要的一条）**：
**不许把非中医赛道硬套中医话术。** 学员做视力防控、口腔、营养品、康复、睡眠的，你却写"湿气重/阳气不足/脾胃虚"——这不是专业，是穿帮。
**学员自己怎么说，文案就怎么说。** 不确定学员的行业用语时，生成前问一句："你们行业一般怎么称呼这个情况？"

**✅ 无论哪个赛道，本文件末尾的「合规三层边界」照样适用**——越是不熟悉的赛道，越要保守。

---

> 读取条件：学员赛道确认后，AI **必须**读对应领域段落（痛点库/选题角度/深度知识触发），再生成文案；赛道不在列表 → 见上方口径表。
> 本文件不是教 AI 新知识——大模型本身已有**大健康各细分领域**（不只中医）与创业知识。它告诉 AI"哪些知识对朋友圈有用、用什么角度用、什么时候调用"。

## 知识调用黄金法则（AI必读）

```
生成文案时，AI 不是"先选维度再找知识"，而是：

痛点（客户真正烦的） → 角度（什么认知能解开） → 维度（用什么方式讲） → 四段式（怎么结构讲）
      ↑                                              ↑
   查领域知识库                                     查写作五铁律
```

**具体执行顺序**：
1. **锁定赛道**：学员的产品/服务属于哪个大健康细分？**列表内**→读对应领域段落；**列表外**→调用模型自身的大健康知识（不硬套中医，见上方口径表）
2. **匹配痛点**：从该领域的"客户最痛问题"中选 1 个最贴合的（列表外赛道：自己提炼该赛道客户最烦的 1 个问题）
3. **选定角度**：从该痛点对应的 2-3 个标题角度中选 1 个
4. **选择维度**：根据角度自然落到六大维度之一
5. **套四段式+五铁律**：黄金四段式搭骨架，五条铁律提升质量
6. **合规检查**：过违禁词、过功效宣称

## 🏥 领域一：大健康 · 中医养生

**核心定位**：帮普通人用"听得懂的人话"理解中医，不故弄玄虚、不恐吓式营销。

**客户最痛的5个问题（选题金矿）：**

| 痛点 | 朋友圈标题角度（任选一种） |
|:---|:---|
| 湿气重（舌苔厚/大便粘/犯困） | ①"你排的不是湿气，是焦虑"（认知升维）②"舌苔厚得能刮下来一层，别喝薏米水了"（认知普惠）③ 周末煮一壶陈皮茯苓水的画面（生活美学） |
| 气血不足（脸黄/掉发/手脚凉） | ①"气不够托不住五脏，血不够养不了皮肤"（认知升维）②"生完孩子感觉身体不是自己的了"（情绪疗愈）③ 一碗当归黄芪鸡汤的早晨（生活美学） |
| 失眠/睡不好（入睡难/多梦/早醒） | ①"你不是失眠，是心脾两虚——胃不和则卧不安"（认知升维）②"凌晨三点醒着的你，不是一个人在扛"（情绪疗愈）③ 泡脚120天记录（过程纪实） |
| 脾胃差（胃胀/不消化/没胃口） | ①"脾像抽湿机，机器没电你光倒水没用"（认知升维）②"把早餐牛奶换成小米粥"（认知普惠）③ 脾胃调理一个月的真实变化（过程纪实） |
| 上火/长痘/口臭 | ①"你上的不是火，是身体在喊'排不出去了'"（认知升维）②"别一长痘就喝凉茶——上热下寒的人越喝越糟"（认知普惠） |

**中医体质9种速查**（AI生成时参考，无需全部罗列给用户）：

|:---|:---|:---|

| 夏 | 养心·清暑 | "夏天出汗多不是虚，是身体在帮你散热" "三伏天喝冰水=往烧红的锅上泼冷水" |

| 冬 | 养肾·藏精 | "冬天别大汗淋漓运动——藏不住，春天就没东西发芽" "手脚冰凉不是穿少了，是肾阳不够烧" |

**深度知识触发（学员说"写深一点"/"更专业些"时调用）：**

## 🏃 领域二：大健康 · 减脂塑形

**核心定位**：打破"减脂=节食+疯狂运动"的认知，建立"调体质才能瘦"的信任。

**客户最痛的5个问题：**

| 痛点 | 朋友圈标题角度 |
|:---|:---|
| 越减越胖/反弹 | ①"你减的是水分不是脂肪——掉的每一斤都会加倍回来"（认知升维）②"代谢像炉子，你节食=把炉子关了，再吃什么都燃烧不了" |
| 肚子大/腰粗 | ①"肚子大不是胖，是脾虚托不住内脏"（认知升维）②"生完一年了肚子还像怀孕五个月——不是胖是气虚" |
| 腿粗/水肿 | ①"下午腿肿到鞋子勒出印子——不是胖，是湿气把身体泡发了"（认知升维）②"你不是腿粗，是排水系统堵了" |
| 便秘/排不出 | ①"三天不上厕所不是小事——肠道管着70%的免疫"（认知升维）②"别吃泻药，肠道不是下水道——一通就坏的" |
| 平台期/没动力 | ①"减脂不是马拉松，是存钱——每天存一点，急不来"（情绪疗愈）②"你已经坚持两周了，第三个星期才是真正的开始" |

**深度知识触发：**

| 话题 | 可调用的深层知识 | 朋友圈安全翻译 |
|:---|:---|:---|
| 为什么节食反弹 | 基础代谢适应性下降——身体感知到"饥荒"，主动降低能耗+提高脂肪储存效率 | "身体聪明得很——你饿它三天，它以为在逃荒，马上开启省电模式，再吃东西全变脂肪存起来" |
| 压力大肚子胖 | 皮质醇→促进腹部脂肪堆积+刺激食欲 | "压力大时身体以为你在逃命，拼命给你囤粮——还专囤肚子上，方便随时取用" |
| 肠道菌群决定胖瘦 | 不同菌群组成影响能量提取效率 | "不是你吃得多，是你肠子里的菌太会'榨油'了——别人100克米饭吸收120卡，你能吸200卡" |
| 胰岛素抵抗 | 长期高血糖→细胞对胰岛素不敏感→更多胰岛素→更多脂肪→恶性循环 | "不是你意志力不够——是你的细胞对胰岛素'麻木'了。就像听惯了噪音，得吼才听得见" |

**深度知识触发：**

## 💼 领域五：分享经济 · 直销/微商/社交电商创业

**核心定位**：不讲"拉人头"，讲"经营人"——让朋友圈看起来像事业伙伴，不像推销员。

**创业者的5个核心认知（朋友圈底层逻辑）：**

| 核心认知 | 朋友圈标题角度 |
|:---|:---|
| 经营人 > 经营流量 | ①"朋友圈不是柜台，是客厅——没人想在柜台交朋友"（认知升维）②"你以为是卖货，其实是帮人——帮到了，成交是顺便的事" |
| 线上养客，线下成交 | ①"别让客户在朋友圈就决定'不买了'——线上做朋友，线下做成交"（认知升维）②"朋友圈只有一个角色：让客户还没见你，就已经信任你" |
| 利他心态是最大的商业模式 | ①"不卖货，卖'我也想像你这样'"（事业轻感）②"帮了100多个人之后我明白：最好的销售是不销售" |
| 创业不是割韭菜，是种树 | ①"三个月就想躺着赚钱的，最后都回去上班了——慢就是快"（认知升维）②"你帮过的每一个人，都是你未来某一天的'刚好'"（过程纪实） |
| 朋友圈即人设 | ①"你的朋友圈就是你的简历——但不是写给别人看的，是活给别人看的"（认知升维） |

**常见客户抗拒及化解（事业轻感/过程纪实的素材库）：**

| 客户说什么 | 你怎么回（朋友圈可用的角度） |

| "我试过了没用" | 不是你不行，是方法没对上你的体质 → 发一篇"为什么同样方法有人管用有人不行"的认知文 |

## 🛡️ 深度知识合规三层边界（AI每次调用深层知识前必查）

> 越专业越危险。以下三条边界是铁律——宁可内容浅一点，也不能踩红线。

### 🟢 第一层 · 朋友圈安全区（放心写）
- 用**比喻/类比**翻译专业概念（线粒体=细胞发电厂、端粒=鞋带头的塑料帽、胰岛素=钥匙）
- 引用可以追溯的**公开经典**（《黄帝内经》原文、NIH可查的公共研究结论）
- 讲"**机制**"但不讲"**效果**"——说"身体是这样运作的"，不说"这样做就能瘦"
- 用"**可能/建议/我个人理解**"等软性措辞

### 🟡 第二层 · 慎写区（需加"个人化保护层"）
- 涉及具体生理机制的内容（如"胰岛素如何影响脂肪储存"）→ 加"我自己学下来是这么理解的"
- 营养学剂量/时间建议 → 加"我自己的习惯是……不一定适合所有人"
- 对比性说法（"这个方法比那个好"）→ 只比生活习惯，不比产品；只说"我个人觉得舒服"，不说"效果更好"

### 🔴 第三层 · 朋友圈禁区（绝对不能出现）
| 禁区类型 | 具体示例 |
|:---|:---|
| 细胞/分子层面的功效宣称 | ❌ "激活线粒体""延长端粒""提升NAD+水平" |
| 疾病诊断或治疗暗示 | ❌ "胰岛素抵抗的人应该……""端粒短的人容易……" |
| 任何量化效果承诺 | ❌ "两周降低皮质醇""三个月端粒变长" |
| 未经证实的"研究发现" | ❌ "哈佛大学最新研究""日本科学家发现"（除非能给出可查出处） |
| 借专业术语制造焦虑 | ❌ "你的端粒正在缩短""自由基正在摧毁你的细胞" |

### 🔑 深度知识翻译口诀（AI每次生成深度内容前默念）
```
专业概念 → 生活比喻
生理机制 → "我自己是这么理解的……"
科学名词 → 删掉，用大白话重说
任何效果 → 不承诺，只分享"我自己的感受"
```

## 📚 合规发布最后一道防线

在点击发送前，心里默念这三句咒语：
- **我不治病**：文案里绝不说"治好了XX病"
- **我不绝对**：文案里绝不说"最有效"、"第一"
- **我是分享**：多用"我个人觉得"、"这是我自己的经验"、"建议咨询医生"

> 💡 **一分钟自查清单**：
> - 功效宣称：用"养护/舒压/辅助/日常调理"替代"治愈/根除/抗癌/治病"
> - 绝对化用语：用"我个人首选/口碑很好/亲测"替代"最/第一/顶级/神效"
> - 专业性边界：建议咨询正规医生，不指导停药/诊断疾病
> - 情绪引导：鼓励接纳/倡导爱自己，不恐吓/制造焦虑
