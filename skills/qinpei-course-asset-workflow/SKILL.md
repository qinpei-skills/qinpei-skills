# 365 课程研发 → 素材图片 → 发布 工作流

## Overview
本技能沉淀了沁珮「365年度会员」知识付费产品从 0 到上架的完整实战流程，把已被用户确认的产品规则、视觉规范、图片生产方法和发布清单固化成一套可被新任务直接套用的 SOP。目标是让"研发课程 → 做素材 → 发布"变系统、变简单，避免每次重新摸索。

## When to use
- 要从小鹅通训练营形态设计一门新课程（年度会员 / 专栏 / 训练营）
- 需要为课程产出封面、详情页、作业封面、讲师海报、权益地图等上架图片
- 需要搭建小鹅通产品结构、整理上架素材清单
- 要做和 365 同形态的知识付费产品，且希望沿用已验证的视觉与文案规则

## 工作流总览（四阶段）
```
阶段1 课程设计  →  阶段2 视觉规范  →  阶段3 图片生产  →  阶段4 上架发布
(搭建方案/大纲)    (配色字体版式锁定)   (HTML→截图→PNG)    (整合+清单+小鹅通)
```

## 阶段1 · 课程设计
目标：先定结构再定素材，避免返工。
1. 产出《小鹅通训练营搭建方案》文档，明确：交付形态（训练营 / 专栏）、定价、产品结构（直播课 + N 大技能包）、滚动 / 单期模式。
2. 规划直播课大纲（365 = 12 节月度直播，每月 1 节、定时解锁）。
3. 规划技能包矩阵（365 = 4 大技能包：朋友圈信任经营 / 社群运营 / 沙龙活动 / IP定位诊断），每个技能包含「基础版 + 升级版」。
4. 确定命名与定价话术（如「365年度会员 / ¥365 一年一天一块钱」）。
5. 文档可上传腾讯文档协同（详见用户级 MEMORY.md 的「腾讯文档大内容上传工作流」）。

## 阶段2 · 视觉规范（全产品统一，禁止擅自改）
执行任何图片前，先读取 `references/visual-spec.md` 并严格遵守。核心铁律：
- 配色：暖米 `#F7F2E9` / 黛青 `#23403B` / 赭橙 `#C56B30` / 竹绿 `#7C9B6E`
- 编号：无底色、无加粗、右上角角标（基础版黛青、升级版赭橙）
- 详情页：自适应高度，不固定 3:4，内容必须完整显示
- 文案：「经销商」一律改「团队长」；不夸大、用真实数字；售卖页规避违禁词

## 阶段3 · 图片生产（已验证最优，禁止退回纯 AI 出文字图）
文字密集封面 / 详情页绝不用 gen-images 直接出（中文乱码、慢）。标准流程：
1. 写一份 **HTML 样式预览稿**（系统字体渲染中文零乱码），内含全部版式 / 配色 / 文案，先交用户确认。
2. 用户确认后，用 `html-brand-asset-exporter` 技能（Chrome 无头截图 + PIL 裁白边）导出 PNG。
   - 封面 1280×720（16:9）；详情页 / 长图 1080 宽、高度按内容自适应。
3. 临时渲染目录 `_tmp_render` 用完即清，只留成品 PNG。
4. 纯氛围质感图（纹理 / 光影）可单独用 gen-images 补，但文字层仍用 HTML 叠印。

## 阶段4 · 上架发布
1. 新建「小鹅通上架图片」文件夹，按场景分三类整合：训练营封面与详情页 / 讲师证书与通用 / 售卖页详情图。
2. 产出上架清单（已生成 / 待生成 / 卡素材），见 `references/asset-checklist.md`。
3. 小鹅通后台：建训练营 → 传封面 / 详情页 → 设 12 节直播定时解锁 → 挂技能包 → 上传售卖页 9 图（注意补齐缺失页）。

## 已确认的关键决策（365 项目，新任务默认沿用）
- 技能包全做「基础版 ＋ 升级版」双版本；每个技能补齐「作业封面」。
- 录取通知书由用户自行生成，AI 不产出（不纳入上架图）。
- 12 节直播课课件图待大纲最终确认后单独批次生成。
- 整体封面标题只写「365年度会员」，不带「训练营」三字。

## 复用资源
- 技能 `html-brand-asset-exporter`：HTML → 高清 PNG（本工作流阶段3使用，Chrome 无头 + PIL 裁切）。
- 参考 `references/visual-spec.md`：完整视觉系统规范（配色 / 字体 / 版式 / 编号 / 命名 / 尺寸）。
- 参考 `references/asset-checklist.md`：图片资产清单与待办（含已生成 38 张、缺失第7/9页、卡素材项、学员证书编号）。
