# 模板 · #8 线上线下一体化 · 活动群全周期（贯穿前中后）

> 用法：AI 按五阶段填话术；**大致周期约一周**（活动前 2-3 天建群预热 → 当天 → 后 1-2 天打卡 → 后 2-3 天解散分流；周期因人而异，节奏按此缩放）。
> 定位：为一场活动单独建「活动闪群」，活动结束群解散、客户按生命周期分流。线上部分（朋友圈/1V1/其他群邀约）归 #3，不重复。

## 核心路径：建群 → 预热养客 → 活动通知 → 现场播报 → 分享打卡 → 解散分流

| 阶段 | 动作 | 话术（填空式） |
|---|---|---|
| ① 建群（活动前2-3天） | 邀已报名/意向客户 + 能裂变的伙伴进群；报名不足 5 人可不建闪群，直接在养客群做 | 「欢迎来参加【××活动】～我是主理人××，活动前我会在群里发注意事项，姐妹们先互相认识一下，接龙报个名，方便我准备物料 ❤」 |
| ② 预热养客（前2-3天→当天） | ①活动通知（时间/地点/主题/着装/交通）②知识科普（每天1条干货）③群互动（接龙/问答/往期案例）④转介绍引导 | 「明天见啦～记得穿舒服点，带瓶水，位置发你：××」／「早呀～下午2点准时开始，来早的姐妹可以先聊聊天，等你❤」 |
| ③ 现场播报（当天） | 群内播报现场照片/小视频/氛围（同步发朋友圈）；收集现场反馈 | 「现场太热闹啦！姐妹们已经开始做香囊了，给大家直播一下～」 |
| ④ 分享打卡（后1-2天） | ①引导发活动感受（先发美照→总结收获→感谢，评选最佳分享）②打卡营（如7天养生打卡：每天提醒+案例）③主题科普 | 「昨天好开心～感谢大家来！照片我整理好发群里，大家自取～想继续聊养生的姐妹，我拉你们进我们的养生交流群，群里每天有干货」 |
| ⑤ 解散分流（打卡结束后） | 群解散（先说明去向，不烂尾）+ 客户分流 | 「这7天姐妹们坚持得都特别好！活动群就先解散啦，想继续聊养生的姐妹我拉你们进××群，想了解事业机会的姐妹找我聊～」 |

## 分流路径（硬规则）
- 买单 / 高意向 → **会员群**（服务+复购）
- 有兴趣未买单 → **兴趣群 / 养客群**（继续养）
- 想做伙伴 → **伙伴群**（事业带教）

**验收**：「群散了，客户没散」——分流话术齐、群按时解散、每类客户都有去处。

## 检查清单
- [ ] 五阶段齐全（建群/预热/通知/播报/打卡/解散分流）
- [ ] 每阶段含具体动作 + 话术
- [ ] 含大致时间（整体约一周）
- [ ] 分流路径齐（买单→会员群/有兴趣→兴趣群/伙伴→伙伴群）
- [ ] 群解散不烂尾（先说明去向）
