# 故事力提效技能包 · 使用说明（v1.1.0）

> 帮大健康 / 分享经济团队长，把"故事"变成信任的最短路径。
> 不会写提示词？跟它聊天就行。

---

## 一、这是啥

一个 AI 故事教练。你跟它说"帮我写个故事 / 发圈讲个案例 / 讲讲我的创业经历"，它会先跟你确认**这条故事用在哪一步、讲给谁听、主线是什么**，你 OK 了它才写。

**六类故事**：个人 / IP / 创业 / 案例 / 产品 / 失败转折，每类都有结构 + 场景 + 自检清单，还能按展业目标组合成完整故事线。

**数字真实铁律**：没真实依据的数字它会标【演绎参考值】，绝不让你拿假数字对外承诺。

## 二、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序）：**
1. 把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好）
2. 装好后在输入栏「+」→「添加技能」里启用

**电脑端（Win / Mac 桌面版）：**
1. 解压 `故事力技能包.zip`，得到 `qinpei-storytelling` 文件夹
2. 把文件夹放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 手机、电脑装的是同一份，用法一样。

## 三、第一次怎么说

**直接抄**：
> "帮我写个朋友圈故事"

**要讲案例**：
> "我要发圈讲个客户案例，帮我写"

**讲创业经历**：
> "我该怎么讲我的创业经历，吸引同频的人？"

## 四、它会怎么工作

1. 先跟你**确认**：这条故事用在展业哪一步（拓客/养客/成交/养伙伴）？讲给谁听？
2. 告诉你用哪类/哪组故事 + 主线是什么，等你 OK
3. 套结构写出来，并给你"为什么这么写"的说明
4. 短文案直接文字版给你（复制即用）；长内容给你 Word 文档

## 五、注意事项

- 它**不编数据**：没依据的数字标【演绎参考值】
- 它**不写真名真品牌**：公开用"一位团队长/美业老板娘"代指
- 你讲过的故事它会记住，下次直接续写，越用越像你
