# 诊断案例库（IP 定位 · 6 个案例）

> **什么时候读这个文件**：诊断过程中需要"讲个案例帮学员对号入座"时。案例是教学素材——具体数字为方法论示范口径，讲给学员听时点明"这是示范，你自己的情况按实际来"，严禁当成该学员的成绩承诺。旅游/育儿案例只用于说明三问、自定义单赛道与表达，**不代表非大健康要硬套九条健康赛道**。

---

**案例一：育儿团队长——"活成了一个广告位"**
一个做育儿的团队长，朋友圈早上"早安，元气满满的一天"、中午甩团购链接、晚上"晚安"。把自己当陌生人刷一遍——"好像……就是一个普通妈妈。"
→ **点破**："你不是不够努力，你是活成了一个广告位，不是一个活生生的人。"

**案例二：旅游学员——从"晒美照"到"避坑指南"**
一开始觉得"做 IP 就是拍好看的照片"，拍了半年该没人看还是没人看。后来换思路——不晒美照，开始分享"带娃出游的避坑指南"：哪个景点婴儿推车能进、哪些酒店有儿童餐、怎么在机场安抚哭闹的孩子。
→ 评论区全疯了："求攻略""太需要了""你什么时候开团"。
→ **结论**：她从"展示自己好看"变成了"帮别人做决策"。后者，才叫 IP。

**案例三：全职妈妈——同样一个人，三个月被追着问**
做健康养生副业，发产品海报+养生语录，两个月一条咨询都没有。后来做了**三个换**：
- **换身份**：从"我是XX品牌代理" → "我是懂食疗的二胎妈妈"
- **换视角**：从"XX产品调理效果很好" → "用我踩过的坑，帮你少花冤枉钱"
- **换内容**：不发产品图，发"一家三口的一周家常三餐怎么安排""公司给的食谱我试做了一次，哪步适合我、哪步不适合"
→ 一个月后评论区开始有人问"你家一周食谱怎么安排的"；**三个月内 20 多个妈妈主动问她：你在用什么？**
→ **结论**：她的专业度没有任何变化。变的只是她从"卖货的人"变成了"一个懂食疗的妈妈"。

**案例四：小C——三问＋自定义赛道＋模式立住，表达定生死**
30岁，女儿3岁，想做育儿副业，最开始晒娃+分享绘本，没起色。走三问：做什么→"带新手妈妈少走带娃弯路"；帮谁→"焦虑的新手妈妈"；解决方案→"带娃实操记录＋每周一个育儿小模板"。非大健康不套九条，自定义单赛道→**新手妈妈带娃实操**。模式→**成长打卡型为主**；过程背书→自己的真实带娃记录；表达人格→**同行者**（爱讲故事、爱跟人聊）。
→ 调整后方向："凌晨妈妈树洞"陪焦虑的新手妈妈聊天＋每周一个育儿小模板——从"泛育儿"收窄到"焦虑的新手妈妈"。
→ **三个月后自然涨粉 2000 多**，开始有出版社寄绘本找她合作。
→ **结论金句**：不要用"我想成为谁"来选模式——要用"**我本来是谁**"来选。不要用"哪里人多"来选方向——要用"**哪里我能做到不可替代**"来选。

**案例五：健康管理学员——从泛养生收窄到一类人，粉丝掉一半、收入翻两倍**
一个做健康管理的学员，一开始发"每天吃什么"的泛养生内容，发了半年粉丝不少，但变现很差——泛粉不买单。后来收窄人群，聚焦"30–45 岁职场女性的日常食养与活动管理"，发"我的一周三餐安排""加班日怎么给自己留出活动时间"。
→ **粉丝从 3 万掉到 1 万，月收入翻了两倍。**
→ **结论**：粉丝数不是资产，"不可替代"才是。宁可让 1000 个人离不开你，也不要 10 万人刷到你就划走。

**案例六：@欧阳会食养——从被观看到被查询（v5.0.0 · 公开案例）**

> ⚠️ **公开案例口径**：合为养创始人欧阳妤宣，小红书 @欧阳会食养，澎湃新闻等公开报道——**全网可查、可指名**（课 2 逐字稿 P14 定稿口径）。其余案例仍去标识化，本条是唯一例外。

- **赛道困局**：药食同源，爆火；古方概念，泛滥。消费者最大的问题不是不想买，是**验不出该信谁**——信任，是这个赛道最稀缺的东西。
- **「验得出」怎么做**：湖南中医药大学、中医药膳学研究生——定位一句话：**食养，只做食养这一条线**。
- **信号四节点（难模仿的高成本信号链）**：
  1. 食养一条线——不跨赛道，什么都做=什么都不精；
  2. 三到十五分钟长视频硬核拆解——食材是什么、日常饮食场景怎么用、食养文化怎么来的，一步一步讲。内容很干，**干，就是高成本信号，抄不走**；
  3. 供应链跑通才变现——粉丝催上链接不接，先找供应链，不满意自己建（仓库 50 平扩到 1000 平、九华山建工厂），**品牌才上线**；
  4. 类目榜首——一年半小红书滋补类目榜首，复购率 70%。
- **她的原话（金句）**：**「博主是流量变现，IP 是信任变现。」**
- **给学员点破的用法**：「她还是她，变的是：**从被观看，到被查询**。先选窄赛道立住，再把难模仿的信号一个个摆出来——客户不是被打动的，是**验出来信的**。」
- 🔴 讲这案例只讲打法与结构，**不承诺学员也能复购 70%/类目榜首**——数字是她的公开事实，不是学员的预期结果（防效果承诺，星光红线）。
