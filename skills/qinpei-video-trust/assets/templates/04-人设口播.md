# 模板04 · 人设口播（AI 生成前必加载本模板）

> **这一格干什么用**：让观众三分钟记住"你是谁、凭什么信你"。人设稿是主页置顶的命门——所有视频都在给这条引流，它接不住就全白搭。
> **双版本规格（默认双稿齐出，学员指定单版才单出）**：
> - 📱 **60秒内版**：约240字（上限260）——一个出身画面+一个转折+一句理念
> - 🖥️ **3分钟中视频版**：约700字（上限750）——加"入行前后的对比细节""最难那一段怎么熬的"两层
>
> **⚠️ 本格两大约束**：① 真实数字【填】永不代编（做了几年/服务过多少人，学员没说的一律问）；② 体质词红线（讲自己身体经历时最易踩，见下方转化表）。

---

## 人设合规转化表（本格专属红线，生成时逐词过）

> 学员讲自己的入行故事，十有八九会讲"我以前身体怎么怎么样"——这里全是雷。

| 学员会说的（🔴 视频里禁讲） | 自动转成（✅ 场景词） |
|:---|:---|
| 我以前气血弱 / 气血两虚 | 我以前手脚常年冰凉、上个楼梯都喘 |
| 我寒湿重 | 我以前一到下雨天浑身发沉 |
| 我脾胃虚 / 脾虚 | 我以前吃点凉的就难受一整天 |
| 我湿气重 | 我以前整个人肿肿的、早上起来眼皮都抬不动 |
| 我宫寒 | 我以前例假那几天只能抱着热水袋躺着 |
| 我体质差 | 我以前是办公室第一个倒下的，换季必中招 |

**原理**（讲给学员听）：体质词=自我诊断，平台判定为医疗内容；场景词=生活描述，零风险而且更真——观众看的是画面，不是名词。

---

## 第一步：先问学员三个真东西（资料卡没有的）

1. **你的出身画面**：入行前你在干什么？最真实的那一面（带娃/上班/开店/种地……起点不丢人，起点才可信）
2. **你的转折事件**：什么事让你进了这行？（一个具体瞬间最好）
3. **你的真实数字**：做了几年？服务过多少人？（🔴 AI 永不代编，学员说多少是多少）

---

## 第二步：按结构填空（四件套）

1. **【开头】出身反常识**（不从"大家好我是XX"开始——从画面开始）：
   - `三年前你要是跟【填：你当时的身份，比如"在超市理货的我"】说，我以后会靠养生吃饭，我肯定觉得你疯了`
   - `我入行那年，是全家人最反对的一年`
2. **【人设句·紧跟开头】**（人设格里人设就是主线，这句是"钉身份"）： 🔴 硬度标准：年头＋至少一个成果数字（客户数/伙伴数/场数/带出人数四者占其二），缺的按流程问学员或【填】留白，禁只报年头。
   - `现在我做这行【填：真实年头】年，【填：真实成果数字——服务过多少客户/带出多少伙伴，四者占其二】`
3. **转折**（为什么入这行，一个具体瞬间）：
   - 【填：转折事件——比如"孩子那场反复的咳嗽/妈妈那次体检/自己那半年糟糕的状态"。🔴 讲状态用场景词，过转化表】
4. **入行之后**（真实的过程，不装轻松）：
   - 【填：最难的一段+怎么熬的。这里最圈粉——观众要的是同路人，不是成功学】
5. **【收尾】理念钉死 + 钩子 + CTA**：
   - 理念句：`【填：你的一句话主张，比如"我想让跟我一样的普通妈妈，不用花大钱也能把日子过舒坦"】`
   - CTA：`这是我，关注我——【填：钩子，比如"以后我把我这些年踩过的坑、攒下的法子，一条条讲给你"（你真打算讲的才算数）】`

---

## 完整示例骨架（60秒内版；标【填】处学员填真事）

三年前你要是跟在【填：你当时的身份】说，我以后会靠养生吃饭，我肯定觉得你疯了。【开头】

现在我做这行【填：X】年，服务过的客户【填：真实数量】个。【人设句·紧跟】当年入行，是因为【填：转折事件——用场景词讲状态，比如"我自己那半年，天天早上醒不来，去医院查又查不出什么"】。我妈说我是瞎折腾，可我就是不服——【填：当时那股劲儿的真实原因】。【转折】

头一年最难。不懂的东西太多，被【填：真实的难，比如"家里人一句'正经工作不好吗'"】劈头盖脸地打。撑下来的理由特别简单：【填：一个真实瞬间，比如"第一个客户跟我说'多亏有你'的时候"】。【入行之后】

我没做成什么大事，我就是想让跟我一样的人知道：日子是能一点点养回来的。【理念】

这是我。关注我——【填：钩子】。【钩子+CTA】

**（60秒内版约240字；3分钟版在【入行之后】展开"最难那一年怎么熬的"两层细节+第二个真实瞬间。约700字。【填】必须学员真事——人设稿里一个假细节，观众扒出来就全盘不信。体质词全部过转化表。）**

## 底部检查清单（AI 交付前逐项打钩，缺一重写）

- [ ] 开头是画面/反常识，不是"大家好我是XX"？
- [ ] **人设句紧跟开头了吗（第二三句内）？**
- [ ] 转折事件用了场景词？（体质词转化表逐词过了？）
- [ ] **所有数字是学员的真实数字？AI 零代编？**
- [ ] 有"最难的一段"吗？（没有难处的成功学人设=假人设）
- [ ] **结尾钩子是学员真有的东西吗？**
- [ ] 理念句是从学员自己嘴里长出来的（不是AI替他升华的）？
- [ ] 每段尾句有让人往下看的理由吗（收尾段除外——收尾把话说完，只留钩子）？
- [ ] 版本对版吗？（60秒内版240字±10% / 3分钟版700字±10%）
- [ ] 时长标注 + 拍摄提示（人设格提示：坐着对镜头平视讲，像跟一个人说话，语速放慢）？
