# 创作与诊断双模式手册（AI 内部文件 · 学员端永不出现）

> **什么时候读本文件**：① 学员只有口述想法/模糊需求 → 走【创作模式】；② 学员自带稿/视频求诊断改稿 → 走【诊断模式】；③ 出观点型稿（价值观/科普格）需要理论支撑 → 读「理论锚点表」；④ 成稿/改稿交付前 → 过【出厂质检层】。主文件行为契约不变，本文件是两种模式的操作细则。

---

## 〇、模式判定（入口第一动作）

| 学员状态 | 走哪个模式 |
|:---|:---|
| 有稿子/有视频（求改、求看、求诊断） | **诊断模式** |
| 只有口述想法（"我想讲讲XX"）、没稿 | **创作模式** |
| 说不清要什么 | 先问一句："你是想让我帮你看看已有的稿子，还是从零帮你搭一条？" |

## 一、受众定向前置层（R-A1~A3 · 两种模式共用 · 最高优先级）

> **受众分裂是实战改稿中出现频率最高的问题**（5 次实测案例验证）——学员说"开头搞不清楚、不知道在跟谁说话"，根源几乎都是受众分裂。写稿第一步不是想"说什么"，是定"给谁看"。

### R-A1 一条稿子只对一个「你」说话

- 逐段问「这个『你』是谁」——出现第二个答案 = 受众分裂，先定人再动笔
- **A 由商业目的倒推**：这条要招人，A 就是想入行的人；顾客再重要，也只是讲给 A 听的论据，不是 A 本人（实测案例：近视防控稿原因一讲给家长、原因二三讲给想入行的人——统一 A=想找长线事业的人，家长场景降级为需求论据，开头自然就清楚了）
- 检验动作：成稿后逐段圈出所有第二人称，指同一个人才放行

### R-A2 系列受众锁定

- 学员要做系列（说"我要出一个系列/第X集"）→ 出框架前先问一句并记下：「这个系列给谁看？」——全系列每一集共用同一个 A，**单集换人 = 掉粉机制**（第一集吸引来的人第二集发现"跟我无关"就走）
- 系列第一集承担钩子角色：**停在转折决定那一刻切断**，方法论/成果留给第二集（系列燃料不能在第一集烧光）

### R-A3 受众三问（定不出 A 时问学员）

1. 你要的是哪批人？
2. 这批人现在正在经历什么？
3. 开头第一句能不能让他一看就知道"在说我"？

**禁靶**：不把"有问题的人"当靶子——批评人双输（做对的替同行不舒服、做错的防御）；批评打法，做对的人会点头。

## 二、创作模式

### Step 0 · 需求拆解（口述碎片 → 六要素，写死）

学员的需求永远是口述碎片。动手前先在内部拆成六要素，**缺项主动问（一次一问），不猜**：

| 要素 | 是什么 | 拆不出来时问 |
|:---|:---|:---|
| 核心观点 | 这条最想让人记住的一句话 | "这条你最想让人记住哪一句？" |
| 论证策略 | 先破后立/让步收网/纯立论 | （默认先破后立，选题有攻击性时用 W2 让步收网） |
| 商业落点 | 这条为哪个转化做信任前置（关注/主页/私信） | "这条发出去，你希望看完的人做什么？" |
| 定向要求 | 说给谁听（哪个细分人群） | "这条是给团队长看，还是给顾客看？" |
| 自证要求 | 需不需要显能力（理论/数据/案例） | 观点涉及专业判断时默认需要（W4） |
| 密度要求 | 对号入座是开头一句还是全片 | 定向要求明确时 → 默认全片（W6） |

拆完 → 进两步走第一步（出框架提纲），拆解结果融进框架的【填】引导里，不把六要素念给学员听。

### W1 · 泛话题做窄（定向动作）

选题里有公共话题词（学习/成长/思维/坚持）→ 第一步必须窄化到目标人群的具象场景。**判定标准：全片不允许出现一个泛化场景的例子**（不出现学英语/学编程/学生党），每个例子必须换算成学员观众的日常（激活死群/带教伙伴/留人/沙龙/客户复购）。

### W2 · 让步论证（先让步再收网）

攻击一个普遍行为之前，先显性豁免它的合理用途（"看开心/找启发/疗愈——无可厚非"），再切割出批评的靶心（"拿来吃饭的技能，必须系统学"）。作用：不树敌、给体面、靶心更准。**结构**：让步豁免（半句）→ 靶心切割（判断句）→ 三层论证 → 立。

### W3 · 开头发身份证

开场第一句点名目标人群里"做得对/最认真"的那批人（"这行里最肯学的团队长"）——让对的人第一秒知道这是给自己的，错的人自动划走。配合"批评打法不批评人"使用。已并入 hook-library「人群圈定型」的使用规则。

### W4 · 自证靠演不靠说（+ 理论显性化公式）

需要自证专业能力时，🔴 禁止直接夸自己（"我很专业""我很有经验"）。用"讲一个需要专业能力才讲得出的内容"来演示。最稳的演示格式：

> **理论名 + 提出者 → 说人话 → 落到学员观众的场景**（必要时 + 现场拆穿一个二手误传）

资历数字只作证据后置（放自证段，不放开头）。示例见下方理论锚点表。

### W5 · 万能论证例（讲"知识失真/碎片化/学习方法"的稿可直接复用）

「一万小时定律」的原点是心理学家艾利克森的《刻意练习》，而且原书恰恰说的是：光重复一万小时没用，要有目标、有反馈、有修正。——这个例子本身就是"二手知识传着传着传反了"的现场证明。使用时点明是论证示例，不嫁接学员不做的承诺。

### W6 · 密度校验（定向稿交付前逐段过）

写完逐段问：**这一段如果换个行业的人来看，还成立吗？**——成立就是密度不够，回去补行业场景。对号入座不是开头一句的事，是逐段校验项。

### 理论锚点表（观点型稿的干货段"理论支撑"工具，按需取用不堆砌）

| 理论 | 提出者 | 说人话 | 落到场景（大健康/团队长向） |
|:---|:---|:---|:---|
| 刻意练习 | 艾利克森 | 光重复没用，要有目标、有反馈、有修正 | 伙伴天天发朋友圈没结果 → 缺的是反馈和修正环 |
| 建构主义 | 皮亚杰 | 知识不是搬砖，得在自己的场景里长出来 | 刷一百条干货不如在自己的团队里做成一件事 |
| 峰终定律 | 卡尼曼 | 人只记得最高点跟结尾 | 沙龙/视频结尾必须给金句和钩子，中间可以有平 |
| 损失厌恶 | 卡尼曼 & 特沃斯基 | 失去的痛苦是得到快乐的两倍 | 只讲"会得到什么"不够，要点出"继续错的代价"（只陈述现状，不恐吓推演——铁律8） |
| 社会认同 | 西奥迪尼 | 人看大家都这么做才敢动 | 案例格的原理支撑：真实案例是最稳的信任状 |

🔴 使用纪律：一条稿最多用一个理论锚点，硬塞必水；理论是为观点服务的证据，不是炫耀。

## 三、诊断模式（学员自带稿/视频）

### 前置输入（视频先转文字再诊断；缺的主动问）

| 输入 | 必需性 |
|:---|:---|
| 文字稿或转写稿 | 必需 |
| 系列定位（单条 or 系列第几集） | 建议提供——系列开头逻辑不同（R1） |
| 这条给谁看 | 建议提供 |

### 诊断六步

1. **开头判断**（只看前 5-15 秒，隔离后文）：观众听到第一句以为这条讲什么？这个问题存在于多少人脑子里？第一句露的是处境/画面，还是情绪预告/meta（上集回顾/谢评论区/"今天讲个更扎心的"）？🔴 后文精彩内容被埋在第几秒——**被埋的好开头就是第一修改点**（R2）。⚠️ 提问式开场（"你尝过吗？"）是替观众宣布情绪，不是让观众看见处境。
2. **受众关系**：找出 1-3 类最可能有反应的人，他们认出了什么（处境/预期后果/群体身份）？这层关系被显露得够不够早？
3. **观看回报**：情绪回报（哪里被击中）/ 判断回报（哪句可以转述）/ 身份回报（看完对自己说什么）。**原则：情绪是入口，判断才是回报**——只有情绪没有判断，看完就忘。
4. **传播反应**（逐项判，不合总分）：停留（第一句给不给理由）/ 持续观看（中段有没有新信息新冲突）/ 评论（观众会不会讲自己的故事）/ 关注（钩子有没有具体到下一集讲什么）/ 转发（有没有可转述的金句）。
5. **商业价值 + 风险**：承接路径是什么；**广告味扫描**——哪句会让观众识别出"这是招代理/卖货的号"，把前面攒的真诚清零（常见雷：四件套清单、"大健康事业"式口号，见 R3）；合规扫描走 compliance-gate 统一清单。
6. **输出四段（固定格式）**：
   - 一句话结论（能不能留住人 + 最直接原因）
   - 观众看到开头会怎么想
   - 看下去以后能得到什么
   - 最该改的地方（最多 3 条，每条带"改后会带来什么"）

### 改稿纪律（R7/R8 焊死）

- **R7 占位符纪律**：事实位一律【填：…】、数字位一律【N】，绝不代编；改稿说明里写明哪些数字必须真实、哪些细节安全、哪些危险（被批评者/离开者零细节）。宁可不写，不能编。
- **R8 改稿只动该动的**：先列「保留资产」清单（哪些段原样保留 + 为什么），改动控制在 3 处以内。改稿的可信度来自克制——全盘重写会让学员失去自己的声音。

### 诊断侧通用规则（R1-R8 全量）

- **R1 系列视频开头规则**：系列 ≠ 可以用上集回顾开场。上集回顾/谢评论区压成半句放第 2-4 句；**故事第一句（有处境、有画面、有悬念）永远前置**——冷流量是每一集的主要增量，前 13 秒属于冷流量，不属于老粉。
- **R2 好开头被埋 = 第一修改点**：全文里最有画面感的那句如果不是第一句，提到第一句。
- **R3 清单式泄底**：「一部手机、一条账号、一个社群、一场直播」式四件套清单——观众想"就这？"，且触发"招代理"识别。方法清单留给专门一集展开；叙事集里只放一个真实场景（第一个动作 + 第一个回应的人）。
- **R4 细节的不对称使用（防对号入座）**：离开的人/被批评的人零细节；留下的人/正面的人写最小真实细节（一句原话、一件小事）。细节是可信度的燃料，控制流向。
- **R5 情绪段必须跟决定**：每段情绪之后跟一个"她/我做对了什么决定"——观众带走的不是"好惨/好励志"，而是"在 XX 时刻做了 XX 决定"。自我感动与观众代入的分界线。
- **R6 结尾排序**：金句 → 具体预告（具体到下一集讲什么人什么事）→ 轻 CTA。预告具体比"关注我看后续"强一个量级。
- **R7 / R8**：见上。
- **R9 预告不碰收益词**：预告下一条的悬念用反常识行为制造（"明明可以 X，为什么还 Y"），🔴 不用钱制造——"创收可观/赚了多少"类表述在预告和标题里有收益暗示红线风险。示例：把"为什么创收可观还坚持开实体店"改成"为什么明明可以轻松一点，还坚持开着这家实体店"——悬念不减、风险归零。
- **R10 资历一次讲透**：同一资历（年数/人数/头衔）全篇只出现一次完整表述，其余引用换说法。人设句只留最能定调的一项，实体店/专利/认证等留到正文论据处自然出现——资历是钩子不是主角，堆砌=心虚。
- **R11 开头禁自贬**：🔴 不用贬义标签开场再花全篇辩护（"我扎根在一件小事上"式——先自贬再说服观众不嫌弃=辩护姿态，天然弱势）。价值反转（"小恰恰是它的价值"）放中后段；开头给观众处境判决，作者姿态是判断不是辩解。
- **R12 时间词必须具体**：口播稿时间词写具体日期或"本周/这周"；🔴 禁"国庆后/过完年/下个月开始"类节假日模糊词——观众刷到时那个时间已过去，会当旧视频划走。

## 四、出厂质检层（Q1–Q6 · 成稿/改稿后、过硬门禁前执行）

> 方法论吸收自外部逐字稿质检流程（两案复盘验证：改稿中的高风险问题几乎全是"悬念埋了没接""指代没定义""数字重复"类——恰是生产时最容易漏的）。完播率的敌人不是内容差，是某一个瞬间观众跟不上了。

**Q1 钩子兑现校验**：凡稿中埋了悬念（"一件事""两个字""只做对了……"），必须在正文承诺位置当场揭晓；同一个悬念词全篇只允许一次核心表述。
**Q2 数字只砸一次**：同一关键数字（天数/人数/金额/场数）全篇只完整出现一次，第二次引用必须换说法（"1240 多天"→"简简单单喝到今天"）。
**Q3 三维度分段扫描**：按话题切换点切段，每段标注一句话功能（开头/人设/论证/案例/收尾）→ 依次扫三问：①段间——上一段最后一句和这一段第一句有没有跳跃？缺的承上启下是什么？②段内——有没有重复前面说过的？删掉这段观众缺关键信息吗？③句级——超 30 字的单句警惕；术语后有没有跟白话解释？
**Q4 指代当场定义**：新概念第一次出现必须当场定义（"火种，就是我带出来的伙伴"）——观众不带着困惑往下走。
**Q5 双 CTA 分主次**：一稿出现两个行动召唤时，设一个主（评论"想"字）、一个次（主页），用"也欢迎"以下降语调带过——双 CTA 平行并列=两个都弱。
**Q6 改稿边界声明（诊断模式必守）**：只管怎么说，不管说什么——学员的观点、案例、数据一律不改；学员已写好的金句段划为**保护区**，一个字不动；防把学员的稿子改成"沁珮腔"——表达基因是生产标准的描述，不是给学员稿换声带的工具。

**质检防跑偏两条**：
- 判断"跑题"前先问：删掉这段，观众在前一个关键节点能不能靠自己脑补出含义？脑补不出来 = 这段是论证的肉，不是赘肉。
- 稿子整体顺就说顺，不强行找茬——宁可漏掉小建议，不让高风险淹没在小问题里。

**质检输出格式（并入诊断六步第 6 步 / 创作模式交付自检）**：问题清单（🔴 高风险=观众大概率在这里划走 / 🟡 中风险=可能走神 / 🟢 小建议，每条引用原句）→ 原地标记改稿（删除线=建议删、🆕=新增，标记成对出现且不念）→ 改动清单表 → 一句话优先级决断（哪几处必改、哪几处选改）。

## 五、系列专项规则（学员做系列时加载）

1. **系列开写前先写一行「本系列 A = 谁」**（R-A2），全系列共用，出稿时回读
2. **第一集信息配比**：第一集 = 钩子集——停在转折决定那一刻切断，"怎么做到的"留给第二集；切断处即钩子处
3. **上集回顾压成半句**（R1）：放第 2-4 句，故事第一句永远前置
4. **预告不碰收益词**（R9）：悬念用反常识行为制造
5. **每集情绪段跟决定**（R5）：系列叙事尤其容易滑向自我感动——观众带走的必须是"她在 XX 时刻做了 XX 决定"

## 七、与 IP 定位的联动约定（词汇对齐，防跳出感）

学员画像里若有 IP 诊断产出的字段（四要素/一句话定位/表达基因卡/IP 类型/内容方向/获客链路），本包**直接复用同一套词**：

| IP 侧产出 | 口播侧怎么用 |
|:---|:---|
| 一句话定位 + 内容方向（2-3 个） | 选题引擎路径 0：从内容方向出题材，每个方向配四标准打分 |
| 你凭什么（经历/结果/共情背书） | 人设句素材库——人设句从背书里长，不靠年头硬撑 |
| 表达基因卡（叙事人格四型/永不说清单） | 语风调节器：研究者→拆给他看；过来人→坑带你绕；永不说清单并入合规关（学员自定义层） |
| IP 类型（专家/故事/陪伴/工具，主+辅） | 格推荐：专家型→科普/测评；故事型→故事/案例；陪伴型→Vlog/活动还原；工具型→价值观方法论/科普清单向。🔴 只推荐，学员点头才写 |
| 获客链路（钩子/留资/承接/归属，最断一环） | 钩子档位+发布包对齐：归属→关注追更；留资→主页资料/置顶评论；承接→私信话术（注意 CTA 合规降档） |

🔴 单装零依赖不变：本包自己采集时借用同一套词（四要素/表达基因/叙事人格），但不引导、不暗示安装 IP 诊断包；画像没有这些字段就当新学员轻量采集。
