# 沁珮共享画像银行

> 所有沁珮技能包共用的"画像银行"——学员的 IP 画像只存一份、填一次，全家桶所有技能包共享。

---

## 🔴 画像写入硬门禁（任何写入/更新操作前必须过，优先级最高）

**每一次写画像（新建/更新/迁移）前后，必须逐项过以下四关——缺任何一关即不合格，补齐后才算完成：**

1. **双写完成**——详细版主文件（`qinpei-profile/我的画像.md`）+ 用户级记忆标记块（`qinpei-profile:start/end`）**两处都写**；只写一处 = 没完成。
2. **标记块格式固定**——`<!-- qinpei-profile:start -->` 与 `<!-- qinpei-profile:end -->` 首尾标记齐全、精简版 ≤15 行；🔴 禁止漏写结束标记、禁止改标记名。
3. **字段名原文**——四要素固定为「你是谁 / 你凭什么 / 你给什么 / 你带来什么」，🔴 **禁止**替换成「你为谁」「你怎么做」等任何自创表述；IP 类型只能从【专家型 / 故事型 / 陪伴型 / 工具型】四类中选主辅，🔴 禁止自创类型（如"陪跑型"）。
4. **块外一字不动**——写入前先 Read 整个 `MEMORY.md`；只替换标记块之间的内容，学员自己的记忆一个字都不许动。

**写入前自检（默默做完再确认）**：两处都写吗？标记齐吗？字段名是原文吗？块外没碰吗？发现任何一处不对 → **修正后再写入**。本条优先级高于本文其他条款。

## 画像存在哪（两处，一详一简）

### ① 详细版（主文件）

`~/.workbuddy/skills/qinpei-profile/我的画像.md`

- 这是**所有沁珮技能包共读共写**的画像主文件
- 朋友圈、社群、沙龙、IP 诊断、故事力等技能包，对话开始时都先读它
- ⚠️ 已存在时**绝不覆盖删除**；学员说"重新填"才更新

### ② 精简版（用户级记忆 · 让画像"自动被读到"）

`~/.workbuddy/MEMORY.md` 里的一段标记区块：

```markdown
<!-- qinpei-profile:start -->
## 我的IP画像（沁珮技能包通用）
- 你是谁：…
- 帮谁：…
- 一句话定位：…
- IP类型：…
- 变现方式：…
- 避讳：…
<!-- qinpei-profile:end -->
```

- **为什么两处都写**：详细版放在 skills 目录里，只有"主动去读"才能看到；用户级记忆是**会话开始自动注入**的——学员后面再装别的沁珮技能包，画像会**自动被读到**，不用技能包自己去翻文件。
- **写入纪律（P0）**：
  - 先 Read 整个 `MEMORY.md`
  - **有标记块** → 只替换 `<!-- qinpei-profile:start -->` 与 `<!-- qinpei-profile:end -->` 之间的内容，**块外一个字都不许动**（那是学员自己的记忆）
  - **没有标记块** → 追加到文件末尾，不改动、不重排任何既有内容
  - 精简版控制在 15 行内（用户级记忆有字数上限）
- **兼容读取（老学员）**：读到旧位置（各技能包目录下自己的 `我的画像.md`）→ 迁到详细版主文件，并在精简版区块里补一份。

## 读取顺序（所有沁珮技能包统一）

1. `~/.workbuddy/MEMORY.md` 的 `qinpei-profile` 标记区块（最快、会话自动注入）
2. `~/.workbuddy/skills/qinpei-profile/我的画像.md`（详细版）
3. 旧位置兼容
4. 都读不到 → 正常采集

**读到之后必须先问一句**（不许默认沿用）：
> "我记得你的画像大概是：**【一句话复述】**。这次还沿用吗？沿用我就在这基础上升级，不用了咱们重新捋。"

- 说**沿用** → 只补缺的字段（尤其四要素里"你凭什么"、IP类型），不重复问
- 说**重新来** → 重问，**新内容覆盖旧画像**

## 画像标准格式（各技能包共同遵守）

```markdown
# 我的画像

## 一句话定位（最重要 · 所有内容统一回这句）
- 用【你的方案】，解决【什么人群】的【什么问题】：

## IP 定位四要素（IP定位诊断技能包产出 · 其他包只读参考）
- 你是谁 · 身份标签：（我是___角色，帮助___人群解决___问题）
- 你凭什么 · 信任背书：（经历背书 / 结果背书 / 共情背书，选中的那条写具体）
- 你给什么 · 价值承诺：（关注我，多久能拿到什么）
- 你带来什么 · 行动引导：（评论区扣1 / 私信我 / 预约下场）

## IP 类型
- IP类型：（主类型60% + 辅助类型40%，如"陪伴型60%+工具型40%"）

## 基础信息
- 行业+年限+主营：（如"做大健康5年，主营中草药保健品"）
- 帮什么人：（如"产后妈妈，调理身材+恢复气血"）
- 变现方式：（卖产品/卖服务/办卡套餐/招代理）
- 从业年限/人数：（如"5年，帮过100多人"）
- 客户最大痛点：（一句话）
- 不想出现的内容：（品牌名/敏感词/竞品）

## 引流钩子
- 主钩子：（领什么资料/体验什么）
- 钩子资料状态：已有 ✅ / 待生成 ⏳

## 风格偏好
- （学员改稿N次后提取的偏好，跨技能包生效）

## 文案类型偏好
- 默认类型：（A防折叠短文案 / B长文案 / 每次问）

## 免打扰设置（计数制）
- 免打扰计数：（每次对话-1，归零后重新确认）
```

## 三个核心动作

### ① 读取共享画像（所有沁珮技能包：对话开始静默执行）

按上面的「读取顺序」逐级找（用户级记忆标记块 → 详细版主文件 → 旧位置）：

- **读到** → 展示给学员确认："我记得你的画像是这样：…**这次还沿用吗？**"（沿用则在此基础升级；不用则重新问）
- **读不到** → 问学员（必答4项：你是谁/帮谁/凭什么/变现；可补：年限/痛点/一句话定位/IP类型/避讳）→ 答完写入画像（两处都写）
- **读到多个画像** → 先问"这次用哪个？"

### ② 导入（电脑喂手机 / 换设备恢复 · 学员粘贴即恢复）

学员粘贴一段画像文本（从电脑端复制的、或手机备忘录存的），AI **解析并写入共享画像文件**，回复：

```
收到，你的画像我恢复好啦～以后朋友圈、社群、沙龙这些技能包都会记得你，不用重新填。
```

判断标准：粘贴内容里有「你是谁/帮什么人/变现方式」等关键字段 → 直接入库；只有零散信息 → 整理成标准格式后入库并让学员确认。

### ③ 导出（备份 / 换设备 / 发给学员自己存）

学员说「导出我的画像」「把我的画像发我一份」，AI 把共享画像整理成**一段纯文本**（不加任何解释），让学员长按复制、存到手机备忘录：

```
我的画像是：做大健康5年，主营中草药保健品；帮产后妈妈调理身材、恢复气血；卖产品+办卡套餐；引流钩子是私信领《产后气血自测表》；IP主线是帮产后妈妈把身体还给自己；不想出现XX品牌名。
```

> 💡 这就是"人肉持久化"：手机端换对话/换设备画像可能丢，但学员备忘录里存着一份，随时粘贴回来秒恢复。
> 💡 如果这段画像不全、或你只记得零散信息（比如只记得"我是做艾灸的"），也可以直接把零散的发我，我帮你整理成标准画像再入库。

## 🔄 版本自检与升级（学员一句话就能升级，不用重装）

**🔴 学员只要说下面任意一句，就走这一节**（不用他复制粘贴安装口令、不用他找链接）：
「升级到最新版本」「升级技能包」「技能包自检升级」「检查更新」「有没有新版本」「更新一下技能包」

**AI 五步执行（一次做完，别来回问）**

**第 1 步 · 看本机装了什么**
```bash
ls -d ~/.workbuddy/skills/qinpei* 2>/dev/null
```

**第 2 步 · 取线上版本表**（这是唯一的版本真源，别用记忆里的版本号）
```bash
curl -fsSL --max-time 10 "https://qinpei-skill-all.app.workbuddy.host/skills-catalog.md?t=$(date +%s)"
```
在返回内容里找 **VERSION-MANIFEST** 那一段，每一行长这样：`包名=版本`（**只认小写字母开头的行**，说明文字里也带等号，别被带偏）。
取不到就换域名 `https://qinpei-skill-all.app.workbuddy.link/skills-catalog.md?t=时间戳` 再取一次；两次都失败 → **如实告诉学员「现在连不上更新服务器，过会儿再试」**。🔴 禁止瞎猜版本、禁止拿记忆里的旧版本糊弄。

**第 3 步 · 逐包比对**
比「线上版本」和「本机 `~/.workbuddy/skills/<包名>/SKILL.md` 里的 `version:`」：
- 线上更新 → 进第 4 步
- 一样 → 记作「已是最新」
- 本机有、版本表里没有 → 跳过，并在汇报里如实说明

**第 4 步 · 升级（一个包一次）**
```bash
S=<包名>
U="https://qinpei-skill-all.app.workbuddy.host/skillhub-zips/$S.zip?t=$(date +%s)"
curl -fsSL --max-time 15 "$U" -o "/tmp/$S.zip"
head -c 2 "/tmp/$S.zip"          # 应为 PK，确认它真是个 zip
python3 -c "import zipfile,os;zipfile.ZipFile('/tmp/$S.zip').extractall(os.path.expanduser('~/.workbuddy/skills/$S'))" \
  || unzip -o "/tmp/$S.zip" -d ~/.workbuddy/skills/$S/
grep -m1 '^version:' ~/.workbuddy/skills/$S/SKILL.md    # 复查：应等于线上版本
```

**🔴 升级四条铁律**
1. **绝不用 `rm -rf` 删技能目录**——学员的资料卡和档案就在里面
2. **不用手工备份**：zip 里本来就不含 `我的画像.md` 和 `学员档案/`，覆盖解压**只覆盖同名文件**，学员数据天然不受影响
3. **解压必须复查版本**——`grep` 出来的等于线上版本，才算升级成功
4. **🔴 取任何本站文件都要带时间戳参数**——边缘节点会缓存旧内容（实测：不带参数时可能拿到几分钟前的旧版）。**上面所有 `qinpei-skill-all.app.workbuddy.host` 地址，抓取时一律在末尾拼 `?t=$(date +%s)`**（只能读网页、跑不了 shell 时，就换成当前时间戳的随机数字）。这样每次 URL 都唯一 → **永远回源拿最新**；漏了它就可能读到旧版本表，升级会**静默不执行**（最难发现）。

**第 5 步 · 汇报（一句话，别写小作文）**
> 已升级：<包名> <版本> ✅ 不用重装，你的资料卡和记录都还在。
> （全都已是最新时：）查过了，你现在都是最新版，不用动。

🔴 上面的 `<包名> <版本>` 用**你实际升上去的**替换，**别照抄示例数字**。

**⚠️ 边界**：升级**只升学员已经装过的包**，绝不借机引入他没装过的新技能包；升级过程里**不提「qp」、不提其他技能包名**。

本机一个 qinpei 技能包都没有 → 说明还没装过，引导他用原来的安装方式装一次即可。

**手机端 / 没有命令行工具怎么办**
用你能用的取文件方式（读网页 / 下载）做同样三件事：**取版本表 → 比版本 → 覆盖写入新文件**。
落盘位置和上面一样，**同样不许删除任何已有文件**。
