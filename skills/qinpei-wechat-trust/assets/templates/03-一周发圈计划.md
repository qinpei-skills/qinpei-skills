# 模板 · #3 一周发圈计划（三层信任 × 阶段配比 + 可视化总览图）

> 用法：AI 把学员信息填入【】占位；**示例列的内容可直接复制改词即用**；填完对照底部检查清单自查。

## 一、先定阶段配比（AI 判断学员阶段）

| 阶段 | 判断依据 | 找意向:养关系:促成交 |
|:---|:---|:---:|
| 起步型（缺客户） | 刚开始/客户少 | 6:3:1 |
| 成长型（建信任） | 有客户但信任不够 | 4:4:2 |
| 成熟型（促成交） | 信任够了/成交不够 | 3:4:3 |

学员可手动调整："这周我想多做成交" → 调高促成交占比。

## 二、一周计划表（周一～周日 · 三层信任+维度+钩子）

> 输出时每行含：时间 + 信任层 + 维度标签 + 内容摘要 + 钩子

### 周一
- 08:00 【第二层·认可你】IP价值（维度：认知升维）→ 内容：【填：主题+黄金四段式一句话】
  - 示例：「补钙三个误区，你中几个？→ 评论区互动，私信领自测表」
- 12:30 【第一层·认识你】生活 → 内容：【填：生活日常一句话】
  - 示例：「今天早餐的小米粥，熬出米油了🍚」
- 21:00 【第三层·信任你】案例（隔天1条）→ 内容：【填：客户案例一句话，去标识化】
  - 示例：「客户说调理两周，晚上能睡整觉了（打码）」

### 周二

- 12:30 【第一层·认识你】生活 → 内容：【填：生活日常一句话】

### 周三

- 21:00 【第三层·信任你】案例 → 内容：【填：客户案例一句话】

### 周四

- 12:30 【第一层·认识你】生活 → 内容：【填：生活日常一句话】

- 21:00 【第三层·信任你】方法SOP → 内容：【填：一个方法/流程分享一句话】

- 21:00 【第二层·认可你】IP价值（维度：认知普惠）→ 内容：【填：一周总结/干货一句话】

## 三、配比校验（AI 必须核对）
- [ ] 第一层（认识你）每天 ≥1 条
- [ ] 第二层（认可你）每天 ≥1 条
- [ ] 第三层（信任你）隔天 ≥1 条（一周3条左右）
- [ ] 产品/事业圈 ≤ 总条数 50%
- [ ] 每发 1 条产品/事业，配 ≥1 条生活
- [ ] 六大维度轮着用，不连续 3 条同一维度

## 四、可视化总览图（硬规则，不可省略）

输出一周计划时，**必须**同时调用 `show_widget` 生成一张色彩鲜艳的日历式可视化总览图，与文字版计划配套呈现。

**可视化总览图必须包含**：
- **标题行**：IP定位 + 总条数 + 关键规则摘要（如"IP价值型每日≥1条""事业轻感占比≤50%"）
- **三层信任图例**：L1认识你（绿色系）、L2认可你（蓝色系）、L3信任你（橙色系），各标注总条数
- **每日卡片行**：左侧日期标签（周一~周日 + 当日条数），右侧并排展示当日每条朋友圈的色卡
- **每条色卡内容**：发布时间 + 维度标签（彩色小药丸）+ 内容摘要（一句话）
- **色卡左边框颜色**：对应该条所属信任层（L1绿/L2蓝/L3橙）
- **维度标签颜色**：六大维度各用不同颜色（认知升维=紫、情绪疗愈=粉、生活美学=绿、事业轻感=珊瑚、过程纪实=灰、认知普惠=黄绿）
- **底部统计栏**：总条数 / IP价值型条数 / 事业轻感占比 / 维度覆盖数

> 💡 技术实现：先 `read_me` 加载 diagram 模块，再用 `show_widget` 输出 HTML 日历组件。参考已验证的 flex 布局 + 彩色左边框 + 彩色维度标签方案。

## 检查清单（AI 交付前对照）
- [ ] 周一～周日完整 7 天，每天 2-3 条
- [ ] 每行有：时间 + 信任层 + 维度标签 + 内容摘要（一句话，不是空泛主题）
- [ ] 内容摘要用的是学员真实画像（产品/人群/痛点），不是通用模板
- [ ] 三层信任 + 配比校验全过
- [ ] 可视化总览图已生成（show_widget）
- [ ] 无编造数字结果
