# 模板 · #2 物料准备清单（活动前 · 三类+检查）

> 用法：AI 按主题填【】；成本硬约束：低配 0 元 / 标配 ≤15 元每人。

## 一、场地布置
【填：桌椅/背景板/签到台/灯光等，按体验感布置】
- 示例：「客厅围坐一圈（拉近距离）＋ 签到台（进门先登记）＋ 一角拍照位（拍立得/手机支架）」

## 二、活动物料（主题相关 DIY 材料 + 微课道具 + 茶水）
【填：按主题选载体，低配 0 元 / 标配 ≤15 元每人】
- 示例（养胃茶话会）：「养生茶包材料（陈皮/山楂/桂圆，拼多多 ≤15 元/人）＋ 茶具＋小点心；低配版＝家里有的茶叶+热水，0 元」

## 三、设备检查
【填：音响/投影/手机支架（现场播报拍照用）】
- 示例：「手机支架（现场播报+合影）＋ 小音箱（背景音乐）＋ 充电宝」

## 四、演练检查项（活动前 1 天逐项打勾）
- [ ] 主持流程过一遍（主持人自己走一遍串场词）
- [ ] 物料齐全（按本清单核对）
- [ ] 分工确认（每人知道自己干什么）

## 检查清单
- [ ] 场地布置/活动物料/设备三类齐全
- [ ] 每项标「谁准备 + 多少钱」
- [ ] 含演练检查项（活动前 1 天逐项打勾）
- [ ] 物料成本符合低配 0 元 / 标配 ≤15 元
