# 展业破局 · 诊断 · 使用说明（v2.0.0）

> 经营卡住了、做了很久业绩上不去、不知道该先动哪一步——
> 跟它聊，它像老中医把脉，一层层帮你把卡点捋出来。
> 不会写提示词？说人话就行。

---

## 一、这是啥

一个 AI 经营顾问。它不灌鸡汤，也不替你下决定——

**它只做一件事：帮你分清"这是真问题还是假问题"，然后告诉你先往哪走。**

- **五层剥茧**：一步步检验你说的那个问题到底成不成立（把检验过程摊开给你看，让你自己看见因果断在哪，而不是被说服）
- **四层把脉**：心态层 → 选择层 → 能力层 → 执行层，从下往上查
- **地基层**：先查最底层的资产——你的客户是谁、你能替他解决什么问题

查完给结论，你确认了，它才告诉你接下来用哪个技能包落地。

## 二、两个入口，随你挑

| 你的状态 | 它会怎么做 |
|:---|:---|
| **有点迷茫**（不知道先干啥 / 卡住了） | 走完整诊断，一层一层问 |
| **很确定**（我就想拉新 / 我就想要文案） | 尊重你的选择，直接照做；只在关键处提醒你一句 |

**它不拦你，也不拒绝服务。** 只是提醒一句"你确定这是你的真问题吗"——决定权永远在你。

## 三、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序 / APP）：**
1. 把安装指令粘贴到对话框发送（约 30 秒装好）
2. 装好在输入栏「+」→「添加技能」里启用

**电脑端：**
1. 解压 `qinpei-business-check.zip`，得到 `qinpei-business-check` 文件夹
2. 放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 手机、电脑装的是同一份，用法一样。纯对话诊断，默认不产文档，手机用最方便。

## 四、第一次怎么说

**直接抄**：
> "帮我看看我的经营卡点"

**带具体处境**：
> "我做这行好几年了业绩上不去，帮我看看卡在哪"

**只想开干**：
> "我想做一批新客，帮我出个思路"

## 五、它会怎么工作

1. 先问你想把脉，还是直接开干（选一个就行）
2. 先查地基层：你的客户 × 你的解决方案
3. 四层把脉：心态 / 选择 / 能力 / 执行，每层给判断，等你确认
4. 五层剥茧：这个卡点是真问题还是假问题，讲清依据
5. 你认可结论 → 它告诉你用哪个技能包落地（朋友圈 / 社群 / 沙龙）
6. 你不认可 → 尊重你，按你的思路重新捋

## 六、注意事项

- 它**不写具体文案 / 方案**——那是"朋友圈""社群""沙龙"技能包的活
- 它**不编结论**：你没有讲的，它不会替你下判断
- 它**不评判对错**：只剖因果，选择权在你
- 诊断是聊出来的——一次只问一个，一次说不清没关系
