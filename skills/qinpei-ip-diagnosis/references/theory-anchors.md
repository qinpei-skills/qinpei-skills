## 一、理论锚点（2001 年诺贝尔经济学奖 · 双奖背书）

> **口径要求**：说人话三句 + 落到场景。点名提出者（可查证），显性化表达——「理论名+提出者→说人话→落到场景」。

### 1. 柠檬市场（阿克洛夫，2001 诺贝尔经济学奖）

**说人话三句**：
1. 买家验不出货的真假好坏，就不敢出高价，只敢出平均价；
2. 于是好货卖不上价，劣币驱逐良币；
3. **大健康就是典型的柠檬市场**——客户不是不想买，是验不出该信谁。

**落到场景**：「你朋友圈里那些『看了不买』的人，很多不是没钱不想健康，是**验不出你和别人有啥区别**。信任，是这个赛道最稀缺的东西。」

### 2. 信号传递（斯宾塞，2001 诺贝尔经济学奖）

**说人话三句**：
1. 光说自己好没用，买家不信嘴，信**成本**；
2. 只有**难模仿的信号**，才传得了真实能力——谁都做得到的，等于没说；
3. **成本，就是可信度。**

**落到场景**：「你说『我很专业』，一分钱成本没有，没人信；你花三年考下药膳学的研究生、天天拆长视频讲原理，这是**高成本信号**，抄不走，才传得出去。你的差异化业务定位，就是把你身上最难模仿的信号挑出来，摆到明面上。」

**金句收口**：**成本，就是可信度。**

## 二、定位定性（立场铁律 · 学员说「IP 没用」时的标准接法）

> 🔴 **核心口径（照抄）**：「IP 没有问题——有问题的，是你的商业模式和解决方案的定位。」

**功能区分（只做区分，禁止说 IP 过时/错了/没用）**：
- IP = 让人**认识**你（脸面、影响力、粉丝）
- 业务定位 = 让人**找你**转化（做生意、验货、成交）
- 两者不冲突，**先立生意（三问），再谈表达（包装）**——顺序不能反。

**🔴 禁止**：「IP 打造已过时」「他们教 IP 的都是错的」「别再做 IP 了」——一律不说。就事论事讲底层要义，名字不重要。

## 三、金句弹药库（课 2 金句卡全量 26 条 · 按场景取用）

> **用法**：结论确认、话术卡收口、学员卡壳点破时取用。**禁止每句话都甩金句**——一个诊断流程里用 2–3 条，用在刀刃上。

### 定位断裂系
- 博主演给粉丝看，我们做业务。（P2）
- 来的人不是你服务的人，转化自然就断。（P3）
- IP 没有问题——有问题的，是你的商业模式和解决方案的定位。（P4）
- 粉丝信她「会挑」，不信她「懂健康」——人设和生意隔着一条河。（P5）
- 定位不是挂在嘴上的标签，是验货现场你恰好掏得出来的东西。（P6）
- 立不住的定位，发圈就是白发。（P10）
- 你不是说给所有人听的，你是说给「等这句话的人」听的。（P12）
- 什么都做，等于告诉别人你什么都不精。（P13）
- 场景可以当包装，不能当定位。（P16）

### 理论与赛道系
- 成本，就是可信度。（P4）
- 三节不是三件事，是一棵树的三段。（P7）
- 你自己都立不住，就别谈带人。（P8）
- 博主是流量变现，IP 是信任变现。（P14 · 欧阳妤宣原话）
- 招商型的奖，是给走过路的人的。（P17）

### 内容与执行系

- 四类轮着来，账号才是活的。（P21）
- 写一条圈的时间，把一周的内容排出来。（P22）
- 吓来的关注留不住，过程才吹不了牛。（P24）
- 能被抄走的，都不是证据。（P25）
- 工具不解决问题，习惯解决问题。（P26）
- 公域引流没有错，接不住才是错。（P29）
- 他带着敬意来验证，你给他看的是刷屏——这一单死在这一屏。（P30）
- 不是翻旧账，是面向未来。（P31）
- 你缺的不是素材，是去拿的眼睛——先有米，再谈开火。（P35）
- 信任是存出来的，不是晒出来的。（P37）
