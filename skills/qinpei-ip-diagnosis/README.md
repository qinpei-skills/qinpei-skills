# 个人IP定位诊断 · 使用说明（v3.0.1）

> 帮大健康 / 分享经济团队长，搞清楚"我到底该立什么人设、发什么内容、做哪种 IP"。
> 不会写提示词？跟它聊天就行。

---

## 一、这是啥

一个 AI 诊断搭子。它用**IP 信任体系四要素**跟你走一遍，最后给你三样东西：

1. **一句话定位**——用【你的方案】，解决【什么人群】的【什么问题】
2. **IP 类型**——你适合做哪种 IP（专家型 / 故事型 / 陪伴型 / 工具型），以哪种为主、拿哪种补
3. **成熟度打分**——你现在几分，最缺哪一块

**它只给方向，不写文案**。犀利、直接、不灌鸡汤。

**适合谁**：做了很久却不知道"该立什么人设"、发圈没人理、不知道"我适合做什么类型"的团队长。

**它独立可用**：装这一个就够，不依赖其他任何技能包。

## 二、安装（手机 / 电脑都能装）

**手机端（推荐，WorkBuddy 小程序）：**
1. 把安装指令粘贴到 WorkBuddy 对话框发送（约 30 秒自动装好）
2. 装好后在输入栏「+」→「添加技能」里启用

**电脑端（Win / Mac 桌面版）：**
1. 解压 `IP定位诊断技能包.zip`，得到 `qinpei-ip-diagnosis` 文件夹
2. 把文件夹放进 WorkBuddy 的 **skills 目录**
3. 重开 WorkBuddy 就能用

> 手机、电脑装的是同一份，用法一样；纯对话诊断，不产文档，手机用最方便。

## 三、第一次怎么说

**直接抄**：
> "帮我诊断一下我的IP"

**带具体问题**：
> "我发圈没人理，是不是我人设不对？"

**系统测**：
> "我想系统测一下自己的IP定位起点"

**问类型**：
> "我适合做什么类型的IP？"

## 四、它会怎么工作

1. 先问你是"带问题来"还是"系统测"（选一个就行）
2. 走**四要素**：你是谁 → 你凭什么 → 你给什么 → 你带来什么（答不全也没关系，一个一个来）
3. 收成**一句话定位**（`用【方案】解决【人群】的【问题】`）
4. 判**IP 类型**（四问定类型：讲干货还是讲故事 / 因为什么被信任 / 最容易产出什么 / 每天多少时间）
5. 按 4 个信号打分（满分 8 分）：定位清晰度 / 内容持续性 / 真实反馈 / 可复制表达
6. 给你文字结论，你确认"OK"后，我把你的定位**记下来**——下次直接来找我，不用重新讲一遍

> **v3.0.0 最大的变化**：诊断主框架从"IP 三问"换成了**四要素**——多出来的那一条「**你凭什么**」，正是 IP 的差异化内核。以前只讲"你是谁、帮谁、怎么帮"，谁都答得出；现在要挖出"凭什么是你"，这才是别人记住你的理由。

## 五、它记得住你

诊断完，它会把你的一句话定位、IP 类型、背书方向**存进你自己的记忆里**。
- 下次再来找它 → 它会先说"我记得你的画像是这样……这次还沿用吗？沿用我就在这基础上升级"，不用重新讲
- 如果你以前用过沁珮的其他技能包、留过画像 → 它也会读出来问你，**沿用就在原基础上补，不沿用就重新问**

## 六、注意事项

- 它**不写具体文案**——只给定位、类型这些方向
- 它**不编数据**：你没讲到的，它不会替你编"很成熟"
- 诊断只给方向，决定权在你自己
- 它可能比之前"较真"（会追问、会打回"帮所有人""我很专业"这类回答）——这是故意的，为了给你真判断
- **不是所有人都该马上做 IP**：如果你业务基本功还没过关，它会直接建议你先做业务，别急着立 IP

## 更新日志

- **v3.0.1**（2026-09-11）：**去掉赛道分类**——原「赛道A 大众×低客单／赛道B 小众×高客单」按客单价划分，不适合大健康 / 分享经济团队长的实际经营场景（产品和价格由品牌与制度决定，不是 IP 自己能选的），会引起"我该选哪条"的无效纠结，故整节移除。「收窄人群、做到不可替代」的洞察保留，改用「从泛内容 → 聚焦一类人」表述；IP 类型定向（4 类型 + 主辅组合 + 四问定类型）不变。
- **v3.0.0**（2026-09-11）：**核心框架换代**——① 诊断主框架"IP 三问"→"IP 信任体系四要素"（你是谁/你凭什么/你给什么/你带来什么）② 新增「一句话定位」句式 ③ 新增「4 种 IP 类型 × 四问定类型」（主类型60%+辅助40%）④ 新增 5 个真实案例 + 两个反常识 + 表达转换句式 ⑤ 新增画像记忆（写入你自己的记忆，跨会话自动读取，读到旧画像会问你是否沿用）⑥ 新增"不做 IP"劝退路径 ⑦ 收尾改为按环境自适应（单独安装时不跳转任何其他技能包）。

- **v2.0.0**（2026-08-21）：知识编码升级——IP三问加合格线与打回话术；成熟度4信号改打分制（0-2分/信号，未讲按0分）；可行性判断加三条硬标准；定位方向加"三不写"质量门禁；新增触发条件与AI自检注意事项；报告内容固定化。
